Composed pipeline:
  `tools/reader_trace_pipeline.py` provides `enrich_reader_trace(...)`.
  It composes the existing byte-concordant indexer bridge, exact-image helper-profile attachment and core graph validator. It reports whether a profile matched and explicitly reports `instruction_decode_performed=false` and `semantics_promoted=false`.
  Unknown helper EAs remain unprofiled. Aggregated multi-reader summaries do not fan out query/result attribution.

Exact-image helper-profile coverage:

  - Unknown EA, other ROM SHA and other CPU profile do not match
  - Evidence references required before profile attachment

Geometry coverage:
  - 1D UBYTE implicit-uniform lookup; q >= 0xF0 terminal path retained with 224/240 wording conflict unresolved.
  - 32-point explicit UWORD axis/value curve, query construction, helper chain, result staging and conditional post-call normalization.
  - 4x4 UBYTE map with distinct, strictly increasing 4-point axis vectors and one unsigned UBYTE query used for both axis searches.
  - 0x0AFF2 instruction/result path distinguishes R0-to-R2 delay-slot transfer, first multiplication consumer, UWORD product sink FFFF115A and separate inline element staging FFFF14E4.
  - All graph edges retain evidence basis explicitly; report-derived edges are not represented as fresh instruction observations.

Evidence boundary:
  The 0x0F10E and 0x10F8A cases are represented from existing closed reports; their source listing identity is not independently re-decoded in this implementation. The 0x0AFF2 case cites the exact Stage-16 extracted listing hash recorded by WO70033, but this graph is still a structured extraction from the report, not a fresh instruction re-decode. Physical meanings and donor semantics remain unpromoted.

Limit:
  The implementation has a graph contract, adapters for the existing SH-2 static indexes, exact-image helper-profile attachment and a single-entry enrichment pipeline. It is not yet a generalized instruction-level semantic reader tracer, whole-ROM CFG/interprocedural engine, or proof of physical calibration meaning.
