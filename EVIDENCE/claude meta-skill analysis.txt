## ISA and ROM cheat sheet (checked in this ROM)
- A branch delay slot always executes (`bt/s`, `bra`, `rts`).
- `bt` branches when T=1, and `tst #imm` sets T when the bit is **clear**.
- `cmp/hs Rm,Rn` sets T when Rn ≥ Rm (unsigned).
- `mov.b` and `mov.w` sign-extend. `mov #imm` sign-extends, so offsets over 0x7F need `extu.b`.
- A 16-bit literal like `h'8xxx` becomes `FFFF8xxx`. A 32-bit `.data.l` value below 0x100000 is a ROM pointer.
- ROM base is 0. RAM is `FFFF xxxx`. The A/D data registers are at `FFFFF800`.
- Calibration scalars sit near `0x8000–0x9000`, reached through a pool pointer. Some are copied to RAM at init.
- `sub_22E10` returns table[15] for query ≥ 0xF0, and otherwise interpolates with `floor((B−A)·frac/16)`.
- The dispatcher `sub_2088C` runs the nine-entry table at `0x21A64`.
- The flag bytes at `860D`, `860B` and `860F` form a one-pass delay chain.

## 2. Function and GBR map, with the scheduler
- **Contents:** Function bounds, the GBR value inside each function, callers and callees, and the ISR → `sub_2088C` → task-table order.
