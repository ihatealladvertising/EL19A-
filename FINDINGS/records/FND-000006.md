# FND-000006 — 0x0F406: 32-point NTC normalization curve with conditional voltage-grid compatibility

**Status:** CURRENT  
**Semantic layer:** input normalization / function-family analogue; physical sensor identity unresolved.

## Addresses and geometry

- ROM `0x0F406–0x0F425`: 32×1 UBYTE curve, verified bytes `FF F1 C8 AE A0 95 8D 86 80 7A 76 71 6D 69 65 61 5D 5A 56 52 4E 4A 46 42 3D 39 33 2D 26 1B 08 00`.
- Reader `sub_22E28`: fixed implicit query grid `0,8,…,248`; no explicit ROM axis pointer.
- Known callsites: `0x28B38`, `0x28B6E`, `0x354AE`, `0x3572C`.
- Acquisition context: ADC2 channel `0x1B` / AN27 and channel `0x1F` / AN31; raw 10-bit result staged with `>>2`, then evaluated through `0x0F406`.

## Observation

WO65056/WO65057 establish two distinct NTC acquisition paths. AN27 raw data at `FFFF1798+0x1C` is shifted into `FFFF8588`, read through `0xF406` at `0x28B38`, and reaches `FFFF84C1` with mirrored/normalized fields `FFFF84BA`/`FFFF84B8`. AN31 raw data at `FFFF1798+0x1A` is shifted into `FFFF857F`, read at `0x28B6E`, and reaches `FFFF84BC`/`FFFF84BB`. Both paths carry a `0x0A..0xAA` validity/range family and downstream filtering/failsafe/slew behavior; WO65182 confirms the MCU input identities but not coolant-versus-IAT wiring.

The target curve output follows an Nissan raw-minus-50°C normalization family: WO65056 records rescaled normalized temperature `[0..255]` from `[0x0A..0xAA]` with failsafe `0x82`, interpreted as raw-minus-50°C. Donor `mTTWN` is a V6-space 32×1 UBYTE `CURVE` at donor `0xDC7A`, `COMP_0035 = raw−50 °C`, fixed 32-point axis `0..4960 mV` at `160 mV/point`, with donor function list `KF7-301.8M[3]`, `KF7-301.16[5]`, `KF7-500.1[54]`. Donor payload bytes are unavailable; no bytewise equality is claimed.

The original axis comparison observed that an 8-count target step equals `160 mV` if one staged count is `20 mV`. That is **conditional numeric compatibility only**. WO65182/WO65134's coordinator erratum corrects the nominal-5-V arithmetic: SH7058 Rev.3 §17.6 specifies external `AVref` over `4.5 V..AVcc`, with `AVcc=5.0 V±0.5 V` for ADC operation. For an ideal 10-bit converter followed by `>>2`, one staged count is approximately `AVref/256` and one 8-count interval is `AVref/32`. At nominal 5.0 V this is `19.53125 mV/count` and `156.25 mV/step`; exactly `20/160` requires `AVref=5.12 V`, which is permitted by the device range but not proven on this ECU.

## Conclusion

Treat `0x0F406` as a **strong V6 `mTTWN` donor candidate** by exact 32×1 UBYTE geometry, fixed-grid construction, compatible raw-minus-50°C output family, and dual NTC/diagnostic software context. Do not promote the donor name, °C conversion, mV axis, donor address or coolant/IAT assignment into an EL19A physical identity. The voltage-grid relation is a conditional hypothesis pending actual board `AVref`; the AN27/AN31 physical sensor mapping is unresolved.
