# FND-000016 — 0x0E21A is a three-threshold selector producing bin index 0..3

**Status:** CURRENT  
**Semantic layer:** input lookup / discrete index selection; physical input domain and calibration meaning unresolved  
**Evidence grade:** ROM instruction-level selector and direct indexed reads  
**Confidence:** HIGH for threshold and index mechanics; LOW / UNRESOLVED for physical meaning

## Affected ROM objects

- Threshold list: `0x0E21A–0x0E21C`, UBYTE values `06 08 0C` = `[6, 8, 12]`. The following byte at `0x0E21D` is `00` and is not read by this selector.
- Four-entry UBYTE table: `0x0ED9C–0x0ED9F`, values `[0, 59, 74, 94]`.
- Four-entry UBYTE table: `0x0F2AE–0x0F2B1`, values `[30, 30, 30, 30]` (constant).
- Four-entry UWORD BE table: `0x107CC–0x107D3`, values `[0, 6528, 16128, 20224]`.

## Observation

In `sub_403D8`, ROM PCs `0x4057A–0x405D8`, the UBYTE query is compared successively against the three threshold bytes at `0x0E21A`, `0x0E21B` and `0x0E21C`:

- query < 6 produces index 0;
- 6 <= query < 8 produces index 1;
- 8 <= query < 12 produces index 2;
- query >= 12 produces index 3.

The resulting integer index is used directly for the three table lookups. There is no interpolation against `0x0E21A`. The fourth byte `0x0E21D` is not part of the threshold comparisons.

## Conclusion and Release 1 representation

`0x0E21A` is a three-threshold bin discriminator, **not** a four-point ROM axis. The three associated arrays are structurally sound four-entry data objects when shown against an explicit static **Bin Index 0..3** axis. The invalid `storageaddress="0x0E21A"` axis binding must be removed. Keep all data raw/generic; the physical meaning of the input thresholds and table outputs is unresolved.

The constant `0x0F2AE` curve is retained as a constant four-entry object rather than interpreted as an interpolation schedule.

## Confidence, limits and no-repeat boundary

- HIGH: threshold byte count/values, comparison branches, result index range, and direct indexed lookups.
- LOW / UNRESOLVED: physical quantity represented by the query, meaning of the bins, and meaning/units of the three arrays.
- Do not reinterpret the thresholds as physical breakpoints or a measured four-point axis.
- Do not repeat the bounded selector/lookup trace at `0x4057A–0x405D8` without a new contradictory evidence source.
