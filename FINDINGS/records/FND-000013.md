# FND-000013 — A bit publication can be split across a branch delay slot: the masking store may be the SET path

**Status:** CURRENT
**Semantic layer:** none (evidence-method finding; establishes no calibration identity)
**Evidence grade:** READER-VERIFIED (every instruction below read from the pinned LST)

## Affected addresses and objects

Every site that publishes a single bit into a status byte by merging a set path and a clear path into one store. Worked instance in this record:

| Cell | Set side | Clear side | Merged store |
|---|---|---|---|
| `FFFF3579` bit4 | `or #h'10, r0` at `0x07EBBE` | `and #h'EF, r0` at `0x07EBD0` | `mov.b r0,@((byte_FFFF3579 - h'FFFF34B3),gbr)` at `0x07EBD2` |

## Observation

`sub_7E8B2` evaluates six conjuncts (`cmp/hi` at `0x07EB90`, `0x07EB9C`, `0x07EBA8`, then `and #h'3F` / `cmp/eq #h'3F` at `0x07EBAE`/`0x07EBB0`, then a `tst #2` on `FFFF3575` at `0x07EBB6`). Each failure branches to `loc_7EBCE`. The success path is:

```
0x07EBBA  mov  r9, r0
0x07EBBC  bra  loc_7EBD2          ; jumps to the shared store
0x07EBBE  or   #h'10, r0          ; DELAY SLOT of the bra above
```

and the failure path is:

```
loc_7EBCE  mov  r9, r0
0x07EBD0   and  #h'EF, r0         ; clears bit4
loc_7EBD2  mov.b r0,@((byte_FFFF3579 - h'FFFF34B3),gbr)
```

Both paths execute the same store at `0x07EBD2`. Reading the store in isolation shows `and #h'EF` above it and suggests a clear-only site; the **`or #h'10` that sets the bit lives in the `bra` delay slot two instructions earlier**, so the same PC publishes set and clear depending on the incoming path.

## Conclusion

A single store reached from two paths can carry both polarities of a bit, with the set-side operation hidden in a branch delay slot. A `store`-admiring read that stops at the masking `and` above the store misclassifies the site as clear-only and loses the publication entirely.

## Rule

When characterising a status-bit write, decompile the **whole** basic block that reaches the store, including the delay slots of every `bra`/`bsr`/`bt/s` on each incoming edge, and note both polarities before stating what the store publishes. Treat an `and #h'~mask` immediately above a store as a hint, not as proof, that the site is a clear. The mirror rule also applies: an `or #mask` above a store is not proof of a set site.

## Confidence

**HIGH** for the mechanics of `0x07EBB4`-`0x07EBD2` — the delay-slot placement and both masked values are read directly, and the subsequent `tst #h'10,r0` at `0x07EBD8`/`bt/s` at `0x07EBE2` only makes sense if the bit can be either value.
