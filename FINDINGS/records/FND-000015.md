**Status:** CURRENT
**Semantic layer:** function identity (diagnostic monitor status array) — no calibration identity
**Evidence grade:** READER-VERIFIED (every instruction below read from the pinned LST)

## Observation

**Count.** The gate loop in `sub_8AD7C` loads its counter as an immediate: `mov #unk_FFFFFFC6,r6` at `0x08B33C`, `extu.b r6,r6` at `0x08B340` → 198; `dt r6` at `0x08B35E` with `bf/s loc_8B342` at `0x08B360` gives exactly 198 iterations, and the pointer advances by `add #3,r5` at `0x08B35A`. Four further sweeps carry the same constant: `0x07437A` (byte1 bit2 clear, byte2 bit2/bit1 clear), `0x075DD4` (byte2 bit2 set when byte2 bit4 set and byte0 < 0x28), `0x075E9C` (byte0 := 0, byte1 &= 0xC2), `0x0800A2` (byte1 bit7 clear). The descriptor's 687 bytes is therefore **capacity**, and 198 is the **live** count: 229 and 198 are not in conflict.

**Populate path.** Three routines write per-entry flags by index, all with `entry = FFFFA074 + 3*index` computed as `r5 = index*2; r5 += index`:

```
sub_8081C (0x08081C)   r1 = FFFFA074 ; r5 = 3*r4 ; r6 = r1 + r5
  0x08082A  mov #1,r2
  0x08082E  or  #8,r0            ; byte2 bit3 SET
  0x080830  mov.b r0,@(2,r6)
  0x080836  mov.b @(1,r6),r0 / 0x080838 or #h'20 / 0x08083A mov.b r0,@(1,r6)   ; byte1 bit5 SET
  0x08083C  mov #h'7E,r0 / 0x08083E mov.w word, r6 = FFFFB4A8 / 0x080840 mov.b r2,@(r0,r6)   ; FFFFB526 := 1

sub_8085E (0x08085E)   byte2 bit3 SET (0x08086E, store 0x080870) AND byte2 bit6 SET (0x080878, store 0x08087A)

sub_80884 (0x080884)   byte2 bit4 SET (0x080894, store 0x080896); rts, delay-slot store to FFFFA378+0xB56
```

Callers sit in the `0x0724xx`-`0x072Bxx` diagnostic band and pass `r4 = r14`, the same monitor index already used to index the pointer table at `0x13780` (`0x072424`-`0x07242A`): `0x072430`, `0x072642`, `0x07284A`, `0x0728C6`, `0x072B2E` (all `jsr sub_8081C` preceded by a conditional `tst #h'80` on a test-status word) and the paired `0x072436`, `0x072648`, `0x072850`, `0x0728DA`, `0x072B38` (`jsr sub_80884`).

**No content loader.** A pointer census over all 93 `mov.w word_…,rN ; h'FFFFA074` load sites (20-instruction forward window, stopped when the base register is reloaded) yields 13 store sites: the three setters above plus ten single-field flag ops at fixed offsets (`+0x1C6` `0x0718EA`, `+0x1F` `0x0786D0`/`0x078B20`/`0x078CBA`, `+0x146` `0x0830CA`, `+0x19A` `0x0952BC`). No site stores a value loaded from ROM or from a measured RAM cell into an entry; byte0 is only compared (`0x075DE4`) or zeroed (`0x075EA2`).

## Conclusion

`FFFF A074` is a **diagnostic monitor status array**: 198 live 3-byte entries, each carrying result/qualification flags in byte2 (bits 1, 2, 3, 4, 6) and byte1 (bits 5, 7), plus a byte0 comparand. Its live count is a compile-time 198 across five independent routines; the 229-entry descriptor extent is allocation capacity whose last 31 entries no located routine ever touches. `sub_24166`'s zero-fill is the initial state; population is per-entry flag setting from the diagnostic monitor callers, never a bulk content load.

## Confidence

**HIGH** for the counter, stride, the three setter routines, their callers and the absence of a content loader in the 93-site window. **MEDIUM** for the absence of a content loader *outside* that window (a routine that reaches the table through a descriptor field rather than a `h'FFFFA074` literal or an indirect pointer would not be caught; WO65904 established the descriptor `0x13B10` is reached only from `0x0242E8`, `0x02A8B4`, `0x02AA4C`, whose stores are the zero-fill). **UNRESOLVED:** whether the 31-entry tail is reserved capacity or an unexercised extension, and the physical meaning of each flag bit.

## Unknowns, contradictions, stop boundary

The `FFFF34F5.bit5` gate semantics remain physically unnamed: the corrected polarity establishes only that the latch arms when no entry carries byte2 bit3, i.e. an all-clear condition. Stop boundary: entry flags and their setters; byte0 semantics, the 31-entry tail and the latch's downstream readers were not traced.
