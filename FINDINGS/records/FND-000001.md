# FND-000001 — E678/E688: scoped screenshot presentation separated from runtime query mechanics

**Status:** CURRENT  
**Semantic layer:** input identity / calibration presentation; physical identity remains unresolved.

## Addresses and geometry

- ROM `0x0E678–0x0E687`: 16×1 UBYTE.
- ROM `0x0E688–0x0E697`: 16×1 UBYTE, separate placement with an identical payload.
- Raw bytes at both placements: `00 12 12 12 2F 2F 2F 19 03 00 00 00 00 00 00 00`.
- User-finalized display vector: `0, 36, 36, 36, 94, 94, 94, 50, 6, 0, 0, 0, 0, 0, 0, 0`.
- User-finalized display axis: `0, 400, 800, …, 6000` RPM for these two tables only.
- Runtime reader grid: `sub_22E10` implicit positions `0, 16, …, 240`; no explicit ROM axis pointer in these calls.

## Observation

`sub_403D8` reads `0xE688` through `sub_22E10` at `0x404C2–0x404C6` and `0xE678` at `0x40512–0x40516`. The caller forms `q = min(UWORD[FFFF85AE] >> 1, 0xFF)`; `FFFF85AE` comes from the timer-capture-derived chain `FFFF85E4 → FFFF8596 → FFFF85D6 → FFFF85AE`. The runtime factor `FFFF1676` is binary `0x00/0xFF`, not a physical ×2 conversion. The result is staged at `FFFF13F0` and can reach `FFFF1018`; prior audit found no ROM-code or DMA/DTC reader of `FFFF1018`.

The selection gates recorded for the calculation path are `FFFF85F8.bit4` and `FFFF8600.bit6`, with outer bypass by `FFFF860B.bit3`. The later truth-table correction supersedes the earlier polarity wording; flag physical names and any Drive/Neutral mapping remain unproven.

## Conclusion

For `0xE678` and `0xE688` only, preserve the user-finalized screenshot presentation: the RPM display axis and displayed values are authoritative at the presentation layer. Record the ROM query mechanics separately: the target uses an implicit `0,16,…,240` grid and a timer-derived query whose physical RPM equivalence is not established by this evidence. The raw×2 equality is a display fingerprint, not an EL19A runtime L/min scale. Do not generalize this exception to other tables or transfer donor Drive/Neutral semantics from the paired QDSPT family.
