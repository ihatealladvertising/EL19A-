**Status:** CURRENT  
**Affected addresses/objects:** `0x9B2E`, `0x9C2E`, `0x9DAE`, `0xE4AC`, `0xE4BC`, `FFFF1C79`.

## Old interpretation

`CONTROL/WO64969.md` classified the `0x9B2E` axes as dynamic GBR-relative values with no assignable ROM address. The XML fragment overlays each placement with separate `Ign_Degrees` and `Knock_Window_Flag` views, and names the `0x9C2E/0x9DAE` payloads `High Octane` and `High Detonation`.

## Corrected/current interpretation

`FND-000003` records fixed axes for `0x9B2E`: `loc_472DC` sets `GBR=0xE4AC` before the `0x473C0` call and restores it on exit, yielding `R6=0xE4AC` and `R5=0xE4BC`. `0x9C2E` and `0x9DAE` are byte-identical payload aliases; the paired path masks both results with `0x7F`, so the observed differential cancels and `FFFF1C79` is not a differential correction. Ignition, knock-window and high-octane/high-detonation labels remain XML display hypotheses only.
