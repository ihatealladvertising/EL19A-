# REC-000020 — 0x0E21A threshold selector replaces the invalid four-point ROM-axis binding

**Status:** CURRENT  
**Affected objects:** `0x0E21A–0x0E21C`, `0x0ED9C`, `0x0F2AE`, `0x107CC`  
**Related finding:** `FND-000016`

## Old interpretation

The selected baseline XML and original scope matrix attach `0x0E21A` as a four-point Y axis for `0x0ED9C`, `0x0F2AE` and `0x107CC`. The baseline disposition excluded all three objects because the four-byte region `06 08 0C 00` is not a four-point monotonic breakpoint array.

## Corrected interpretation

The ROM code at `0x4057A–0x405D8` consumes the first three bytes as thresholds `[6,8,12]` and computes a discrete index 0..3. The tables are indexed directly without interpolation. The fourth byte is unused in this selector.

The invalid ROM axis pointer is removed. Release 1 includes the three arrays as RAW/PROVISIONAL and gives them a static Y bin-index axis `[0,1,2,3]`, explicitly labelled with the selector thresholds at `0x0E21A`. The constant `0x0F2AE` data remains four equal raw values.

## Reason and evidence

- Target ROM `EVIDENCE/VERSA f501.bin`, `0x4057A–0x405D8`.
- `FND-000016` records the threshold comparisons and direct indexing.
- `CALIBRATIONS/RELEASE1_SCOPE_MATRIX_R1.csv` rows 092–094 change the dispositions to RAW/PROVISIONAL.
- `CALIBRATIONS/EL19A_release1_conservative.xml` removes the invalid `storageaddress="0x0E21A"` binding and uses the explicit static index.

## Confidence and limits

HIGH for the selector mechanics and index range. LOW / UNRESOLVED for the physical input domain and the physical meaning of the table values. No measured operating axis is claimed.
