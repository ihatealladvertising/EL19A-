# REC-000019 — Release 1 successor corrects baseline placeholder and misattached axes

**Status:** CURRENT  
**Affected objects:** the axis-recovered provisional surfaces/curves listed in `FND-000017`; `0x0FEC0` shared-row axis; `0x09B2E`, `0x09C2E`, `0x09DAE`; and the already established `0x0F3D6/0x0F3DE`, `0x0E904` axis corrections.

## Old interpretation / baseline XML state

The selected full-definition baseline contains a mixture of sample-index placeholders, static raw-query placeholders and several incorrect ROM-axis attachments. In particular:

- `0x09B2E/0x09C2E/0x09DAE` place X=`0x0E4BC` and Y=`0x0E4AC`, reversing the established reader argument orientation in `FND-000003`.
- `0x0EFFC`, `0x1031C`, `0x1109A` and `0x12D98` carry mode-gate or unrelated addresses as axes.
- The provisional tables listed in `FND-000017` contain static/index placeholders where the ROM reader uses explicit axes or fixed grids.
- `0x0FEC0` uses row 0 of `0x0CD56` as its shared Y axis.

## Corrected interpretation and successor implementation

The owner-integrated successor `CALIBRATIONS/EL19A_release1_conservative.xml`:

1. Implements X=`0x0E4AC`, Y=`0x0E4BC` for all three 9B2E-family raw maps, as already established by `FND-000003` / `REC-000003`; both axes use raw scaling.
2. Replaces bogus axis attachments with the explicit ROM axes or implicit fixed raw grids in `FND-000017`.
3. Recovers the listed ROM-axis pointers for provisional curves/surfaces and restores the implicit fixed UBYTE/UWORD grids where helper mechanics prove them.
4. Uses a clearly labelled index-only axis for inline-indexed surfaces and for any axis whose physical query domain remains unresolved.
5. Preserves the `0x0CD56` row-0 shared-axis relationship for `0x0FEC0`.
6. Reuses `FND-000002` / `REC-000002` for `0x0F3D6/0x0F3DE`, and `FND-000005` / `REC-000005` for `0x0E904`, rather than duplicating those established corrections.

## Reason and evidence

- The selected baseline XML and the object-by-object matrix were compared in exact top-level order.
- The corrected matrix has 261 rows: 2 ESTABLISHED, 252 RAW/PROVISIONAL and 7 EXCLUDE.
- Reader mechanics and exact callsites are consolidated in `FND-000017`; the 9B2E argument order is already preserved in `FND-000003`.
- The original baseline XML and original consultant matrix are retained unchanged.

## Confidence and limits

HIGH for the recovered addresses, widths, dimensions, helper relationships and index/fixed-grid representation as reported by the ROM/LST audit. Physical units and actual operating domains remain unresolved for raw/provisional objects.

The owner build performed XML tree parsing, 1:1 matrix correspondence, object-extent arithmetic, static-axis element-count checks and ROM-address-bound checks. This does **not** claim a RomRaider desktop import test or a new byte-by-byte binary extraction in this session; those remain explicit validation requirements before calling the release fully validated.
