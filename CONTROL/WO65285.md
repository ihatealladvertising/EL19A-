## Objective

Use the validated A2L 1D declaration-order stream to rank EL19A 1D curve candidates and identify missing ignition/fueling curves, without transferring donor addresses or labels. Prioritize target 8-, 16- and 32-point UBYTE/UWORD/SBYTE curves with known extents or reader geometry.


## Scope

1. Reuse WO65283's normalized sequence and measured ordering reliability; if order only holds within a function group, align within that group only.
2. Build the target-side 1D curve sequence from the merged XML, ignition fragment and 179-row catalogue, keeping known extents separate from inferred/unknown extents.
3. Use only independently verified anchor matches (matching geometry/storage plus target evidence); align with gaps and preserve repeated/duplicate physical placements as separate target addresses.
4. Rank candidate matches for ignition dwell/idle/cranking curves, fuel start/base schedules, fuel-cut curves, and other potentially relevant 1D objects. Include disconfirming evidence and competing matches.
5. For each proposed match report target address/extent/storage, donor symbol and ordinal, axis and conversion metadata, target reader/query evidence, confidence per layer, and the next cheapest discriminator.

## Required deliverable

A bounded report containing:
- Exact target addresses, extents, storage types, dimensions and axis/query evidence where established.
- Relevant target instruction PCs, caller/reader contract, transforms, branch conditions and first meaningful consumers where in scope.
- Separate structural, axis/scaling and functional confidence.
- Candidate-to-symbol matches and disconfirming evidence where applicable.
- RR disposition and exact unresolved boundary.
- Reused evidence and explicit no-repeat list.
