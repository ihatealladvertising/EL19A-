## Results

### Record run and layout

- The listing and raw ROM support a contiguous run of **197 12-byte records** from `0x12E44` through `0x1377F`; end-exclusive `0x13780`. The preceding bytes at `0x12E38` are separately listed as three longword/vector values. The last record starts at `0x13774`; a different pointer-list representation begins at `0x13780`.
- For the examined records, the cited DTC numeric suffix is the big-endian UWORD at record offset `+6`; the record stride is `0x0C`. The six prefix bytes and final four bytes vary; their semantics are not assigned here.
- These are numeric code fields (`03 40`, etc.), not ASCII strings containing a literal `P`. The P-code labels below are the corresponding reported OBD-II interpretation of those numeric suffixes; this work did not trace ECU reporting behavior.

This is not sufficient evidence that the DTC run is consumed there; no DTC consumer or reporting path is claimed.
