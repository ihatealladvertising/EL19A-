## Part A — ADC reference / full-scale voltage

1. Start from the already established ADC2 conversion path and peripheral register addresses in WO65056/WO65105. Inspect only the ADC2 configuration and initialization sites necessary to determine whether firmware selects, calibrates or otherwise encodes the ADC reference.
2. Determine whether any target code or existing repository hardware evidence explicitly identifies:
   - VREFH/VREFL or equivalent reference source;
   - a reference-select bit/setting or internal reference path;
   - a calibrated ADC full-scale value or reference constant used by the AN27/AN31 processing;
   - a hardware/board-level source for the actual voltage.
3. Preserve the difference between ADC resolution, shift operations and physical reference voltage:
   - A raw 10-bit result followed by `>>2` proves an 8-bit staging representation.
   - The `0,8,...,248` lookup grid proves 8 staged counts per point.
   - `8 × 20 mV = 160 mV` is arithmetic compatibility only; it does not prove 20 mV/count or a 5.0 V reference.
4. If the reference is fixed by external analog pins or board wiring and no repository schematic/pinout/calibration record identifies its voltage, stop at that exact boundary. Do not mine unrelated constants or perform a global 5 V/ADC scan.
