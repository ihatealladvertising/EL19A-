## Objective

Only the first meaningful consumer of each cell is in scope.

## Mandatory falsifiable hypothesis

- **Identity layer advanced:** output identity and function identity.
- **Hypothesis:** both cells are *target levels* for a closed-loop or rate-based controller, so each should be read by one routine that compares it against a measurement and produces an actuation or state command.
- **Evidence:** WO65313 verifies the write side (`FFFF1810` at `0x36A76`; `FFFF9992` at `0x38BA6`) and the construction `curve result + speed-family offset → filter/blend`.
- **Prediction:** each cell has a small, bounded reader set whose immediate arithmetic is a comparison/subtraction against another level, followed by a command write.
- **Cheap discriminator:** enumerate readers of exactly `FFFF1810` and `FFFF9992` (plus the `FFFF180C+4` and `FFFF9916+0x7C` access forms) from the existing RAM cross-reference, then decode the first consumer of each.
- **Information gain:** distinguishes a regulated target from dead-end staging, which is the difference between a nameable control function and an unresolvable internal store.
