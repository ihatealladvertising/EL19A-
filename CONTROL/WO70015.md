## 4. Findings-backed objects outside the current XML/scope/catalogue

These are not newly discovered in WO70015. Their target evidence is already recorded in current Findings and the project direction.

| Address | Established structure | Existing evidence | Recommended treatment |

| `0x0DE6E` | 16×1 UBYTE vector, extent `0x0DE6E–0x0DE7D` | FND-000022 / REC-000025; WO64938 | Defer as part of a linked/edit-coupled pair. |
| `0x0E2ED` | 16×1 UBYTE vector, extent `0x0E2ED–0x0E2FC` | FND-000022 / REC-000025; WO64938 | Defer with `0x0DE6E`; each vector serves as data and the other's axis at reciprocal calls. |

The reciprocal pair is not two independent ordinary curves. Editing either vector changes its values and the breakpoint grid used by the other lookup. A future definition must preserve both, cross-reference the pair, and clearly warn that editing is coupled. The source report's unresolved alternative call-PC statement is already isolated in FND-000022/REC-000025 and is not re-opened by this inventory-only WO.

The six map/axis catalogue gaps plus these three Findings-backed objects give **nine specifically accounted-for structures outside the current Release 1 inventory** (six catalogue entries and three standalone objects). This is not a total of every possible missing ROM table; it is the finite verified set established by the current cross-file reconciliation and cited Findings.
