### 4. Gate polarity correction (WO65254) — slew-rate limiter

At `0x66E8A–0x66E92`: `mov.b @r9,r0` (`r9=FFFF8B52`), `tst #h'40`, `bf loc_66EF8`; fall-through `bra loc_66F76` with delay slot `mov r7,r0`.

- **`FFFF8B52.bit6` SET** → direct path: `0x66F76` `mov.w r0,@(h'96,gbr)` stores the blend result unchanged to **FFFF10BE** (GBR=FFFF1028).
- **`FFFF8B52.bit6` CLEAR** → `loc_66EF8` adjustment path:
  - Cap compare `UWORD[FFFF84FE] > ROM[0x98B8]` (`0x66EFC–0x66F02`), then status gates `FFFF85FF.bit7`, `FFFF8613+4.bit3`, `FFFF3628+7.bit3`, `FFFF85FF+1.bit5` (`0x66F04–0x66F20`); any failure routes to `loc_66F5E` with delta 0.
  - Step computation: `r6 = UWORD[FFFF84D4+0xE] = UWORD[FFFF84E2]`, `r2 = UBYTE[0x8832]`, `mul.l` (`0x66F24–0x66F2E`); product saved; `sub_21AC0` called with `UBYTE[0x8463]` (`0x66F30–0x66F3C`, helper contract not re-derived); result minus saved product (`0x66F4A`).
  - Delta clamp: `r6 = UWORD[FFFF1000] − UWORD[FFFF1002]` (`0x66F40–0x66F4C`); if step > r6, step = r6 (`0x66F4E–0x66F52`); `cmp/pz` — negative step → 0 (`0x66F54–0x66F5E`).
  - `loc_66F60`: `r6 = FFFF1002 + delta`, unsigned saturate to `0xFFFF` (`0x66F60–0x66F72`). Delay-slot store `0x66F70` `mov.w r0,@(h'92,gbr)` writes the **delta to FFFF10BA on both clamp outcomes**; `0x66F76` writes the clamped value to **FFFF10BE**.

WO65254's prose reversed the bit6 mapping ("clear → FFFF10BE / set → may write FFFF10BA"); the instruction bytes above are authoritative. FFFF10BA is a nonnegative slew delta, FFFF10BE the rate-limited output moving from the blend target toward the held value FFFF1000. Physical meaning of the direction/units remains unresolved; the arithmetic structure (target + bounded nonnegative step, delta staging) is a slew/rate-limit pattern.

### 5. Qualification flag and sample-and-hold output FFFF10C0

- `0x66F78–0x66F94`: reads `UBYTE[FFFF34C1+0xC8]` bit7; gates `UBYTE[FFFF34C5].bit0`, `UBYTE[FFFF34C1].bit0`, `FFFF85FF+1.bit5`, `UWORD[FFFF84FE] ≥ ROM[0x91EE]`.
