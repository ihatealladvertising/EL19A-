## Objective

Determine the exact instruction-level meaning of the sampled-cell `0x80` paths in `loc_23254` and `loc_2332C`. Keep the two reader implementations separate. Do not assign a calibration meaning such as invalid, unavailable or disabled without consumer evidence.

## RP-004 — sub_22CB8 / loc_23254

- `sub_22CB8` computes the address of the first sampled data cell in R4 and the corresponding adjacent row address in R5; each row uses stride `0x10`.
- The interpolation path masks sampled UBYTE values with `0x7F` before passing them to `sub_231C8`.
- This masking is applied to the sample pairs used for interpolation; their bit 7 does not contribute to the numeric interpolation.
- At `0x232B4–0x232BE`, the tail reloads the original first cell `[R4]`, tests mask `0x80`, and ORs `0x80` into the interpolated result only when that first cell has bit 7 set.
- Therefore RP-004 propagates bit 7 from the first sampled cell while interpolating the low seven bits. A bit-7 value in another sampled cell is masked from the arithmetic and is not independently propagated by this tail.

## RP-006 — sub_22DA8 / loc_2332C

- `loc_2332C` compares sampled UBYTE values against `0x80` before interpolation.
- In the interior path, it checks the two adjacent samples at the first row and then the corresponding two samples at the second row. If any checked sample is `>=0x80`, control reaches `loc_233B4` and returns exactly `0x80`.
- In edge paths where only a single row/column pair is used, the participating pair is checked; any participating sample `>=0x80` likewise returns `0x80`.
- Only when all participating samples are below `0x80` does it invoke `sub_231C8` for the normal interpolation result.
- Unlike RP-004, RP-006 treats `0x80` or any higher UBYTE value among the participating cells as a reader-level sentinel condition. It does not interpolate the low seven bits and preserve an independent first-cell flag.

## Decision / closure

- **RP-004:** interpolate low 7 bits; separately propagate bit 7 from the first sampled cell only.
- **RP-006:** return sentinel `0x80` if any participating sampled cell is `>=0x80`; otherwise interpolate normally.
- These are different contracts and must not be merged into one generic bilinear-reader rule.
- The numeric/semantic interpretation of the propagated bit or returned sentinel remains caller-specific and unproven here.
