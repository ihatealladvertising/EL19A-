## 3. Glossary

| Term | Source-defined meaning / scope | Unit / dimension | Formula or relationship stated | Source page(s) | Confidence and ambiguity |
|---|---|---|---|---|---|
| MAF as load signal | A mass-air-flow meter provides a load signal from mass airflow without separate barometric-pressure and air-temperature correction; contamination, reversion and plumbing affect reliability. | Mass airflow / inferred load | No formula on p1; qualitative load claim. | Nistune p1 | Explicit source statement; Nistune product context, not EL19A proof. |
| Reversion / vented metered air | Reverse flow after boost or atmospheric BOV venting makes the ECU see metered airflow the engine did not receive, causing rich/lean disturbances. | Qualitative airflow/error | Extra measured airflow → corresponding extra fuel. | Nistune p1 | Explicit; fault-mode/installation context. |
| VQ map / voltage quantifier | Converts MAF voltage into the value used to determine load. | MAF voltage input; load output | `TP (load) = VQMap[MAF voltage] / RPM * K Constant`. | Nistune p5 | Explicit formula; TP unit not stated; only VQ-equipped ECUs. |
| MAF transfer table | Single-axis table indexed by static sensor voltage; table values are raw but directly related to grams/second; increasing values increases injector pulse width. | Voltage axis; raw airflow-like values | No numeric conversion stated. | UpRev p4 | Explicit; raw-to-g/s conversion not given. |
| K fuel multiplier | ECU multiplier used to determine base fuel schedule; adjusted for injector/MAF changes. | Dimensionless multiplier | `current MAF value × K value = BFS`. | UpRev p4 | Explicit; UpRev tuning-product definition. |
| BFS / base fuel schedule | Theoretical injector pulse width required to maintain 14.7 AFR; explicitly **not** actual injector pulse width. Used as an axis on fuel-target, ignition, cam-advance, torque and boost-sensitivity tables. | Time (milliseconds implied by examples); load-like axis | `BFS = MAF × K`; actual PW also depends on AFR target, trims and runtime conditions. | UpRev p4, p6–p7, p10, p12 | Explicit; do not equate BFS with actual PW or generic load. |
| Calculated Load | ECU divides current BFS into the table value at the current RPM; affects automatic-transmission line pressure. | Percent / load ratio | Paraphrase of source: calculated load = table value at RPM / current BFS. | UpRev p6 | Explicit; 100% at WOT is a tuning goal, not a universal conversion rule. |
| TP minimum / TP maximum | MAF-to-load stabilisation limits: minimum prevents zero measured load on deceleration; maximum prevents overshoot/richness on acceleration. | Load limit | No numeric formula; table lookup by RPM. | Nistune pp3–4 | Explicit; availability varies by ECU, with some 1995+ VE/NEO ECUs lacking TP minimum. |
| Fuel Target | Table returns desired AFR; axes are BFS and RPM. | AFR target | X = BFS; Y = RPM. | UpRev p3 | Explicit; ROM/table-specific. |
| Fuel Compensation | Percent change to base fuel schedule; 100 is neutral, above 100 adds injector PW, below 100 removes it. | Cranking Enrichment | Modifies BFS by percentage from a coolant-temperature lookup; 100 is neutral. | Percent of BFS; coolant axis | Axis = coolant temperature. | UpRev p5 | Explicit; static axis. |

## 5. Conflicts, ambiguity and non-applicability

- UpRev explicitly warns that ROM versions differ; High Det, Timing Cold, knock-strength logging and some compensation tables are platform/ROM-version specific. None is assumed present in EL19A.
- Nissan ignition-table values in UpRev are burn-time representations, not degrees BTDC. A table with plausible timing-like values cannot be labeled degrees from literature alone.
- UpRev BFS is theoretical pulse width for 14.7 AFR, while Nistune `TP (load)` is a VQ/RPM/K-derived load with unstated units. The shared letters and RPM dependence do not prove the same ECU variable.
- UpRev itself calls the electronic-throttle X axis "unknown theoretical value"; no EL19A candidate was promoted from that description.
- Knock-listening frequencies describe an external diagnostic device and human/spectrogram observation, not the ECU's knock-detection algorithm or threshold.
- No numerical MAF raw-to-g/s conversion, NTC channel identity, torque unit, cam-advance unit or crank-drag unit is supplied by the sources.
- WO65287's target-side rejection of knock-window/degree interpretation overrides the literature vocabulary for `0x9B2E/0x9C2E/0x9DAE`; the literature row is retained only as source history.
