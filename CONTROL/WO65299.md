## 6. Duplicate, alias and defect reconciliation

1. **Ignition family alias defect.** WO65162 I-03 found six ignition-fragment rows for three objects. The selected baseline is broader: it contains the three raw v3 rows at lines 134/139/144 **and** six decoded/knock rows at lines 889–913, i.e. nine rows for three byte ranges. Proposed disposition: collapse each address to one raw UBYTE row; omit all `Ign_Degrees` and `Knock_Window_Flag` views as independent tables. Keep `0x9C2E` and `0x9DAE` as separate placements because WO65287 proves runtime selection and differential use despite byte-identical payloads.
2. **Knock-window rejection.** WO65287 found bit 7 is separately staged, masked and reinserted, with no independent bit-7-only consumer and no target-side link to knock detection. `floor(x/128)` and `(x%128)-64` are off-target display conventions, not EL19A arithmetic (WO65109 line 61; WO65287 §6).
3. **Axis orientation conflict.** WO65109 line 88 records fragment X=`E4BC`/Y=`E4AC` versus reader convention Y=`E4BC`/X=`E4AC`. The addresses and 16×16 geometry are certain; grid orientation is not. Proposed rows preserve the existing X/Y slot convention but flag the orientation as unresolved.
4. **Single-axis/scalar extent defects.** WO65162 I-01/I-02: 22 `1D` rows lack declared extent; 35 `2D` rows have one axis and are true 1-D curves (33×16 B, 2×8 B). No extent is invented here; final assembly must repair representation. The proposed curve snippets below use the current one-axis dialect to remain copy-paste-valid, with the defect explicitly carried forward.
5. **`0x0E904` contract collision.** WO65162 I-04 remains a definition defect: static 0–240 Y axis in XML versus proven `UWORD` axis `0x0FA62` in the catalogue. No new trace was performed; final assembly should use the catalogue axis.
6. **Register baseline flags carried forward, not re-derived.** Per the live register's WO65325 audit flags: `E678/E688` are timer-query QDSPT basic-value curves rather than RPM-axis airflow maps; `F3D6/F3DE` need ROM axes `F3C6/F3CE`; `0x8550` is mDSHCUT / DSPT Prohibition Coolant Temperature, not proven specifically a Rev Hang gate.
