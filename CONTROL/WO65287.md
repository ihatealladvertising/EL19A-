  - 0x474CC reads stack+0x14, 0x474D0 reads stack+0x18; `or r6,r2` @0x474D4; `or r2,r6` @0x474D8; store byte → **FFFF1324** (FFFF1054+0x2D0) @0x474DC.

- **Two staging exit modes:**
  1. **Blend exit** via 0x475EC/0x475F0: FFFF1324 = blend1 | bit7-flags, FFFF1325 = blend2 | bit7-flags.
  2. **Raw overwrite exit:** branches at 0x47524–0x4752C and 0x475F2–0x475FA test a gate bit via `tst.b #2, @(r0,gbr)` with r0 = sign-extended 0xFFFFA825; with GBR=E4AC the 32-bit wrapped effective address is 0xFFFFA825+0x0000E4AC = **0x8CD3** (derived arithmetic, not symbol-annotated) — i.e. **ROM[0x8CD3].bit1**, the same gate byte used by `sub_4410E`. - **Bit-7 verdict for this family:** bit 7 is a separately staged flag that is OR'd into the staged bytes (mode 1) or carried raw (mode 2). No independent bit-7-only consumer exists; no target-side evidence links bit 7 to knock detection. **"Knock window" naming is unsupported.**
