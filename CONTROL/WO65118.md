## Method (as implemented)

1. Parsed concordant listing CODE lines; verified raw bytes at every cited PC against the ROM. **PC concordance 306,688 / 306,688.**
2. Recomputed function extents and per-function GBR internally: local `ldc` only, short pool annotations read from actual ROM bytes, dominance-lite branch/label invalidation, `ldc.l @r15+,gbr` treated as caller restore. A function with 0 or >1 distinct provable GBR gets no GBR attribution.
3. For every RAM memory operand (`@(disp,GBR)`, `@(r0,GBR)`, `@(disp,Rn)`, `@(r0,Rn)`, `@Rn`, `@(disp,PC)` pool form), resolved base and index from provable straight-line sources; `address = (base + offset) mod 2^32`; emitted only `>= FFFF0000`. Width scaling b=1, w=2, l=4 for raw displacements; symbolic `label ± h'..` expressions evaluated as byte displacements.
4. Derived direction from operand position/mnemonic. Derived bit metadata from immediate bit forms: `and.b #imm,@mem` → `cleared` / `~imm & 0xFF`; `or.b` → `set` / `imm`; `xor.b` → `toggled` / `imm`; `tst #imm,@mem` / `tst.b` → `tested` / `imm`. `and/or/xor/tst #imm,Rn` immediately after a provable RAM byte load into `Rn`, in the same straight-line region, appends `bit_<action>=h'<mask>@<pc>` to that RAM row's `note`. Register provenance invalidated on any write to `Rn`, any branch-target entry, or any call/return boundary. `tst #imm` sets T when the bit is **clear**; polarity recorded, never applied to infer semantics.
5. Deduplicated identical rows; every operand whose base, index or displacement could not be proven produced one unresolved row. Nothing emitted as address zero.

## Limits / unverified (explicit)

- **L1** Computed pointers, pointer tables, block-copy loops and `movca.l` transport are not modelled; such sites appear in the unresolved file.
- **L2** Straight-line dominance-lite provenance can miss a base defined in a predecessor basic block reached by a non-dominating branch, and can over-accept a value whose defining `mov.w` annotation is partial. Unresolved counts are therefore conservative, not exhaustive.
- **L3** Bit-modifying memory forms (`and.b #imm,@mem`, `or.b`, `xor.b`) are emitted with `access=read` because the underlying instruction both reads and writes; the RMW nature is carried in `bit_action`/`bit_mask`. No separate `rmw` value is emitted. `and` without `.b` is 32-bit; the recorded mask is the low-byte projection, appropriate for the byte-flag use cases in the index.
- **L4** Register-based bit annotations require the load and the bit operation to share a straight-line region; chains separated by calls or non-dominating labels may not be annotated even though the address row is present.
- **L5** Rows are **structural access facts only** — no semantic, physical or unit naming, no claim that a tested bit means a particular state. The register's "branch-only / not independently reproduced" note applies to this package until coordinator audit.
