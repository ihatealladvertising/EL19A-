## 1. The producer — byte-verified store at `0x6F884`

Critical bytes re-verified in this WO (function `sub_6F69E`, LST `loc_6F69E`; prologue sets GBR=`FFFF2150` / r11=`FFFF2150`):

| PC | Instruction | Effect |
|---|---|---|
| `0x6F79A` | `mov.w word_6F8B4, r0 ; h'796` | offset `0x796` |
| `0x6F79C` | `mov.w @(r0,r11), r7` (r11=`FFFF2150`) | blend weight `W = UWORD[FFFF2150+0x796] = UWORD[FFFF28E6]` |
| `0x6F866` | `mov.w r0, @(h'134,gbr)` | intermediate `FFFF23B8` staging (GBR=`FFFF2150`) |
| `0x6F868-0x6F876` | `0x2D7=727` × r6, `+0x49=73`, `sub_21AC0` divide | final transform |
| `0x6F878-0x6F880` | `cmp/hi r12,r0` + saturate to r12 (`0xFFFF`) | cap to UWORD |
| `0x6F882` | `mov.l off_6F8E8, r2 ; h'FFFF1000` | base register r2 = `FFFF1000` |
| `0x6F884` | `mov.w r6, @r2` | **`UWORD[FFFF1000] = r6`** |

So the final value is `min((r6 × 727 + 73) / 800, 0xFFFF)` where `r6` is the clamped/selected output of the preceding cascade. `r6` is not modified between its formation and the store (delay-slot `mov r2,r6` at `0x6F880` is the only assignment).
