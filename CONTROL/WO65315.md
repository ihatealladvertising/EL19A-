1. Read only 64811000p2_m.a2l if present in the authorized workspace; if absent, report unavailable and stop.
2. Extract MAP and CURVE characteristics whose symbol or description indicates base fuel schedule maps, injector duration/latency curves, fuel multiplier/K-value maps, target A/F or lambda maps, warm-up/coolant enrichment curves, transient enrichment curves, MAF/airflow/load maps, fuel trim maps, or cylinder fuel correction maps.

4. Resolve referenced COMPU_METHOD blocks and axis descriptions only; do not transfer conversions to EL19A.
