## 2. X axis — domain identity proven

- Axis `0x0F6F2` is 16 × U16 with maximum **727** (WO65323 §3.3).
- `FFFF1000` is produced (WO65305 §2 step 6) as `min((r6 × 0x2D7 + 0x49) / 0x320, 0xFFFF)` where `0x2D7 = 727` and `0x320 = 800`, and `r6` is itself clamped to `0x320` (`0x6F866`).
- Therefore `FFFF1000 ∈ [0, 727]` **by construction**, exactly the axis range: the axis is a rescaled image of the same quantity the query carries (`0..800 → 0..727`).

Interpretation: the axis and the query are in the **same, self-consistent unit**; interpolation is in raw counts of that unit. The donor's `×0.125 %` reading would make `0..800` equal `0..100 %` — the `0x320 = 800` ceiling is consistent with `100 % × 8`, but **no instruction in the path applies an explicit ×8 or /8**, so the physical unit remains a hypothesis rather than a decoding.

**Verdict X: hypothesis consistent, not proven.** Confidence: domain identity **HIGH**; physical unit **LOW**.
