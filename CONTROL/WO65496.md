## Objective

WO65484 proved the X axis of the 16×16 UWORD cluster is the `FFFF1000` domain (max 727) but could not test the Y-axis convention because the Y query cell `FFFF84FE` has **no writer in the RAM index**. Find its producer, or prove that none exists in the reachable code, and determine the numeric domain of the Y axis (`0x1133A`, raw 0–2550).

## Mandatory falsifiable hypothesis

- **Identity layer advanced:** input identity (Y axis).
- **Hypothesis:** `FFFF84FE` is written by a routine whose arithmetic yields an RPM-domain value consistent with the axis's 0–2550 span (donor convention: 3.125 rpm/count → 7969 rpm).
- **Evidence:** WO65484 §1 (call convention, Y query at `0x66E14`/`0x67DB4`), WO65484 §3 (twelve read sites, zero writes in `WO65118`).
- **Prediction:** a bounded scan for `FFFF84D4`-based writes with displacement `0x2A` (and the `FFFF84FE` literal form) will find one or a few writers; their transforms will either contain an RPM-scaled lineage (`×25/8`, `>>3`) or terminate in an unrelated internal count.
- **Cheap discriminator:** scan the LST for `@(h'2A,` word stores against a base loaded with `FFFF84D4` or `FFFF84C8`, plus the literal `FFFF84FE`; decode at most three writers.
- **Information gain:** decides whether the UWORD cluster's Y axis can ever be given rpm units, which is the last blocker on labelling that whole family's axes in the RR definition.
- **Result:** to be recorded on closeout.

## Scope

1. Bounded LST scan for writers of `FFFF84FE`: base-relative word stores with displacement `0x2A` against bases loaded as `FFFF84D4`/`FFFF84C8`, plus any literal `FFFF84FE` reference or `mov.l`-based store.
2. Report the writer count. If more than three, stop and report the set size rather than tracing all.
3. Decode up to three writers: PC, routine (GBR), gate, transform, inputs, and the numeric range the transform can produce.
4. Compare the produced range with axis `0x1133A` (0–2550) and with the donor `×3.125 rpm` reading; state supported / contradicted / undetermined.
5. Stop at the first ADC/CAN/peripheral read or indirect dispatcher.

## Required deliverable

- Writer table for `FFFF84FE` (PC, routine, transform, input lineage, output range).
- A verdict on the Y-axis unit with separate confidence for domain and physical meaning.
- RR disposition (may the Y axis carry a note, or must it stay raw?).
- Exact unresolved boundary, reused evidence and no-repeat list.
