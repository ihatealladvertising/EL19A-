### Helper mechanics

`sub_22E10` uses threshold `0xF0`:
- If query `q >= 0xF0`, returns element 15 directly through the `0x22E1E/0x22E20` return path.
- If `q < 0xF0`, jumps to `loc_2350C`; four shift/rotate pairs derive the interval index and fractional nibble. The byte branch at `0x23532–0x2353A` reads adjacent points `table[index]` and `table[index+1]`; `sub_231C8` interpolates.
- No ROM axis pointer is passed. The implicit grid is `0,16,32,…,224`; the high query range clamps to the final entry.

The query cell `FFFF84B8` is also used by prior coolant-temperature processing findings, but this WO does not infer a physical fuel/cranking strategy from that shared input alone.
