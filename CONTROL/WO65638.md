| Item | Record |

| Comparand | `r5=0xFF` from `mov #-1` + `extu.b`. |
| Word-derived candidate | `U16[FFFF85CE] >> 5` before the compare. |
| `bf` condition | taken for `candidate <= 0xFF`; not taken for `candidate > 0xFF` under the conventional `cmp/hi r5,r6` polarity. |
| Delay slot | `0x34792 mov r5,r6` always executes before control resumes, whether the branch is taken or not. |
| Target geometry | `loc_34794 = 0x34794`, the instruction directly after the delay slot; both outcomes physically converge there. |

The branch is therefore redundant with respect to the stored value.
