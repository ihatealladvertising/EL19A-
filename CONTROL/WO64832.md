## Stage 3 — TEST results (EL19A; verified 2026-11-16)

### Query provenance
- Both readers consume UBYTE `FFFF85A9`, which is mirrored from source byte `FFFF85D1` by the `FFFF85C4 → FFFF859C` block copy (`0x20F06`).
- `sub_346E0` at `0x346E0` reads UWORD `FFFF85C4+0x0A = FFFF85CE`, zero-extends it, shifts right four, clamps to `0xFF`, returns the byte in its RTS delay slot and stores it to `FFFF85C4+0x0D = FFFF85D1` (`0x346E6–0x346F8`).
- Caller `0x3477C` invokes `sub_346E0`; thus the exact transform is:
  `FFFF85A9 = min(UWORD[FFFF85CE] >> 4, 255)`.
- `FFFF85CE` is therefore the immediate query source; its upstream writer/physical units remain unresolved. The bounded earlier CP12 audit found no writer in the known `sub_3459C` / `sub_257AC` structure paths and rejected false-positive stores with a different base. Do not reopen a global RAM scan without a new lead.

### Path selection and table arithmetic
- F3D6 path: `sub_65730` sets GBR=`FFFF9862`. At `0x6582E–0x6583E`, `FFFF99E7.bit3 SET` selects F3D6/F3C6; clear bypasses the table and uses the non-table path. The result is `13 × interpolant), clamped between `4×UWORD[FFFF9866]` and `4×UWORD[FFFF9868]`, then stored initially at `FFFF2150+0xA88 = FFFF2BD8`. The two dynamic bound words' upstream producers were not established in this bounded trace.
- F3DE path: at `0x68200–0x6822E`, `FFFF99E7.bit3 SET` selects F3DE/F3CE; clear bypasses the table path. The interpolant is multiplied by 13 and clamped to `908..2908`; the bounds are ROM UWORDs `0x1172C=0x00E3` and `0x1172E=0x02D7`, each multiplied by four. Initial result is stored at `FFFF2150+0xA8A = FFFF2BDA`.
- The F3D6/F3DE routines contain additional upstream path conditions (including `FFFF1E6E` bits and `FFFF3614/FFFF860B` state); keep these as target gates, not donor operating-mode labels.
- Donor conversions `raw × 0.3575°` and `axis raw × 25 RPM` are not executed in either traced target path. The target reader uses target axis bytes and raw UBYTE query directly; query units are unproven.

### Downstream decision / furthest endpoint
- F3D6 post-processing writes UWORD `FFFF33EA`; F3DE post-processing writes UWORD `FFFF2C92` (via the `FFFF2C90/2C92` result pair).
- `sub_810A0` computes `abs(UWORD[FFFF33EA] - UWORD[FFFF2C92])`.
- Caller `loc_81048` passes the full difference to `sub_810BC`; the BSR delay slot places the full value in R5, while R4 carries its low byte. When `low_byte(diff) != 0` and `diff > 0x5C`, the code checks internal status `FFFF39A7`; if clear it calls `sub_71F74` with event/service argument `0x4E`. Otherwise the non-trigger path stores `0x14` to `FFFF39A7`.
- `sub_810E8` stores the full difference to UWORD `FFFF2150+0x2D6 = FFFF2426` when the low byte is nonzero.
- `sub_71F74` is a generic record/callback dispatcher using GBR=`FFFFA074`; the inspected path dispatches to internal helper routines (`sub_72480/sub_72676)). No hardware register, actuator driver or external throttle command is shown.
