## Answer in one paragraph

`U16[FFFF246C]` (= `FFFF2150+0x31C`) has **exactly four resolved accesses**: two zero writers in the band-reset clusters (`0x0A08F6` with base `r11`, `0x0A5420` with base `r13`, both `r2 = IVECT1 = 0`), the producer's saturation store `0x0A671C` (`mov.w r2,@(r0,r13)`, `r13 = FFFF2150`), and **one reader — `0x0A672C` `mov.w @(r0,r13),r2`, inside the producer routine itself**. Every other `0x31C` site in the ROM resolves to a different base (`FFFF1054+0x31C = FFFF1370`, `FFFF2F00+0x31C = FFFF321C`, `FFFF8E54+0x31C = FFFF9170`), so the displacement is generic like `h'AA` and `h'328`, and no absolute literal to `FFFF246C` exists anywhere. The reader is a gate: when the term is **positive** and `U16[FFFF2474] < 100` and `UBYTE[FFFF3563].bit5` is set, the routine calls `sub_A091A`, which clears `FFFF3519.bit2`, `FFFF3564.bit0`, `FFFF3563.bit2`/`.bit1`, calls the mass-clear `sub_A0690`, and **sets `FFFF34B5.bit5`**. So the `FFFF2150` measurement sub-band is not dead internal state: its single sink qualifies a **status/limit reset action**. It still reaches no actuator, no MMIO and no calibration query.

`sub_A0690` (gbr = `FFFF34C1`, `r11 = FFFF2150`, `r9 = FFFF38DF`, `r10 = FFFF371E`) is a **mass status-bit clear sweep**: it zeroes `FFFF2150+0x222` (byte) and `FFFF2150+0x79C` (word) at `0x0A06BE`/`0x0A06C4` and then clears a long run of `FFFF34C1+NN` flags with `and.b #mask,@(r0,gbr)` from `0x0A06A8` onward.

`FFFF34B5.bit5` is the aggregate "condition detected" publication bit characterised by WO65898 (24 setters across `0x09C00C`–`0x0A5430`, read as `tst #h'20` at `0x08B31A`, aggregated into `FFFF3579.bit4` by the six-conjunct accumulator in `sub_7E8B2`). `0x0A093C` is a further setter of that bit, consistent with WO65898's census range; `0x0A5430` is the other one in the same family.

## 4. Classification

- **`NAMED OUTPUT`? No.** The chain reaches only status bytes (`FFFF3519`, `FFFF3563`, `FFFF3564`, `FFFF34B5`) and two cleared `FFFF2150` fields. No MMIO register, lamp, diagnostic frame or actuator store is touched.
- **`CALIBRATION QUERY INPUT`? No.** No lookup helper is called on this path; the only ROM reads are the two scalar thresholds `0x904E` and `0x97E0`, both used as direct comparisons and neither a table or axis.
- **`INTERNAL STATE` — with a real action.** The classification is `INTERNAL STATE (status/limit reset qualification)`: the term does not merely accumulate, it gates a status-block clear plus the `FFFF34B5.bit5` latch.
- **Identity layer advanced: output identity.** WO65913 stopped at the store; this closes the sink and shows the `FFFF2150` measurement sub-band drives a *control action* (reset/latch), not just more status bits. It does not advance input or function identity, and it establishes no calibration object.
