2. **DATA-line literal scan** for any `h'` value in either range: 0 hits for DTC; 1 hit for CID (`h'147AE` in `dword_98E8` at ROM `0x98EC`).
3. **dword_13780 pointer table** (198 entries × 4 bytes at `0x13780`): all entries fall in `0x113CC–0x116F4`; 0 entries in DTC or CID ranges.
4. **Boundary-address scan** for `0x12E40/0x12E44/0x1377F/0x13780/0x14660/0x14664/0x148A3/0x148A4`: `0x13780` has 30 CODE + 17 DATA references (all to the pointer table, not DTC records); `0x148A4` has 1 CODE reference (`sub_319EC` at `0x319F6`).
5. **dword_98E8 reference** (`0x147AE` at `0x98EC`): code at `0x98758`/`0x9881E`/`0x988DE` accesses this structure via GBR=`0x9860` at offsets `0x98/0x9A/0x9C/0x9E/0xA0/0xA2` (words at `0x98F8`, `0x98FA`, `0x98FC`, `0x98FE`, `0x9900`, `0x9902`), none of which is `0x147AE` (at `0x98EC`, offset `0x8C` from GBR). The value `0x147AE` is not dereferenced as a pointer.
6. **sub_319EC / 0x148A4 reference**: calls `sub_2245C` (byte-copy helper) with `r2=0x148A4`, `r0=9`, copying 9 bytes from the post-CID adjacent structure (`0x148A4`, i.e. `dword_14658+0x24C`) to the stack. This reads the mixed structure after the CID table, not CID records themselves (per WO65090 §C, adjacent bytes excluded from the 144-record run).

## 4. Result

No computed or indirect consumer path is statically provable for either the DTC or CID record ranges:

- **DTC (`0x12E44–0x1377F`)**: zero references (CODE or DATA) to any address in the range except the already-classified numeric literal at `0x70650`. The adjacent `dword_13780` pointer table (198 entries) points to `0x113CC–0x116F4`, none into the DTC block.
- **CID (`0x14664–0x148A3`)**: zero CODE references. The single DATA reference (`0x147AE` in `dword_98E8`) is not dereferenced as a pointer. The only CODE reference to the table boundary (`0x148A4`) copies post-table bytes, not CID records.

Block-copy helpers (per WO65103 census) do not source from either range. GBR-relative or computed-pointer paths into these ranges are not evidenced.

## 5. Conclusion

Bounded negative: no indirect/computed consumer of DTC or CID records established. Consistent with WO65077 (direct-literal negative) and WO65090 (extraction only, no reader). The records remain structurally extracted but unattached to any code path.
