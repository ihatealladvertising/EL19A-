- **Observed:** 144 CID-like U16 values in a fixed 4-byte table.
- **Observed:** each record has constant raw bytes `0x00` and `0xFF` after the U16 value.
- **Not established:** that `0x00` is a supmask, a mask, reserved data, an index, or a flag.
- **Not established:** that `0xFF` is a terminator or type marker.
- **Not established:** 11 Supmask records or exact CID-to-mask pairs.
