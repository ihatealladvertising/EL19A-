# WO65005 — 32-Point UWORD Pair: 10EEA/1100A and 10F2A/1104A

- **Status:** COMPLETE — paired caller/axis contracts resolved; prior provisional table/axis roles corrected
- **Issued / closed:** 2026-11-16
- **Scope:** Resolve the direct sub_22FAC caller contract for the two paired 32-point UWORD surfaces in sub_68A86; establish data/axis roles, query preparation, helper mechanics and immediate output. No semantic naming.
- **ROM:** EL19A f501.bin, 1 MiB, MD5 46991697c502052752a2cabcb84c9e27, SH7058 / SH705822N, FID 8CMCKRN5.
- **Source:** EL19A_Complete_Disassembly_ANNOTATED_V3_NEXT6_16_ALL_PENDING_ANNOTATIONS.lst (Library ID file_00000000fc2c820eb592f21d9c27911c).

## Confirmed evidence

### Helper contract

- sub_22FAC at 0x22FAC saves incoming R4, copies incoming R5 to R0, zero-extends incoming R6 into R5, and calls sub_2340C.
- Its delay slot sets R4=0x3E, the final byte offset for 32 UWORD breakpoints. Thus sub_2340C receives:
  - R0 = axis pointer (original caller R5)
  - R4 = 0x3E maximum byte offset
  - R5 = zero-extended UWORD query (original caller R6)
- After the axis search, sub_22FAC restores the saved caller R4 as the table-data pointer, loads adjacent UWORD samples and calls sub_231C8 for interpolation.
- Therefore caller contract is **R4=data base, R5=axis base, R6=query**. Both arrays are 32-point UWORD big-endian; axis comparisons are unsigned/raw, with no ×4/×16 transform in this wrapper.

### Paired caller in sub_68A86

- At 0x68A88, R5 is loaded with 0x10EEA; at 0x68A8E, the caller reads the final axis word at offset 0x3E. Query is the U32 value loaded from FFFF1054+0x52C at 0x68A94.
- If the query is not above that final breakpoint, it is capped to UWORD 0xFFFF and the first lookup at 0x68AA8 uses:
  - R4 = 0x1100A (32-point data)
  - R5 = 0x10EEA (32-point axis)
  - R6 = capped original query
- If the query is above the first axis's final breakpoint, the caller shifts it right four bits (two shlr2 operations), caps it to UWORD, and the second lookup at 0x68ACA uses:
  - R4 = 0x1104A (32-point data)
  - R5 = 0x10F2A (32-point axis)
  - R6 = shifted/capped query
- Both branches stage the returned UWORD at FFFF1054+0x5C4 (0x68AB4 / 0x68AD4).

### Axis boundary observation

- The LST data stream at 0x10EEA begins 7E7A, 0000, 01F7, 03EF, ... and continues through 76FC at the final word. The leading 7E7A is an irregular high first entry; do not silently reorder or discard it. The remaining sequence from index 1 through index 31 is increasing.
- The second axis pointer 0x10F2A is likewise passed directly as the axis argument. Its leading entries in the LST stream are B083, 0B08, 0B39, ...; preserve the leading entry as observed. This WO does not assign a semantic meaning to either leading value.
- Data extents implied by the helper's 0x3E endpoint: 0x1100A–0x11049 and 0x1104A–0x11089, each 32 UWORD big-endian samples. Axis extents: 0x10EEA–0x10F29 and 0x10F2A–0x10F69, each 32 UWORD big-endian breakpoints.

## Disposition

- **Confirmed role correction:** 10EEA and 10F2A are the axis pointers in these calls; 1100A and 1104A are the table-data pointers. This reverses the provisional role assignment in the earlier candidate note; do not carry forward the old table/axis orientation.
- **Confirmed lookup behavior:** 32-point UWORD axis search through sub_2340C, followed by adjacent-sample interpolation through sub_231C8; raw unsigned axis values.
- **Confirmed query branches:** original U32 query from FFFF1054+0x52C capped to UWORD for the first pair; if above the first axis's final breakpoint, query is shifted right 4 and capped for the second pair.
- **Confirmed output:** both branches write the result to FFFF1054+0x5C4.
- **Unresolved:** physical axis units, calibration semantics, provenance/meaning of the U32 query, and downstream interpretation of the shared output.
- No semantic or donor-symbol promotion. No workbook, XML, ROM, IDB, LST, script or Library changes.
- **Stop boundary:** caller/axis contract and immediate result staging only.
