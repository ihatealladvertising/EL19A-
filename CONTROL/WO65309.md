Extract donor A2L RPM/speed-control VALUE characteristics and distinguish actual limit thresholds from speed-reference ramp coefficients and related control parameters.

## Scope

1. Read only 64811000p2_m.a2l if available in the authorized workspace; if missing, record the missing source and stop.
2. Search symbol and description fields for engine-speed limit/cut/recovery, vehicle-speed limit, gear/reverse/neutral limit, speed reference, acceleration/deceleration gradient, target speed, rev limiter and fuel-cut restore.
3. Preserve characteristic type, symbol, description, donor address, storage width/signedness, COMPU_METHOD, units, min/max, record layout and any state/selector metadata.
4. Explicitly classify mCRURFVAG, mCRURFVDG, mCRUSPAG and mCRUSPDG as speed-reference ramp candidates unless the A2L itself establishes a limiter role; do not mislabel them as RPM/speed cut thresholds.
5. Deliver exact metadata and ambiguity notes; no target matching by address/order.
