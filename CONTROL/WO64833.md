## Stage 3 — TEST (EL19A target)

### Existing target evidence / do not repeat

- `EFA4` is a 16-byte UBYTE candidate:
  `00 03 0F 1D 28 34 41 4A 55 6A 79 85 92 9C A2 A6`.
- The target passes EFA4 to `sub_22E10` at approximately `0x40742`.
- `sub_22E10` uses an implicit 16-count query grid and returns sentinel `0xF0` for query `q >= 0xF0`; no external axis pointer is supplied.
- The lookup result is stored at `FFFF13EA). `sub_4110C` reads it, multiplies it by four and incorporates it into a compare/select calculation contributing to a UWORD at `FFFF1014).
- Current semantic assessment is low confidence; no physical throttle command or actuator endpoint is established.

### New work

1. Reconstruct the exact query expression/source supplied to EFA4, including width, signedness, scaling, clamping and out-of-range handling. Determine whether its 16-count implicit grid has any target-proven relationship to 400 RPM; do not assume 25 RPM/count.
2. Check all credible competing EL19A 16-point UBYTE candidates in the same bounded candidate inventory, not a ROM-wide blind scan. Compare exact dimensions, byte payload, axis model, query mechanics and reader callsites.
3. Confirm the full downstream expression from `FFFF13EA` through `sub_4110C` to `FFFF1014`, and follow direct consumers only far enough to establish whether the output is a threshold, factor, state, target or actuator input.
4. Check whether the target code applies anything equivalent to raw ×0.35. If it does not, record that as a conversion contradiction for semantic equivalence, even if structure remains compatible.
5. If donor raw data is later made available, compare the exact 16-byte payload; otherwise leave raw-data equality untested.
