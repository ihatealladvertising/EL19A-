## Stage 2 — CONFIGURE (theoretical prediction)

Expected reference object:

A useful target structural fingerprint is therefore: 16 consecutive UBYTE samples, plausible curve morphology, and a query that can be mapped to a 400-RPM grid. A 16-point count alone is weak evidence.

## Competing target candidates checked (bounded inventory)

- E678 and E688 are also 16-point UBYTE readers in the same `sub_403D8` routine, but each contains `00 12 12 12 2F 2F 2F 19 03 00 00 00 00 00 00 00`; they are different objects from EFA4 and have their own QDSPT-family hypotheses.

- No other 16-point UBYTE member is present in the bounded GitHub candidate register supplied for this WO. This is a bounded comparison, not a ROM-wide candidate census.

## Query and behaviour reconciliation

- EFA4 query: `q = min(UWORD[FFFF85AE] >> 1, 255)`. `FFFF85AE` is timer-capture-derived through `FFFF85E4 → FFFF8596 → (>>6) FFFF85D6 → block copy`; its engine-RPM identity is not proven.
- The target reader uses an implicit q grid at raw 16-count intervals; no separate fixed RPM axis pointer is passed. A mapping to the donor fixed `0..6000 RPM / 400 RPM` axis would require an unproven target query-to-RPM conversion.
- Target code does not apply donor `raw × 0.35°` to EFA4. The UBYTE result is stored at `FFFF13EA`, read by `sub_4110C`, multiplied by four, and contributes to an internal compare/select calculation and UWORD `FFFF1014`.
- `FFFF1014` flows to internal derived values including `FFFF2742` and `FFFF10CA`; later calculations produce `FFFF10CC`, `FFFF1736`, `FFFF1630` and `FFFF1632`. No terminal VAPO angle output, physical throttle command or actuator endpoint is established.
