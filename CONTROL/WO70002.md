## Verified Disassembly & Structural Findings

1. **Exact `sub_BE352` (`0xBE740–0xBE7F0`) ROM Checksums Bit-Verified:**
   - Algorithm sums/XORs big-endian 32-bit words across `0x08200..0xFFFFF`, skipping addresses `{0x08200, 0x099DC, 0x099E4, 0x20000}`.
   - `EL19A`: `XOR = 0x4A7ADC08` stored at `0x099DC` (exact match), `ADD = 0x73560FFE` stored at `0x099E4` (exact match).
   - `EL13A`: `XOR = 0xDC572991` stored at `0x099DC` (exact match), `ADD = 0xED0DDFB3` stored at `0x099E4` (exact match).
2. **Master Variant Option Byte `0x08CD3` (`107` CODE Loads):**
   - `EL19A = 0x80` (`bit 7 = 1`, `bit 3 = 0`, `bit 2 = 0`) vs `EL13A = 0x0C` (`bit 7 = 0`, `bit 3 = 1`, `bit 2 = 1`).
   - Across `107` CODE pool loads (`mov.l -> @Rm`), `74` test `bit 7 (0x80)`, `5` test `0x10`, `1` tests `0x08`, `1` tests `0x14`, and `26` load unmasked/multi-mask.
   - **Lead / Hypothesis (needs deeper subroutine trace):** Consistent with MT (`bit 7` on `EL19A`) vs CVT/AT (`bits 3,2` on `EL13A`) hardware/strategy configuration gating.
3. **Paired `5x9` Variant Matrices (`0x099F0` / `0x09A1D` + `0x0B6A2` / `0x0B6FC`) & `11x4B` Slot Table (`0x09A66`):**
   - `0x099F0` & `0x09A1D` (`5x9` UBYTE gates) pair with `0x0B6A2` & `0x0B6FC` (`5x9` UWORD_BE, `180B` total) across `sub_6664A`, `sub_664B2`, and `sub_28C36`. In `EL13A`, only index slot `3` (`+` row2 `0x8000`) is populated, whereas `EL19A` populates multiple slots (`0xDAA2..0xD769`). *(Hypothesis: multi-gear MT map selection vs single CVT D-range slot.)*
   - `0x09A66..0x09A91` (`11x4B`, `sub_841C8`): 3 of 11 descriptor slots (`0x09A66`, `0x09A6A`, `0x09A8E`) are disabled (`05 00 00 00`) in `EL19A` and active (`01 08 4A 20`, `01 08 4A 60`, `03 08 47 C0`) in `EL13A`.
4. **Dual-Path Normal <-> Trustful Symmetry Confirmed Across Newly Discovered Objects:**
   - Existing `Cat179` 16x16 twins (`0x0D456`/`0x121C4` diff `403/512B`, `0x0D656`/`0x123C4` diff `399/512B`) and their axes (`0x0F6F2`/`0x128DE` diff `19/32B`, `0x1133A`/`0x12E18` diff `19/32B`) move in lockstep.
   - Uncatalogued 16x1 axis trio `0x10CC2` / `0x12A4E` / `0x12D18` (`sub_6F5E8` `sub_22F80` & `sub_6F8EC` `sub_23170`, diff `13/32B`) moves identically in lockstep with `0x10CE2` / `0x12A6E` / `0x12D38` (`14/32B`).
   - Three Normal <-> Trustful scalar/pair constants also move in exact lockstep: `0x091EE` <-> `0x113C4` (`01 5E 02 FC` -> `00 00 00 00`), `0x095A6`+`0x095B4` <-> `0x11714` (`0F A7 03 15` -> `0C 04 02 A7`), and `0x0971A` <-> `0x11722` (`2D 42` -> `2E D6`).
5. **Catalog-179 Axis Metadata Defects Surfaced During Overlap Checks:**
