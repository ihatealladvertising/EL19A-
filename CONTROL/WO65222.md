## Objective

Resolve the hardware source, timer channel and clock basis of the capture-derived delta consumed as UDWORD `FFFF14E0` and transformed into `FFFF85E4`. Determine whether the observed reciprocal chain can defensibly be classified as engine speed, vehicle speed, another event rate, or only an unscaled period index. Do not infer RPM from the 48 MHz numerator or donor axes.

## Evidence to reuse

- `CONTROL/WO65092.md`: exact software chain `FFFF85E4 → 48,000,000 / FFFF85E4 → FFFF8596 → FFFF85CE`; `FFFF85E4` is built from a counter difference shifted right five, with branch-dependent correction and invalid marker `0xFFFFFFFF`.
- `CONTROL/WO65181.md`: F3D6/F3DE query is `min(UWORD[FFFF8596] >> 7,255)); first-stage outputs enter `0x0F712` and `0x128FE) internal lookup paths. Physical units and actuator endpoint unresolved.
- `CONTROL/WO65104.md`: prior timer/interrupt audit. It found Timer11B→Timer5→Timer11→APC pulse-control activity, but explicitly did **not** establish `FFFF85E4` as ICR0A/TCNT0; the known ICR0A handler writes `FFFF1A64`, not `FFFF14E0`.
- `CONTROL/WO65106.md`: verified Timer11/Timer5 hardware interrupt and compare paths; use only to distinguish already-established pulse-control scheduling from the capture source.
- `CONTROL/WO65116.md`–`WO65122.md`: existing vector, function/GBR, effective-address, RAM byte/bit and call-graph indexes.

## Scope

1. Start at the exact `FFFF14E0` read feeding the `0x257AC` difference construction documented in WO65092. Identify every verified writer or source-copy path using existing indexes first.
2. Trace the source to the first genuine SH7058 timer/capture register, input-capture interrupt, peripheral event or externally populated record. Distinguish timer counter reads from capture-latch reads and software timestamps.
3. Establish timer channel, counter width, prescaler/divider, clock source and relevant initialization bits only where directly visible in target code or authoritative device documentation.
4. Determine whether the captured event can be associated with crank, cam, vehicle-speed or another input. Require a concrete pin/interrupt/decoder path; a timer channel name or reciprocal constant alone is insufficient.
5. Reconcile the result with the already verified Timer11/Timer5 APC scheduling chain. Do not conflate the independent pulse-output timers with the `FFFF14E0` capture source absent a direct dataflow edge.
6. State what the 48,000,000 numerator can and cannot establish after the timer clock/divider evidence is known.
