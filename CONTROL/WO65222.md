## Investigation — exact read site

`sub_257AC` at PC `0x257CC`: `mov.l @(r0,r6), r4` where `r6 = h'FFFF1054` (loaded from `off_25800` at `0x257C8`) and `r0 = h'48C` (loaded from `word_257F4` at `0x257CA`). Effective address: `FFFF1054 + 0x48C = FFFF14E0`. This is the UDWORD read feeding the difference construction documented in WO65092. The same read repeats at `0x257EA` to refresh `FFFF8650` with the current value.

## Writer search — exhaustive, negative

1. **Direct address search:** Full-listing search for `FFF14E0` as a code address yields exactly two references: the annotation comment at line 32929 and the RAM-map declaration at line 444957. No instruction references `FFFF14E0` as a store destination.
2. **WO65117 effective-address dictionary:** No entry resolves `FFFF14E0` as a write target (all register-base and GBR+offset writes checked; 45,105 unresolved EAs not individually re-derived, but no resolved path targets this cell).
3. **WO65118 RAM byte/bit xref:** No row lists `FFFF14E0`–`FFFF14E3` as a write target.
4. **WO65103 transport graph:** No DMA, DTC, or `movca.l` configured. Block-copy constructs do not reach `FFFF14xx`.
5. **RAM-map declaration:** `FFFF14E0`–`FFFF14FF` declared `.res.b 1 UNDEFINED` at listing lines 444957–444988 — zero-initialized RAM with no initializer and no code writer.

## Triggering context (readers only)

`sub_257AC` is invoked from `sub_2088C` at `0x208A6`, which is called from two interrupt handlers:
- `INT_ATU02_ICI0A @ 0x268E0`
- `INT_ATU12_IMI1AE @ 0x276A8`

Neither interrupt handler writes `FFFF14E0`. Per WO65104, the known ICR0A input-capture handler stores to `FFFF1A64`, not `FFFF14E0`. Per WO65106, Timer11/Timer5 APC pulse-control paths do not target `FFFF14E0`.

## Timer/provenance findings

- **No software writer** to `FFFF14E0` exists in the ROM. The cell is read as UDWORD but never written by any instruction.
- **No timer channel, counter width, prescaler, divider, or clock source** can be established from static code analysis. No timer configuration code targets this address.
- **No pin/interrupt/decoder path** can be associated with crank, cam, vehicle-speed, or any other event. The capture source is outside code visibility — either hardware-maintained (not reflected in the disassembly) or the value is indeterminate from static analysis.
- **Timer11/Timer5 APC chain** (WO65104/WO65106) is independent: no dataflow edge connects those pulse-output timers to `FFFF14E0`.

## 48,000,000 numerator

The numerator `48,000,000` in `48,000,000 / FFFF85E4` (WO65092) cannot establish RPM, vehicle speed, or any physical unit. Without a proven timer clock frequency, counter width, prescaler, or event identity, the quotient is an unscaled period-derived software coordinate only.
