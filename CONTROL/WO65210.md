## Established reader mechanics (LST evidence)

### `sub_403D8` lookup paths

- `sub_403D8` contains three 16-point UBYTE lookup paths via `sub_22E10` for ROM tables `0xE688`, `0xE678`, and `0xEFA4` (LST 102433/102438 annotations).
- E688 path: `D4 52 mov.l off_4060C,r4 ; h'E688` at `0x404C2`, `jsr @r2 ; sub_22E10` at `0x404C6` with `r5` extu.b query (LST 102585–102589). Annotation: “Passes ROM table E688 to sub_22E10; accessed as 16 UBYTE elements in this call path.”
- E678 path: `D4 41 mov.l off_40618,r4 ; h'E678` at `0x40512`, `jsr @r2 ; sub_22E10` at `0x40516` with `r5` extu.b query (LST 102652–102656). Annotation: “Passes ROM table E678 to sub_22E10; accessed as 16 UBYTE elements in this call path.”
- Both results are scaled with `R11+0x622` byte and stored as UWORD to `R11+0x39C` in their respective branches (LST 102590–102599, 102657–102665). Physical meanings of R11 fields/base remain unresolved.

### `sub_22E10` 16-UBYTE gate/interpolation

- `sub_22E10` (LST 26378): loads `0xF0` gate; `cmp/hs r0,r5; bt locret_22E1E`. If `r5 >= 0xF0`, returns `mov.b @(h'F,r4),r0` (last byte of 16-byte table). Otherwise jumps to `loc_2350C` with `r3=0`.
- `loc_2350C` (LST 27497+): shifts/rotates `r5` to form index/fraction state, computes `r4+index`, then for the byte path loads adjacent bytes: `mov.b @r4,r1; mov.b @(1,r4),r0; extu.b ...` and jumps to `sub_231C8` interpolation helper. This is a 16-point UBYTE table access/interpolation path, not a UWORD table read.
- `sub_231C8` is the endpoint interpolation helper (MUL.L high-word, no rounding; branch differences noted in LST annotation; caller orientation not assumed here).
