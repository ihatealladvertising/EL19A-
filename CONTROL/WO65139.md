## Axis-domain correction

This section corrects the epistemic status of axis-domain claims in the comparison results above. It does not change any disposition; it clarifies what each disposition means.

### Contradicted (axis domain)
- **Axis width mismatch**: E904/E914 use UWORD BE axes (read by `sub_2340C`); pressure donors mTHPAMB/mTRPAMB use UBYTE axes. This width mismatch is decisive and independent of any axis-domain conversion. **Contradicted.**
- **Numeric axis range non-overlap**: E904 raw axis range 10752→24576 and E914 raw axis range 0→51200 do not overlap the V6 mTHOSNTP/RCV converted axis range 0→12799.8046875 (COMP_0434_S). This is a fact about the declared numbers. **Contradicted for raw-number equivalence.**

### Not established (axis domain)
- **EL19A axis domain**: No EL19A axis conversion, label, or physical domain is established for E904, E914, or E934 axes. Whether EL19A axes are RPM-domain, pressure-domain, or any other domain is **not established**.
- **Cross-domain equivalence**: The V6 mTHOSNTP/RCV axis is declared RPM-domain ("25*1/128rpm*ms"). Whether EL19A's axes share this domain, or whether a scale/offset conversion could map EL19A raw values into the V6 converted range, is **not established**. Raw-number range non-overlap therefore does not contradict functional equivalence — it only contradicts direct raw-number equivalence.
- **Axis conversion**: No EL19A axis conversion is proven, so it is **not established** whether EL19A raw axis values could be converted to match the V6 converted axis range.

This correction preserves all original comparison results and dispositions. "Contradicted" applies only to what is directly disproven by declared attributes (axis width, raw numeric ranges); "not established" applies to cross-domain functional equivalence, which remains open pending EL19A axis-domain evidence.
