# WO65023 — Residual ROM-Wide Indirect Call-Table Discovery

- **Status:** ACTIVE
- **Objective:** Test whether the currently known dispatcher inventory is complete by finding additional indirect function-pointer tables in EL19A.
- **Known structures to exclude from duplicate counting:** six `sub_209A6` tables (8/14/7/62/6/3 entries), nine-entry `sub_2088C` table at `0x21A64`, and 122-entry `sub_20DCE` table at `0x2187C`.
- **Inputs:** Current annotated EL19A LST and Xref Index already available in the project workspace/Library. Reuse existing files and scripts; do not recreate or overwrite tools.
- **Tasks:**
  1. Search the disassembly for indirect call/jump forms (including `jsr @rN`, `jmp @rN`, register-indirect calls and equivalent SH-2 forms) and identify enclosing loops that load pointers from ROM/RAM tables.
  2. For each plausible dispatcher, verify pointer-source progression, entry stride, loop count/termination and target decoding. Include literal-pool pointers, GBR/register-base addressing and computed table bases; do not rely on exact-address literal searches alone.
  3. Separate genuine function-pointer dispatch tables from single callbacks, virtual/vector tables, data-pointer arrays, CAN records, lookup tables and indirect calls through a single loaded pointer.
  4. Compare candidates against the three known dispatcher families and report only genuinely additional structures or bounded exclusions.
  5. Check whether any additional tables are reached from interrupt/vector handlers, but do not assume ATU-31 IMI3A or periodic execution.
- **Boundaries:** This is a bounded discovery audit, not proof that every runtime-computed or externally populated dispatch structure is absent. No semantic/task/cadence claims from table size alone. Do not reopen `0x24DC/0x2514` absent new contradictory evidence.
- **Deliverable:** Candidate/confirmed dispatcher inventory with loop PCs, table bounds, counts, target coverage, discovery method and explicit blind spots; state whether any new tables were found.
- **Stop:** All available indirect-call sites in the current LST have been triaged, or a clear input/coverage limitation is reached.
- **Artifact guardrails:** Update this WO and operational register only. No XML, workbook, ROM, LST, IDB, scripts or Library modifications.
- **Communication:** Minimum chat; report only essential evidence, exceptions and next action.
