# WO65031 — Residual Indirect-Transfer Audit, ROM 0x00000–0x3FFFF

- **Status:** ACTIVE
- **Objective:** Structurally classify unresolved register-indirect JSR/JMP sites in the low ROM segment and identify any additional pointer vectors or dispatch families.
- **Target:** EL19A f501.bin, 1 MiB, MD5 `46991697c502052752a2cabcb84c9e27`.
- **Input:** `EL19A_Complete_Disassembly_ANNOTATED_V3_NEXT6_15_V32_WO64794_TIMER11_2026-11-13.lst`; use the existing `EL19A_Xref_Index.csv` only for bounded address/source checks.
- **Initial population:** 65 of the listing's 241 unannotated register-indirect transfers fall in this segment. This includes known sites; remove previously classified sites before reporting residuals.

## Scope / method

1. Enumerate unannotated `JSR @Rn` / `JMP @Rn` in `0x00000–0x3FFFF`.
2. Exclude established structures and sites already classified in WO65021–WO65030 (including known dispatcher loops, callback records, stack-sourced fixed helpers and computed switch jumps).
3. For each remaining site, trace only the call-register's bounded producer chain: local register writes, stack spill/reload, literal pointer loads, indexed longword loads and any direct xref evidence.
4. Group repeated call sites sharing one producer/descriptor mechanism. Record exact PCs, register, source address/expression, index arithmetic, null/bounds checks and target(s) where proven.
5. Promote a table only when the call path demonstrably consumes a pointer sequence; do not infer a table from adjacent code/data or address morphology alone.

## Stop / exclusions

- Bounded listing/dataflow only; no ROM-wide RAM-writer scan and no exhaustive def-use engine.
- Stop a site when its pointer source crosses an unresolved function/interrupt boundary; record that boundary.
- Do not infer cadence, task semantics or interrupt attribution from pointer structure.
- Do not modify XML, workbook, ROM, LST, IDB, scripts or Library files.
- Minimum chat: report essential findings, evidence, unresolved boundaries and next action only.
