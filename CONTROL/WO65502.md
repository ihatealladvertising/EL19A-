## Objective

WO65490 proved `0x108B4` is not a 16-point coefficient vector: it holds exactly two values, `0x1900` (6400) at entries 0–5 and `0x1E46` (7750) at entries 6–15. Determine from reader `sub_22E7C @ 0x5B5CE` whether the two levels are selected by index, by a flag, or not distinguished at all — i.e. whether this is a two-state gain pair or a padded single value — and whether the 6/10 split is meaningful.

## Mandatory falsifiable hypothesis

- **Identity layer advanced:** internal coefficient identity, input side.
- **Hypothesis:** the two levels are a genuine two-set coefficient pair selected by a condition inside `sub_22E7C`, because a padded block would normally repeat one value throughout.
- **Evidence:** WO65490 §4.6 (distinct-count 2, values `0x1900`/`0x1E46`, split at entry 6); WO65323 §3.4 (reader address, "internal filter only, no units").
- **Prediction:** the reader will index the block with a stride/offset that distinguishes entries <6 from entries ≥6, or will load one level per branch; a single uniform read of all 16 entries would instead indicate a filter tap line where the position of the step is an artefact of a shared coefficient table.
- **Cheap discriminator:** decode the indexing at `0x5B5CE` and its callers only — no whole-routine scan, no new indexing pass.
- **Information gain:** either converts a demoted row into a describable two-set parameter (with its selection condition) or proves it must stay hidden from the definition.
- **Result:** to be recorded on closeout.

## Scope

1. Resolve the literal base and index arithmetic used to read `0x108B4` at `0x5B5CE`.
2. Determine whether both values are reachable at runtime and under which condition.
3. Check whether the 6/10 entry boundary corresponds to a filter-tap count or a loop bound in the same routine.
4. State whether a static editor axis can be derived, and whether the row can leave `[EXP]`.

## Required deliverable

- The base/index arithmetic, the decoded access sites, and the selection condition (or an explicit statement that no selection exists).
- A verdict: two-set parameter (with condition) / single value with padding / unresolved.
- An additive correction to WO65490 §4.6 if the measurement contradicts it.

## Stop conditions / exclusions

Stop after the accesses under `sub_22E7C` and at most two direct callers. No whole-ROM coefficient scan, no physical-unit claim, no XML or catalogue edit, no donor transfer.
