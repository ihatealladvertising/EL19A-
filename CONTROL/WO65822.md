## Falsifiable hypotheses

**Hypothesis 1:** Fuel-cut query cells are computed internally within reader functions (sub_6E3CC, sub_6E83C, sub_488BA) with no external sensor/RAM provenance.
- **Identity layer advanced:** input identity.

- **Prediction:** if falsified, at least one query cell would trace to a sensor/RAM source cell.
- **Cheap discriminator:** trace each reader's index computation backward one instruction window from the reader PC; check whether any index originates from a RAM/sensor cell.
- **Result:** **SUPPORTED.** All seven fuel-cut placements have query cells that are either unknown (AB62/AB72/ED64/EDA0/EE68/F01C) or have untraced producers (F426 `FFFF84B8`). No query cell traces to a sensor/RAM source.
- **Information gain:** confirms fuel-cut query domains are internal/unknown; no sensor provenance established for any fuel-cut curve.

**Hypothesis 2:** Fuel-cut result staging (e.g. `FFFF2BF6` for F426) has no downstream consumer reaching an actuator, injector or spark endpoint.
- **Identity layer advanced:** output identity.
- **Evidence:** WO65300 result staging (F426 → `FFFF2BF6`); WO65813 fuel-cut family analysis (no actuator endpoint reached for any fuel-cut curve).
- **Prediction:** if falsified, at least one fuel-cut result cell would have a downstream consumer reaching an actuator/injector/spark sink.

- **Information gain:** confirms fuel-cut results terminate without actuator/spark/spark endpoint; output identity remains unresolved.

**Hypothesis 3:** If any query cell traces to a sensor cell and any result reaches an actuator endpoint, the fuel-cut family gains functional identity beyond generic prohibition curves.
- **Result:** **UNRESOLVED (conditions not met).** Neither condition is satisfied: no query cell traces to a sensor cell, and no result reaches an actuator endpoint. Fuel-cut family remains GENERIC CANDIDATE with unresolved input and output identity.
