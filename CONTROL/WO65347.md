## 2. Falsifiable hypothesis record

- **Hypothesis:** a single flag selects either the normal pair (`0x0D456`/`0x0D656`) or the Trustful pair (`0x121C4`/`0x123C4`) exclusively at runtime.
- **Prediction:** the two dispatch entries would be reached through opposite branches of one conditional, with each branch computing only its own pair.
- **Cheap discriminator:** locate the two dispatch pointers in the pointer table, find every code reference to that table base, and inspect the call loop and both dispatch tails.
- **Result:** **NEGATIVE for exclusivity; POSITIVE for blending.** The two dispatch entries are adjacent pointers in the same table and the only call site sweeps the whole table unconditionally. Each pair is then blended internally with a weight.
- **Information gain:** WO65323's "normal/Trustful runtime blend; selection unproven" is refined: at the dispatcher level both banks always run, so no selector exists there; the "selection" is the arithmetic blend of each pair's two maps.
