## Objective

Resolve the genuinely 0-row byte cell exposed by WO65518's cluster stop boundary. At the head of the same `r12=FFFF2150` routine, `0x80586` loads `r0=h'58A` from `word_8058C`, then `0x8058A` reads `U8[r12+0x58A]`, `0x8058E` increments it, `0x80590` writes it back, `0x80594` compares it against `r5=5`, and `0x8059A` writes 0 when the incremented value is at least 5. EA: `FFFF2150+0x58A = FFFF26DA`.

`FFFF26DA`, `FFFF26DB`, `FFFF26DC` and `FFFF26DD` all have **0 exact rows** in both indexes; `h'FFFF26DA` has 0 LST hits; `h'58A` has exactly **2 LST rows** (the CODE load at `0x80586` and the DATA word at `0x8058C`); no CONTROL disposition exists for the cell.

Test whether this cell reaches a consequential compare, state export, previously dispositioned cell or one of the six discriminator cells.
