Threshold 0x3F00 (16384): query >= threshold → return last entry (`UWORD[base+0x7E]` = 6907); query < threshold → fixed-grid interpolation via `loc_234FC` → `sub_231C8`. No explicit axis pointer; fixed grid.

**Callsite `0x369EA` (in `loc_369D0`):** query = `UWORD[FFFF184C] << 4` (zero-extended, then two `shll2` = ×16). Helper returns UWORD in `r0`. Stored as UWORD to `FFFF84A4+2 = FFFF84A6` at `0x369F2` (delay slot).

**First consumer `sub_36A08` (0x36A0A):** reads `FFFF84A6`, clamps to `[0, 0xFFFF]` (structurally dead high clamp for UWORD; low clamp to 0 active), writes clamped UWORD to `FFFF182C+0x14 = FFFF1840` at `0x36A24`.

**Downstream readers of `FFFF1840`:** `0x36A3A` and `0x36A72` in `sub_36A26` (GBR=FFFF180C), `0x370B8` in `sub_37074` (GBR=FFFF180C). Additional direct readers of `FFFF84A6` at `0x38B3A`/`0x38B58` in `sub_388B4`.

### Test 3: Query grid vs fixed axis (the decisive test)

The WO requires testing whether "one target query step of 2048 corresponds to one donor axis interval of 2.8125 degrees through an actual scale conversion."

| Attribute | EL19A `0x0FEE0` | V6 `mTATVO` | Match? |
|-----------|-----------------|-------------|--------|
| Axis/query model | Fixed grid, no explicit axis pointer | Fixed axis, COMP_0298_S | Different models |
| Query transform | `UWORD[FFFF184C] << 4` (×16) | Index × 1 (FIX_AXIS_PAR_DIST 0 1 32) | Different |
| Threshold/saturation | 0x3F00 (16384), saturates to last entry | No threshold (fixed 32-point axis) | Different |
| Query range | 0 → 16384 (then saturate) | 0 → 87.1875° | Different domains |
| Points | 32 over query range | 32 over 87.1875° | Same count |
| Per-point step | 16384/32 = 512 (<<4 domain) = 32 raw | 87.1875/32 = 2.8125° | **No provable scale link** |
| 2048-step hypothesis | 2048 <<4-units = 128 raw units | 2.8125° per point | 128 raw → 2.8125°? No conversion factor |

**Scale conversion analysis:** If 32 EL19A points map to 32 donor points, the per-point EL19A step in raw domain is 32 (16384/32/16). Donor per-point step is 2.8125°. Ratio: 2.8125/32 = 0.087890625° per raw unit — no documented conversion factor supports this. The 2048-step hypothesis yields 2048 <<4-units = 128 raw units; 128 raw units = 4 EL19A table points, not 1 donor point. No scale conversion ties 2048 to 2.8125°.

**Result: No provable scale correspondence.** The query-grid models differ fundamentally (EL19A: shifted query with threshold saturation; donor: fixed degree axis). No actual scale conversion links them.
