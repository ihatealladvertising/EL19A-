## Field-Level Confidence Gates

WO65215 synthesizes the following confidence grading framework from WO65211–WO65214 evidence. Confidence is assigned per field (table/axis/measurement), not per ROM or per source.

### Gate G1 — Address Validity (binary-recoverable)

| Level | Criterion | Evidence source |
|---|---|---|
| G1-VERIFIED | Address present in ROM/listing with direct literal hit; in-bounds | WO65214 direct-hit enumeration |
| G1-DECLARED | Address declared in XML/A2L but no direct listing confirmation | WO65212/WO65213 address declarations |
| G1-PACKED | Address in packed block; recoverable via LST parsing but not direct literal | WO65214 Class E/F (21 entries) |
| G1-UNRESOLVED | Address declared but overlay/shared semantics prevent extent determination | WO65214 3 shared-address pairs (6 entries) |
| G1-ABSENT | Address not found in any evidence source | WO65212 unverified pairing |

### Gate G2 — Structural Completeness (layout fully characterized)

| Level | Criterion | Evidence source |
|---|---|---|
| G2-FULL | Dimensions, element width, stride, axis count, axis types all known | WO65214 Classes A–D |
| G2-PARTIAL | Dimensions known but axis model ambiguous (FIX_AXIS vs AXIS_PTS) | WO65213 FIX_AXIS ambiguity |
| G2-STRIDE-ONLY | Stride/dimensions inferred but no axis binding | WO65212 record layout inventory |
| G2-NONE | No structural information beyond address | WO65212 unverified candidates |

### Gate G3 — Reader/Call-site Binding (code confirms access)

| Level | Criterion | Evidence source |
|---|---|---|
| G3-BOUND | Reader function and callsite confirmed in listing; argument order documented | WO65109, WO65150, WO65217 |
| G3-HELPER-IDENTICAL | Reader shares verified helper-body identity with known reader | WO65179 (3+ pairs VERIFIED) |
| G3-UNBOUND | Address declared but no reader callsite traced | WO65212 A2L-only objects |
| G3-REJECTED | Reader traced but structure disconfirms mapping | WO64833 (mTFVAPO 0/16 byte match) |

### Gate G4 — Semantic Identity (physical meaning confirmed)

| Level | Criterion | Evidence source |
|---|---|---|
| G4-PROVISIONAL | XML/A2L label present but not independently confirmed by code | All A2L-declared objects |
| G4-REJECTED | Code evidence contradicts label/semantics | WO64833–WO65040 series |
| G4-UNPROVEN | No consumer or producer trace establishes meaning | WO65109 knock-window bit 7 discarded |

### Composite Confidence Score

| Score | Gates required | Interpretation |
|---|---|---|
| HIGH | G1-VERIFIED + G2-FULL + G3-BOUND | Field recoverable and reader-confirmed; safe for catalogue inclusion |
| MEDIUM | G1-VERIFIED + G2-PARTIAL + G3-UNBOUND | Address valid, structure partially known, no reader binding; candidate only |
| LOW | G1-DECLARED + G2-STRIDE-ONLY + G3-UNBOUND | Declaration only; no structural or code confirmation |
| REJECTED | Any G3-REJECTED or G4-REJECTED | Evidence contradicts mapping; do not use |

### Recommended Generator Design (Not Implemented)

1. **Parse stage:** Stream A2L CHARACTERISTIC/MEASUREMENT/AXIS_PTS/COMPU_METHOD blocks; extract storageaddress, record layout, compu method ref, axis references.
2. **Verify stage:** For each address, attempt direct literal hit in ROM/LST; classify packed vs direct per WO65214 Class E/F patterns.
3. **Classify stage:** Assign layout class (A–F) per WO65214 taxonomy; assign G1–G4 gates per WO65215 framework.
4. **Emit stage:** Output TSV with fields: address, layout class, G1–G4 gates, composite score, source file, source WO. Emit ONLY fields with HIGH confidence.
5. **Gate stage:** Block emission of any field with G3-UNBOUND or lower without coordinator review.
