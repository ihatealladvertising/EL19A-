# WO65215 — Cross-source metadata grammar and EL19A generation feasibility

**Status:** RESERVED — NOT STARTED; unclaimed  
**Priority:** P1 · **Class:** SYNTHESIS / GENERATION SPECIFICATION  
**Depends on:** WO65211–WO65214 CLOSED or bounded reports accepted.

## Objective
Synthesize the two A2L tracks and CF48D BIN/XML benchmark into a reusable, evidence-graded metadata rulebook and a practical specification for generating provisional RomRaider XML definitions from an EL19A BIN.

## Tasks
1. Reconcile the V6 and Juke A2L grammar with the CF48D XML/BIN recoverability matrix; distinguish shared format conventions from ECU/family-specific conventions.
2. Produce a field-by-field source matrix for RomRaider XML: address, name, type, dimensions, axes, endian, signedness, scaling, units, limits, category, description, interpolation and semantic identity.
3. For each field assign source class: BIN-DERIVABLE, DONOR-METADATA-ONLY, TARGET-READER-REQUIRED, EXTERNAL-SEMANTIC-REQUIRED, or UNKNOWN.
4. Define confidence gates preventing donor names, units, axes or semantics from being silently assigned to EL19A.
5. Apply the rules to a small, already-evidenced EL19A candidate sample from the current XML/catalogue and classify which fields could be emitted automatically, emitted provisionally, or must remain blank/unresolved.
6. Specify a safe two-stage generator design: structural candidate extraction first; target reader/semantic validation and XML emission only after explicit evidence gates. Do not implement the generator.
7. Identify the minimum additional evidence or tooling required to improve automatic coverage, prioritizing reuse of existing indexes and reports.

## Deliverables
- `CONTROL/WO65215.md` with the normalized schema, recoverability matrix, confidence rules, EL19A pilot and generator specification.
- No executable code or source artifact changes.

## Acceptance criteria
- Every proposed XML field has a documented source and confidence rule.
- Distinguishes what BIN alone can never reveal (e.g. names, physical meaning, units absent metadata, runtime interpolation behavior).
- EL19A pilot demonstrates concrete field coverage without promoting unsupported semantics.
- A clear go/no-go recommendation for automated structural XML generation, plus bounded next steps.

## Stop conditions / exclusions
No generator implementation, no XML/A2L/ROM/workbook/catalogue/index/script/tool edits, no broad new firmware scans, and no semantic transfer from donor definitions. This is a specification and feasibility closeout only.
