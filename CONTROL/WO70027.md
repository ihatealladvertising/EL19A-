## Verdict

The C12W 3DD9A / 9APCTDEM06.s19 pair is a valid **independent-container donor fixture with a calibration-region delta**, not a whole-image byte-identical twin. All differences are confined to `0x08200–0x1677B`; bootblock, the unpopulated `0x1A000–0x1FFFF` gap, and executable code `0x20000–0xFFFFF` are byte-identical.

- **Whole-image byte identity:** NOT REPRODUCED AS WORDED — 7,170 bytes differ.
- **Zero differences across bootblock + unpopulated gap + executable code:** REPRODUCED — 0 differing bytes in 975,360 compared bytes.
- **main16 integrity:** REPRODUCED — both decoded images store and compute `0x043B`.
- **Production cal16 at `0x08200` in 3DD9A:** REPRODUCED — stored/computed `0xAC8C`, status OK. The S19 copy has a calibration-adjusted/differing cal16 word (`0xC277` stored, `0x5319` computed), status BAD; no repair was attempted.
- **581 caller-backed table address alignment:** REPRODUCED — 581/581 addresses have exact A2L declarations. Exact geometry agreement is 578/581; three explicit exceptions are recorded below.
- **351-axis alignment:** PARTIALLY REPRODUCED — 351/354 caller axis addresses have A2L symbols; three do not. Extents are mapped for all 351 rows (343 from `AXIS_PTS` declarations, 8 from caller dimensions where the A2L object is a `CHARACTERISTIC` with unresolved `AXIS_PTS_REF`).
- **463 identical / 118 calibrated-difference payloads over 7,170 bytes:** REPRODUCED with an exact decomposition — 4,198 differing bytes fall inside caller table extents and 2,972 fall outside those extents but still inside the calibration region.
- **A2L metadata remains structural only:** REPRODUCED — no donor name, unit, conversion, axis, semantic label or calibration value was transferred to EL19A.
