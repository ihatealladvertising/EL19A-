## Objective

Build a targeted metadata inventory of donor A2L fuel, mixture and airflow characteristics to support candidate search while preserving the distinction between VALUE scalars and CURVE/MAP objects.

## Scope

1. Read only 64811000p2_m.a2l if present in the authorized workspace; if absent, report unavailable and stop.
2. Extract characteristics whose symbol or description indicates base fuel schedule, injector duration/latency, fuel multiplier/K-value, target A/F or lambda, warm-up/coolant enrichment, transient enrichment, MAF/airflow/load, fuel trim or cylinder fuel correction.
3. Retain exact characteristic type (VALUE/CURVE/MAP/other), symbol, description, donor address, storage width/signedness, dimensions, axis references/conversions, COMPU_METHOD, units, limits and record layout.
4. Resolve referenced COMPU_METHOD blocks and axis descriptions only; do not transfer conversions to EL19A.
5. Report family counts, ambiguous/overlapping matches and negative controls. Do not sort or align by declaration order.

## Required deliverable

A bounded report containing:
- Exact A2L characteristic metadata and source identity where used; clearly mark donor-only fields.
- Exact EL19A ROM addresses, extents, storage types, dimensions, axes/query evidence and instruction PCs where established.
- Reader/caller contract, transforms, branch conditions and first meaningful consumers where in scope.
- Separate structural, axis/scaling and functional confidence.
- Candidate-to-symbol matches, competing matches and disconfirming evidence.
- RomRaider disposition and exact unresolved boundary.
- Reused evidence, filters and explicit no-repeat list.

## Stop conditions

Stop if source is unavailable. No generated extraction files, scripts, A2L edits, XML/workbook/catalogue edits or target address inference.
