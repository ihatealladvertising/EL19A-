## Decision and principal corrections

1. The previously described `FFFF33E6` / `FFFF33E8` pair (WO65074) and `FFFF2F00+0x468 = FFFF3368` (WO65087) are **RAM cells, not peripheral-window MMIO registers**. The earlier WO65074 wording "hardware-mapped output addresses" is not supported by the SH7058 address map; this report corrects that classification without rewriting the historical report.
2. The strongest verified hardware pulse-output path is an ATU-II Timer5 A/B compare event → `INT_ATU51_IMI5A/B` → Timer11 GR11A reschedule → APC pulse-control register updates, gated by Port D direction bits.
3. This establishes a real peripheral-control path, but not a specific injector, ignition, ISC, fan or MIL device. The Port D pin-function mux and physical harness endpoint are not established.

## 2. Verified timer compare and pulse-control paths

### Timer5 A/B compare event source

- The Timer5 counter base is `FFFFF4E0`; `GR5A` and `GR5B` are `FFFFF4E2` and `FFFFF4E4`.
- `service_ATU11_timer_compare_and_state` writes `GR5A` at `0x27F84` and `GR5B` at `0x27FF6`. Each compare value is formed from the current `TCNT5` and the routine's supplied interval/state fields. No physical scale or actuator identity is established.
- ROM vector entries `0x20224` and `0x20228` point to `INT_ATU51_IMI5A` (`0x28186`) and `INT_ATU51_IMI5B` (`0x282C4`) respectively.
- These are the Timer5 compare-event handlers relevant to the downstream output path. Their presence in the vector table and their code bodies are verified; exact runtime enable/start conditions for Timer5 are not fully established in this WO.

### Timer11 GR11A/B and APC output control

WO65003 already traces `sub_27720` writes to `GR11A` (`FFFFF5C2`) and `GR11B` (`FFFFF5C4`), including the RAM-derived compare value and the overdue `TCNT11+3` path. It also identifies `FFFFF700` read-modify-write operations. This WO extends that endpoint:

- `INT_ATU51_IMI5A` at `0x28186` and `INT_ATU51_IMI5B` at `0x282C4` both load the `TCNT11` base `FFFFF5C0`.
- In the enabled branch, each schedules `GR11A = TCNT11 + 2`: store at `0x28244` (A handler) and `0x28382` (B handler).
- Each handler reads the Port D direction register `PDDR` at `FFFFF746` via `PDIOR_W` base `FFFFF740`, tests the upper Port D direction bits against a per-path RAM mask (`FFFF114F` for A; `FFFF1150` for B), and skips the APC action if the selected direction bit(s) are not configured as outputs.
- When the gate passes, the handler reads the APC word at `FFFFF700`, ORs the relevant mask byte into it, and writes the word back: A path at `0x28248–0x2824E`; B path at `0x28384–0x2838E`.
- Register labels identify `FFFFF700` as `APC_POPCRE_B` and `FFFFF701` as `APC_PULS7SOE_B`. These writes therefore alter the APC pulse-output control pair. The exact pin-to-device assignment of the mask bytes is not established.
- The pre-existing `sub_27720` path also uses dynamic Port D/PDDR gating and RMW operations at `0x27892–0x278A4` and `0x278FA–0x27906`; retain WO65003's producer and selector qualifications.

**Resulting supported chain:**

```text
TCNT5 compare A/B
   |  GR5A = FFFF F4E2; GR5B = FFFF F4E4
   v
INT_ATU51_IMI5A / INT_ATU51_IMI5B
   |  test PDDR (FFFFF746) against FFFF114F / FFFF1150
   v
schedule Timer11 GR11A = TCNT11 + 2
   |  FFFF F5C2
   v
APC_POPCRE_B / APC_PULS7SOE_B RMW
   |  FFFF F700 / FFFF F701
   v
Port D upper-bit pulse-output path (physical pin/device unresolved)
```

## 4. Port and pin-mux evidence

- `PDIOR_W` base is `FFFFF740`; the `PDDR` direction word is read at `FFFFF746`.
- The Timer5 A/B handlers test the upper Port D direction nibble (`PDDR & 0x0F00`) against masks derived from `FFFF114F` and `FFFF1150). This is positive evidence that the APC pulse path is gated by Port D output-direction state.
- The `sub_27720` path uses an additional dynamic mask from `FFFF1054+0xEA`, also shifted into the upper byte before the PDDR test.
- The reviewed paths read PDDR; they do not configure it. No corroborating write to the Port D pin-function registers (`PFIOR/PFCRH`) was established in this trace. The physical pin function and external circuit remain unresolved.
