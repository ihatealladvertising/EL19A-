## Metadata Grammar Extraction

### Record Layout Rules

| Layout | Width | Stride | Order | Use |
|---|---|---|---|---|
| `REC_UBYTE_C` | 1 byte | contiguous | row-major | 1D curves, MAP data |
| `REC_UWORD_C` | 2 bytes | big-endian | row-major | 1D/2D UWORD data |
| `REC_AXIS_UBYTE` | 1 byte | contiguous | ascending | explicit axis breakpoints |
| `REC_AXIS_UWORD` | 2 bytes | big-endian | ascending | explicit axis breakpoints |

**FIX_AXIS (implicit):** Declared inside CHARACTERISTIC via `AXIS_DESCR FIX_AXIS` with `NO_INPUT_QUANTITY COMP_0000_S <N> 0 <N-1>` and `FIX_AXIS_PAR_DIST 0 1 <N>`. Implies a fixed N-point grid at raw indices 0..N-1 with identity conversion. No separate storage address.

**Explicit AXIS_PTS:** Standalone block with storageaddress, record layout, compu method, point count, and declared range. Referenced by characteristic axis mapping.

### Conversion Chain

`A2L CHARACTERISTIC` → `storageaddress` + `RECORD_LAYOUT` → raw bytes → `COMPU_METHOD` (RAT_FUNC linear scale) → physical value

`A2L AXIS_PTS` → `storageaddress` + `REC_AXIS_*` → raw breakpoints → `COMPU_METHOD` → physical axis values

## Representative Characteristic → Payload Chain

**mMKLMRTH** (`KLMRT` high-octane map):
- A2L: `MAP 0x00011937 REC_UBYTE_C 0 COMP_0017 0 255`, 2× `AXIS_DESCR FIX_AXIS` (3 pts each, identity)
- ROM: 3×3 UBYTE at 0x11937 = `00 00 00 07 0A 07 07 0A 07`
- Conversion: identity (COMP_0017 = ×1)
- Physical: raw UBYTE values, no unit conversion

**mECUHWNO** (ECU part number):
- A2L: `CURVE 0x00008204 REC_UBYTE_C 0 COMP_0004 0 255`, 1× `AXIS_DESCR FIX_AXIS` (11 pts)
- ROM: 11 UBYTE at 0x8204 = `31 30 30 33 30 34 30 30 30 30 31` (ASCII "100304000001")
- Conversion: identity
- Physical: ASCII part number string

**mTADVTRSN** (advance RPM axis):
- A2L: AXIS_PTS `mTADVTRSN` at 0x00011B6C `REC_AXIS_UBYTE` 16 pts `COMP_0020` (×25 rpm), range 0–12750
- ROM: UBYTE breakpoints at 0x11B6C+, starting `08 0C 10 14` (= 200, 300, 400, 500 rpm)
- Conversion: raw × 25 = rpm

## Conclusion

**Juke A2L ↔ reconstructed ROM pairing is validated at the address-mapping level.** Three independent characteristic/axis addresses confirmed against raw S19 bytes. The A2L metadata grammar is well-defined: 7,260 characteristics with REC_*_C layouts, 416 axis points with REC_AXIS_* layouts, 978 linear RAT_FUNC compu methods. FIX_AXIS (implicit) and explicit AXIS_PTS (addressed) are distinct axis models not disambiguated by A2L alone.

**Primary gap:** No cross-ROM payload verification possible (V6 donor ROM unavailable), and A2L does not encode reader callsites or measurement write paths. Juke metadata remains donor-side only; no EL19A transfer.
