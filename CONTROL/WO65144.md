## 3. Result

### 3.1 `FFFF100A` — one producer, no reader

Written at `0x42C04` in `sub_42838`, delay slot of `bt/s loc_42C0C` (so it executes on every pass):

```
00042BF8  6C 2F        exts.w  r2, r12
00042BFA  DE 1E        mov.l   off_42C74, r14 ; h'FFFF1000
00042BFC  60 23        mov     r2, r0
00042BFE  62 CF        exts.w  r12, r2
00042C00  42 11        cmp/pz  r2
00042C02  8D 03        bt/s    loc_42C0C
00042C04  81 E5        mov.w   r0, @(h'A,r14)    ; FFFF100A ← sign-extended r2
```

* `r0 = r2` = the computed value; `r12 = exts.w(r2)` is the sign-extended form used for the `cmp/pz`
  test. The store happens in the delay slot, so `FFFF100A` always receives the signed 16-bit result
  regardless of the branch.
* **No reader of `FFFF100A` exists** in the listing (resolver: 0 reads). It is a write-only result slot
  on this path; its consumer, if any, is indirect.

### 3.2 `FFFF1C79` — read-only byte, two consumers

`FFFF1C79` (`FFFF1C78 + 1`) has no writer in the listing. It is read as a byte in two places:

| PC | function | idiom | use |
|---|---|---|---|
| `0x46358` | `sub_4619C` | `mov.b @(1,r4), r0` (r4 = `FFFF1C78`) | `add r0, r5` where `r5 = U8[FFFF1D2E]` (from the `FFFF1D12` block) — i.e. `FFFF1C79` is **added** to a row-query byte |
| `0x46BF6` | `sub_46744` | `mov.b @(1,r6), r0` (r6 = `FFFF1C78`) | `cmp/gt r5, r0` — `FFFF1C79` is used as a **threshold** against `r5` |

So `FFFF1C79` is a byte-sized ignition parameter that is both accumulated into a `FFFF1D12`-block
result and used as a comparison limit. No writer is resolvable statically.

### 3.3 The bit-7 gate

The bit-7 test in `sub_4619C` is **not** on `FFFF1C79`; it is on `FFFF8600`:

```
loc_46252:
00046252  96 3E        mov.w   word_462D2, r6 ; h'FFFF85FF
00046254  84 61        mov.b   @(1,r6), r0      ; U8[FFFF8600]
00046256  C8 80        tst     #h'80, r0
00046258  89 01        bt      loc_4625E
0004625A  A0 8B        bra     loc_46374        ; early exit
```

So bit 7 of `FFFF8600` (the C2-block byte WO65128/WO65147 documented) gates an early exit in
`sub_4619C` *before* the `FFFF1C79` read at `0x46358`. The bit-7 path is therefore a guard on the
C2-block state, not on `FFFF1C79` itself. `sub_46744` also contains `tst #0x80` sites
(`0x46878`, `0x46960`, `0x469B8`), but those test GBR-resident bytes in its own block
(`GBR = FFFF3614`-area), not `FFFF1C79`.

## 4. Domain conclusion

`FFFF100A` is a write-only signed result slot on the ignition path; `FFFF1C79` is a read-only byte
parameter consumed (added, then used as a threshold) by two ignition functions. The bit-7 gate is the
`FFFF8600` C2-block bit documented in WO65128/WO65147 — confirming that the ignition downstream path
is gated by the same C2 state, not by `FFFF1C79`.
