# WO65034 — Targeted Provenance of Low-ROM RAM Callback Slots

- **Status:** ACTIVE
- **Objective:** Trace the bounded producer/caller provenance of RAM pointer slots identified in WO65031: `FFFF09E6`, `FFFF0A1A`, `FFFF08B8`, `FFFF1820`, `FFFF1020`, `FFFF1810`, `FFFF1010`.
- **Method:** For each slot, retrieve only existing Xref_Index writer/caller records and bounded listing windows. Identify initialization vs runtime writes, pointer width, whether values are ROM code pointers, and call-site consumers. Follow at most one producer/caller boundary per slot; stop where provenance becomes shared/global or requires exhaustive RAM-writer search.
- **Output:** Slot → writer PC/function → written value/source → consumer PC/function → pointer classification; separate confirmed static ROM table relationships from RAM callbacks and unresolved dynamic pointers.
- **Stop:** No broad RAM-writer scan; no assumption that a RAM slot is a callback table merely because it feeds JSR. Do not modify Xref CSV or existing scripts.
- **Artifact boundary:** WO only plus operational register; no XML, workbook, ROM, LST, IDB, scripts or Library modifications. Minimum chat.
