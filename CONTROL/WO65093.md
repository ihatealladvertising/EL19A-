# WO65093 — Paired Normal/Trust Lookup Output Consumer Trace

**Status:** BOUNDED COMPLETE — CLOSED (2026-11-21)

## Objective

Trace the two paired lookup results produced in sub_69C5C and determine how their outputs are used. They are not simply separate outputs: a runtime UWORD weight selects either endpoint or interpolates between them, producing a shared result consumed by a second gated computation.

The routine establishes GBR=FFFF84D4. It loads query UWORD from FFFF1000 and calls sub_230B0 twice with the same query and axis pointers 0x1298E/0x129AE.

| Call | Map pointer | Result handling | Destination |

## 2. Runtime weight producer — sub_69CE8

- Reads UBYTE FFFF8613+1; bit 0 controls update direction.
- Reads current UWORD FFFF1054+0x724 = FFFF1778 and a UWORD from ROM 0x11700.
- Bit 0 clear: adds the ROM UWORD and saturates at 0xFFFF. Bit 0 set: subtracts it and floors at zero; the underflow path substitutes 0xFFFF.
- Stores the resulting UWORD to FFFF1054+0x724 in the RTS delay slot at 0x69D1A.

This proves a runtime-updated UWORD control/weight is used by the next routine. Physical meaning, unit and global producer/cadence remain unknown.

## 3. Endpoint selection/interpolation — sub_69D1C

- Calls sub_69C5C first, then sub_69CE8, then reads UWORD FFFF1054+0x724.
- Let w=UWORD[FFFF1778], T=UWORD[FFFF1768] (trust lookup result), N=UWORD[FFFF176A] (normal lookup result).
- If w==0, selects T directly. If w==0xFFFF, selects N directly.
- Otherwise computes (0x10000-w)*T + w*N as two 32-bit products, adds them, selects the high word and sign-extends the resulting SWORD.
- Stores the selected/interpolated result at FFFF1054+0x70E = FFFF1762 at 0x69D68.

**Conclusion:** this pair is used as two endpoints of a runtime-weighted interpolation. It is not an in-place comparison, independent parallel monitoring output, or simple mode selector. Weight zero selects the trust result; 0xFFFF selects the normal result.

## 4. First direct consumer — sub_6A0D4

- sub_6A0D4 explicitly establishes R14=FFFF1054 at 0x6A0DA.
- It computes a local scaled value using UWORD offsets 0x6E8, 0x72E, 0x732, ROM UWORD 0x11722, and sub_223FE/sub_21AC0; clamps it to signed 16-bit bounds; and stages it at FFFF1054+0x710 = FFFF1764.
- Runtime gates combine FFFF8613+5.bit0, FFFF99E7.bit0, and FFFF1D99+0x70.bit5. If inactive, the local value is copied to FFFF1054+0x718 = FFFF176C.
- If active, it reads selector UWORD FFFF1D12+0x52 = FFFF1D64. Selector zero uses the local value; selector 0xFFFF loads the paired-map result FFFF1762; intermediate selector computes a second complementary weighted interpolation between the local value and FFFF1762.
- Stores the selected/second-stage interpolated result at FFFF1054+0x718 = FFFF176C (0x6A178).

The paired-map blend is therefore one input to a further gate- and selector-dependent blend with an independently computed local value.

## 5. Invocation gate and bounded additional consumer

- The enclosing routine beginning loc_6A1B0 sets GBR to ROM option byte 0x8B51. If bit 5 is set, it bypasses the sub_69D1C/sub_6A0D4 pair. If bit 5 is clear, it tests bit 7 of the GBR-relative byte at offset 0x182; when set, it calls sub_69D1C then sub_6A0D4 (0x6A1CA–0x6A1D2). Upstream scheduling/cadence was not traced.
- A separate function at 0x6A4FC explicitly sets R10=FFFF1054 at 0x6A50E. Its conditional path reads UWORD FFFF1054+0x714 at 0x6A57A and FFFF1054+0x70E at 0x6A58E (alternate path reads +0x70E at 0x6A5D2); it combines/clamps these with local values and UWORD FFFF2150+0x92A, then stages at FFFF1054+0x71C (0x6A5BE). This confirms a second consumer context for the trust endpoint and combined result. The bounded trace did not establish a direct +0x716 read in this routine or trace the stage further.
- Other literal 0x714/0x716 occurrences were not accepted unless the base was proven. The 0x29B74 site is based on FFFF2150, not FFFF1054; unresolved-base occurrences remain outside the accepted reader set.

## Findings and confidence

1. **High confidence:** 0x11BC4 and 0x119C4 are evaluated under the same query/axes and centered into distinct UWORD endpoint cells.
2. **High confidence:** runtime-updated UWORD FFFF1778 weights the endpoints; zero selects trust, 0xFFFF selects normal, and intermediate values interpolate them.
3. **High confidence:** combined result FFFF1762 is consumed by a second gated blend in sub_6A0D4 and by a separate local calculation at 0x6A4FC.
4. **Unresolved:** physical subsystem/domain, units, why endpoints are weighted, upstream source/cadence of the weight, full callers of the enclosing routine, and downstream use beyond FFFF176C/FFFF1054+0x71C.
5. No Nissan semantic name or calibration unit is assigned. “Trust” and “normal” describe bank membership only.
