## Results — 2026-11-17

### Reader behavior

- `0x50546–0x5054C`: R1 is ROM object `0x8469`; byte `[R1+4]` is compared unsigned against `[FFFF84B4+6]`. If the ROM byte is greater than the candidate, the routine writes marker `0x3C` to `FFFF1E7C+0x1F`; this is a separate state output, not a write to the candidate.
- `0x770A6–0x770C0`: reads `FFFF84BA` and copies it to a caller/context record at `R12+0x24`. Other fields in that record are populated from `FFFF849A`, `FFFF9860`, `FFFF859C`, `FFFFB4A8`, and `FFFF1D12`; record base/consumer semantics are not established here.
- `0x77140–0x7715A`: second path copies the same byte to `R12+0x16` in a related caller/context record. Again, this is read/copy-out behavior.
- `0x9538A–0x9539A`: unsigned compare against `0x78` (120). If `FFFF84BA < 120`, ROM byte `0x87FE` is copied to `FFFF363C+0x33`; otherwise that write is skipped.
- `0x95DCE–0x95DDE`: compares UBYTE `FFFF84BA` against UBYTE `FFFF2150+0xA8F`; the larger value is clamped down to the smaller and the result is stored back to `FFFF2150+0xA8F`.
- `0x9633C–0x9635A`: if candidate > 50, subtracts 50, applies a conditional +3 rounding adjustment, then arithmetic-shifts right one; if candidate <=50, emits `0x80`. Result is stored to `FFFF2150+0x920`. This is a numeric conversion/threshold path, but its units and physical source are not identified.

### Adjacent-field evidence

- In the same `sub_95D62` GBR=`FFFF84B4` context, offsets +1, +3 and +6 are read at `0x95E42`, `0x95E2C`, and `0x95DCE`, respectively, and participate in related arithmetic/output paths. This supports a multi-field RAM data structure, not a single isolated scalar.
- Other reviewed readers use offset +4 as a lookup query (e.g. `0x4AF42`, `0x85B28`) and offset +3 as a UBYTE query (e.g. `0x7D072`, `0x95D8C`). No channel identifier, sensor conversion, calibration-unit metadata, or direct coolant label was established.
- The 50 and 120 thresholds and the value's use as a clamp bound are compatible with several sensor/state quantities; they do not uniquely identify coolant temperature.

### Conclusion

**Role assessment:** confirmed UBYTE RAM field consumed as a threshold operand, clamp ceiling, numeric-conversion input, and copied record field. It belongs to a multi-field RAM structure rooted at `FFFF84B4`.
