### 2) Backward source-expression trace (GR5 interval `r5`)

Common pre-branch computation at 0x27EB4-0x27F12 (LST 39415-39469):

1. **Gate:** `FFFF1E63+1.bit0` must be set (39407-39413) else exit to 2802E. `FFFF868C+9.bit6` set earlier (39406).
2. **Byte sum input A:** `r5 = extu.b BYTE[FFFF1CA8 + 0x3B]` (39416-39421). Source: `FFFF1CE3`.
3. **ROM byte B:** `r6 = extu.b BYTE[0x8BA8]` (39420,39422,39424). Literal loaded via `off_280FC`.
4. **ROM byte C:** `r2 = extu.b BYTE[0x8ABD]` (39418,39423,39425). Literal loaded via `off_280F8`.
5. **Sum/cap:** `r5 = r5 + r6 + r2`; if `r5 > 0xFF` then `r5 = 0xFF` (39426-39433). Stored as byte to `GBR+0x64 = FFFF10B8` (39438).
6. **Scale by runtime state:** `r2=r5_ext; r6 = LONG[FFFF85C4+0x20]` (39435-39441). `mul.l r6,r2; sts macl,r1; r0=0x708; jsr sub_21BE4` (39441-39444). This is a divide/scale helper call: `(FFFF85C4+0x20 * sum) / 0x708` by convention of surrounding code; exact helper semantics bounded to observed call contract.
7. **ROM UWORD clamp:** `r5 = extu.w WORD[0x9434]` (39445-39447). If `r0(result) > r5`, clamp to `r5` (39448-39452). `0x9434` is read as UWORD.
8. **Store interval base:** `UWORD[FFFF1054+0x46A]=UWORD[FFFF14BE] = clamped_result` (39454-39456).
9. **Convert to GR5 delta:** `r5 = clamped_result * 10` via `shll2; add r2,r5; shll` (39457-39461). This `r5` is the compare delta used by both GR5A and GR5B paths.
