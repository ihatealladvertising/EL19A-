## Base discrepancy note

The paired-bank functions (`sub_69496`, `loc_695FC`, `loc_696F0`, `sub_6A85C`, `sub_6A0D4`) use `FFFF1054` as a **direct base register** (loaded into r13/r14 via `mov.l off_xxxx, rN ; h'FFFF1054`, then `@(r0,r13)` addressing).

Elsewhere in the codebase, `FFFF2150` is used as a **GBR base** (loaded via `ldc r0, gbr` where r0 = FFFF2150, then `@(offset,gbr)` addressing).

`FFFF1054+0x5E0` = `FFFF1634`; `FFFF2150+0x5BC` = `FFFF270C`. These are **different addresses** in different RAM regions. WO65080's attribution of `FFFF2150+0x5BC` and `FFFF2150+0x726` refers to a different base and does not match the `FFFF1054`-relative effective addresses verified in the listing. The two bases are not interchangeable; the pairing is established by the `FFFF1054`-relative cells, not by `FFFF2150`-relative cells.
