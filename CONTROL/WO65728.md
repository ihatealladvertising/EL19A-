## Objective and result

Determine whether the reloaded `r0` at `0x3630`, after the `AND #h'7F` at `0x3632`, is restored to bit `0x80 = SET` by a following `OR #h'80` before any `r0`-using store in the next four instruction PCs.

**Result: HYPOTHESIS REJECTED — NET CLEAR AT FIRST STORE.** No bit-0x80-setting `r0` write occurs in `0x3634–0x363A`. The first instruction, `0x3634 mov.b r0,@((dword_8220 - h'821C),gbr)`, stores `r0` to `U8[FFFF8220]` before any restoration, so the value stored there has bit `0x80` cleared by the carried `0x3632 and #h'7F,r0`. The only later explicit mask, `0x3638 and #h'BF,r0`, clears bit `0x40` and does not set bit `0x80`. A second store at `0x363A` writes `r0` to the same byte with no restoration in between. This is a four-PC bit-sequence census only; it does not reopen WO65704/WO65716 or assign physical meaning.
