## Objective

Resolve the writer conditions and chronology of RAM bit `FFFF99E7.bit3`, which controls the table-versus-non-table branch in both F3D6 and F3DE processing paths.

Known target-side behavior to reuse:

- In the F3D6 routine, the test around `0x6582E–0x6583E` selects the F3D6/F3C6 lookup when bit3 is set; the clear path bypasses the lookup.
- In the F3DE routine, the corresponding test around `0x68200–0x6822E` selects F3DE/F3CE when bit3 is set; the clear path bypasses the lookup.
- WO65181 resolves their shared query to `min(UWORD[FFFF8596] >> 7, 255)`; do not repeat that lineage.

The decision question is: who sets and clears `FFFF99E7.bit3`, from what inputs, under which gates, and in what execution context relative to each of the two limiter routines?

## Critical distinction

Do not confuse `FFFF99E7.bit3` with the separate `FFFF99E9.bit3` gate used by `sub_34476` in the timer-derived reciprocal chain. Their addresses and functions differ. WO65181 is authoritative for the `FFFF99E9.bit3` arithmetic and sentinel polarity; this assignment concerns only `FFFF99E7.bit3`.

Do not confuse this bit with the unrelated QDSPT branch bits `FFFF85F8.bit4`, `FFFF8600.bit6`, `FFFF860B.bit3` and `FFFF1DB4.bit5`, which are WO65183's scope.
