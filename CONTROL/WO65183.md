### 1. Threshold equation (`sub_403D8`, `0x40422–0x4044A`)
```
r5   = UBYTE[FFFF84B4+6] = UBYTE[FFFF84BA]          (0x40426, extu.b)
r4   = UBYTE[FFFF1D99+0x1B] = UBYTE[FFFF1DB4]       (0x4042C, prior value)
if (r4 & 0x20) r5 += 3                               (0x40430–0x40434)
if (r5 >=u UBYTE[0x8550]=0x0A) bit5 := 1 else bit5 := 0   (cmp/hs 0x4043E; or #0x20 in bt/s delay slot 0x40442 runs on both paths, and #0xDF at 0x40444 only on fall-through)
UBYTE[FFFF1DB4] := r0                                (0x4044A, whole-byte write; other bits preserved)
```
Result: unsigned raw hysteresis — set when `FFFF84BA ≥ 0x0A`; once set, stays set while `FFFF84BA ≥ 0x07`. (No overflow guard on +3; `r5` is 32-bit so no wrap.) WO65118 lists `0x4044A` as the **only** writer of `FFFF1DB4` (index hit confirmed in context). `FFFF84BA` remains an AN27-derived NTC path value per WO65056/WO65182; no Celsius or coolant identity is established.

### 4. `FFFF1DB4.bit5` effect on the later value (`0x40532–0x4057C`)
`UWORD[FFFF1018] := r5` where:
- `FFFF1E73.bit7` set **or** `860B.bit3` clear → `r5 = 0`.
- else `FFFF860F.bit3` clear: `r5 = FFFF1DB4.bit5 ? UWORD[FFFF1054+0x39C] : 0`.
- else (`860F.bit3` set): `r5 = max(UWORD[FFFF1042] − UBYTE[FFFF23E6], 0)`.
So `FFFF1018` is non-zero only when `860B.bit3` is set (outer calc bypassed this pass). It then uses the `0x39C` value latched from an earlier pass with bit3 clear. With `860F` = previous `860B`, the `0x39C` branch (bit5-gated) applies on the first pass after bit3 rises (860B=1, 860F=0), and the decay branch applies on later passes. **Inference:** 860F is the previous-cycle copy of 860B, based on the `sub_20DCE` copy order; this assumes `sub_20DCE` and `sub_403D8` execute in sequence.

**Discrepancy:** WO64860 names the scalar byte `FFFF2446`. From the literals above, `r14 = FFFF2150` is set on both paths (`0x403FA`/`0x40418`), and `0x296` gives **`FFFF23E6`**. This assumes `r14` is preserved across `sub_22E10`; `sub_22E10`'s body was not re-checked. Coordinator should reconcile WO64860.
