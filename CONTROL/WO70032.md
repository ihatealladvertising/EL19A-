## Objective

Integrate the newly added EL19A donor-aligned scalar TSV/XML evidence into the SH705x workbench as a reproducible, target-side audit command. Preserve target-byte facts separately from donor names, tiers, conversions, units, and XML scaling hypotheses.

## Implementation

The command joins rows by exact EL19A address and records row source fields, ROM bounds and bytes, unsigned big-endian value, optional scanner width matches (with candidate element types retained), and optional XML fragment address hits. It accepts plain JSON or gzip-compressed scan catalogues. It compares raw unsigned values only for 1- and 2-byte rows. Four-byte rows and other widths remain explicitly unresolved. XML names and scaling are retained as hypotheses and are never emitted to RomRaider XML.
