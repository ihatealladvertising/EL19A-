## Objective

Identify the actual EL19A RPM/speed cut and restore calibration roles and distinguish hard fuel cut, soft torque/throttle intervention, gear/state-specific limits and monitor thresholds.

## Scope

1. Start from existing target candidate lists and closed fuel-cut/limiter reports; no fresh global scalar or RAM sweep.
2. Prioritize only unresolved RPM cut/restore thresholds, vehicle-speed limit/restore, gear/neutral variants and any soft limiter tables already present in the catalogue or A2L candidate lists.
3. For each candidate establish exact ROM extent/type, reader/caller, query source and units, selector/state conditions, comparison polarity/hysteresis and first consequential intervention (fuel, ignition, throttle or internal status).
4. Use donor A2L descriptions as a hypothesis list only. Specifically separate speed-reference acceleration/deceleration coefficients and target-speed control scalars from vehicle-speed limiter thresholds.
5. Return a compact evidence matrix and RR disposition; explicitly list candidates rejected as unrelated.
