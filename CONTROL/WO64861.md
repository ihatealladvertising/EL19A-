## Investigation closeout — 2026-11-16

**Technical status: COMPLETE — bounded output-path discriminator; ETC actuator endpoint not established.**

### Timer/output-register findings
- ATU-II timer 5 is used by `INT_ATU51_IMI5A` and the paired channel-B interrupt path. At `0x281F8–0x281FE`, channel A schedules a compare by adding a bounded interval to current TCNT5 and writes the result to TCNT5+2 (GR5A). At `0x28336–0x2833C`, channel B similarly writes TCNT5+4 (GR5B).
- The target register map identifies TIOR5A/B at `FFFFF4EB/FFFFF4EA`; the bounded annotated-listing search found only their register declarations, not runtime writes/configuration. These timer compare writes therefore establish interrupt scheduling, not a routed physical output.
- Timer 7 setup code at `0x2453C–0x24564` initializes TCNT7A and adjacent compare/capture registers. The listing has no ATUII_TIOR7 symbol or identified output-mode/pin routing for this channel. No connection to FFFF23E6 or FFFF1018 was established.
- Timer 11 compare-register writes were previously inspected under WO64794. Its PL1/PL2 direction bits are outputs, but PLCRH/PLCRL function selection is cleared; the TIO11A/B pin route is not established. Do not repeat that pin-mux audit.

### GPIO/output-path findings
- The annotated listing defines port data registers (PADR/PBDR/PCDR/PDDR/PFDR/PEDR/PLDR/PGDR/PJDR/PKDR), but the bounded search found no direct runtime PDR writes. PBDR appears as a pointer in a ROM data structure at `0x15498`; its indirect consumer was not traced and cannot be treated as an actuator output.
- Port direction-register references and input-status reads exist, but do not by themselves prove output data or ETC actuation.
- ATU-II TGR3A and TIOR3/5 register names occur as register definitions only in the inspected text; no dataflow from FFFF23E6/FFFF1018 to these registers was found.

### Disposition
- FFFF23E6/FFFF1018 remain internal-state candidates; no ETC motor command, PWM duty, H-bridge control, actuator pin or physical throttle endpoint is demonstrated.
- Timer 5 compare writes are best explained by interrupt/event scheduling; Timer 7 setup remains functionally unassigned; Timer 11 pin output is weakened by the already-verified pin-mux state.
- This is a bounded negative result, not proof that the entire ROM contains no ETC output path. Indirect GPIO descriptor handling and unrepresented hardware paths remain outside the demonstrated boundary.
- No XML, workbook, ROM or LST edits. Read-only closeout.
