## Bounded work

### A. Direct ROM reads of static configuration/option bytes

Searched the listing for `mov.l off_<table>, rN ; h'84xx` (absolute ROM address loads) followed by `mov.b @rN` (byte read). Six distinct ROM addresses in the `0x8400–0x845B` range are read directly as static configuration/option bytes:

| Address | Shipped value | Usage type | Read PCs | Guard/config role |
|---------|--------------|------------|----------|-------------------|
| `0x8404` | `0x07` | Multiplier factor | `0x9168E` | `mov.b @r6, r2; extu.b r2, r6; mul.l r14, r6` — used as multiply-by-7 factor; result compared vs `0x7FFF800` at `0x9169A` |
| `0x8405` | `0x0C` | Guard byte (bit mask) | 21 sites (WO65111 §b) | `tst #1/2/4/0x20/0x40/0x80` across 21 sites; bits 3/4 never tested; ships with bit2+bit3 set |
| `0x8407` | `0x03` | Threshold | `0xA87C6` | `mov.b @r2, r6; extu.b r6, r2; cmp/gt #8, r2` — `0x03 > 8` is false, always takes non-branch path at `0xA87D0` |
| `0x8445` | `0x0A` | Threshold | `0x38F98` | `mov.b @r5, r2; cmp/hs r2, r6` — gates `or.b #h'20, @(r0,gbr)` when `r6 >= 0x0A` |
| `0x845A` | `0xFF` | Maximum bound | `0x26A1C`, `0x26A60` | `mov.b @r4, r2; extu.b r2, r2; cmp/gt r2, r6` — `0xFF > r6` is false for UBYTE, max-value bound check |
| `0x845B` | `0x64` | Configuration value | `0x29C1A`, `0x69988` | `mov.b @r6, r2` — reads decimal 100 and stores to RAM; config value, not a guard bit |

**`0x8406 = 0x1E`** (part of the `0x8404–0x8407` word `07 0C 1E 03`) — **never directly read** as a byte in bounded search.

These RAM-space reads may mirror ROM config bytes or be separate runtime state; they are not ROM-resident and are not part of this guard matrix.
