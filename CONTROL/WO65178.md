# WO65178 — ROM-wide static configuration and option-byte guard matrix

**Status:** RESERVED — NOT STARTED; unclaimed  
**Priority:** P1  
**Branch:** `wo65178-rom-variant-guard-matrix`  
**Authority:** `CONTROL/active_work_orders.md`

## Objective
Extend the known `0x8405`/configuration-byte investigations into a bounded, reproducible matrix of ROM-resident bytes/bits used as static branch guards, and classify the guarded code regions/functions.

## Required work
1. Reuse WO65111's `0x8405` provenance, existing option-byte findings (including `0x856E`, `0x8B51`, `0x8CD3`), canonical listing and merged function/GBR indexes.
2. Extract code sites that load ROM constants/bytes and test immediate masks (including `tst #imm`, compare/test idioms and equivalent bit-test sequences); distinguish immutable ROM guards from mutable RAM state.
3. Normalize each guard as effective ROM address, mask, expected polarity, tested instruction, caller/function, branch destinations and affected downstream call/path.
4. Group repeated reads of the same byte and distinguish independent flags from alternate reads of one packed option byte.
5. Determine which options can be statically evaluated from the EL19A ROM image and which remain runtime/variant-dependent.

## Acceptance criteria
- Complete coverage statement for the chosen instruction idioms and canonical listing.
- Matrix includes address, raw byte, bit/mask, polarity, PC, function, branch effect and evidence for ROM provenance.
- Reconcile known 0x8405/0x856E/0x8B51/0x8CD3 examples; explicitly identify false positives and unresolved computed-address guards.
- No inferred MT/AT, emissions, cruise, rear-O2, NATS or trust-monitor label without corroborating code/data evidence.
- Ranked list of guarded functions likely to affect EL19A applicability, with confidence and trace suggestions.

## Boundaries
Read-only static analysis. Reuse existing indexes and avoid repeating WO65111's detailed 0x8405 trace. No ROM/LST/XML/workbook/catalogue/index/script/tool edits and no runtime/vehicle testing.
