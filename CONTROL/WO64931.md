## Objective
Classify the DAD6 lookup as a dynamic row-pointer structure rather than a standalone curve. Identify row stride, inner element layout, RAM selector/query and helper behavior. Do not infer full bank dimensions or semantic role.

## Caller / dynamic row pointer
Function sub_434C4 establishes GBR=FFFF85C4 and reads:
- UWORD query source: FFFF85DA, loaded into R6.
- UBYTE row selector: FFFF85C4, later read from GBR+0.

The row pointer calculation at 0x434EC–0x434FA is:
- Load ROM anchor DAD6 into R4.
- Load row selector U8[FFFF85C4] into R2.
- Compute R4 = DAD6 − 0x20 + (selector × 0x20).
Thus each selected row is 0x20 bytes / 16 UWORD BE values. Selector 1 addresses DAD6 itself. Selector 0 would address DAB6. No maximum selector or total bank extent is established by this bounded trace.

## Inner fixed-grid lookup
Before the dynamic pointer is passed to sub_22E7C:
- UWORD[FFFF85DA] is adjusted by subtracting 0x20 with a lower-bound path for smaller inputs.
- The adjusted value is multiplied by 0x80 and capped to UWORD 0xFFFF.
- This result is supplied in R5 as the helper query.
- sub_22E7C uses its generated 16-point UWORD query grid 0000,1000,…,F000, no ROM axis pointer.

The helper call is at 0x434FE. After lookup, the result is stored/used in a following calculation; no semantic trace is required for this objective.

## Classification
- **Dynamic / descriptor-style row bank:** row address is computed from U8 RAM selector and a 0x20-byte row stride.
- **Inner table segment:** 16 UWORD BE values per selected row.
- **Inner lookup:** fixed-grid sub_22E7C; no ROM breakpoint axis expected.
- **Outer dimension:** unknown. Do not claim 16×N or 256×16 without a proven selector bound and full extent.
- **Candidate address:** DAD6 is the anchor row for selector value 1, not a proven complete map base.
- Semantic identity, physical units and actual outer dimension remain unassigned.
