## Objective and result

Test one cheap, bounded discriminator for whether the opaque EM43A Osiris payload is protected by a short repeating XOR or fixed-period byte transformation, with no EL19A calibration semantics promoted.

**Result: BOUNDED NEGATIVE; PREDICTION FAILED.** The period screen found only minute column-frequency deviations. Per-payload top-five periods and an aggregate five-period trial set were examined. For every trial, XORing the first 4 KiB with the per-column most-frequent-byte candidate left entropy high and produced no recognizable ASCII structure; all printable strings >=8 bytes were short random-looking fragments. This does not identify a cipher and does not exclude all possible transformations; it rejects the stated simple repeating-key/MFB-discrimination prediction for periods <=64.

## Method and selection rule

For each payload and period `p = 1..64`, bytes were partitioned into `p` columns by `i mod p`. For each column:

- **IoC** = `Σ_x n_x(n_x−1) / (n(n−1))`, averaged over columns; uniform reference `1/256 = 0.00390625`.
- **Entropy** = Shannon entropy in bits/byte over 256 byte values, averaged over columns; uniform reference `8`.
- **Max-frequency share** = `max(n_x)/n`, averaged over columns; uniform reference `1/256`.

Per-payload top five were ranked by IoC excess over `1/256`, with entropy deficit and max-frequency excess as reported tiebreak columns. The five periods carried into key trials were selected by the aggregate mean IoC excess across both payloads, tie-broken by aggregate entropy deficit then max-frequency excess: **49, 47, 16, 36, 53**. This is one deterministic selection rule; no period was chosen by inspecting decoded output.
