## 1. Address-classification correction: FFFF8518 / FFFF851A

- Startup initialization at `0x27DA–0x27F2` sets R7 to `FFFF8500`, R4 to `0x264C`, and loops through vector-table indices, storing the 32-bit handler pointer `0x0000264C` at `[FFFF8500 + 4×index]`. The loop covers index 0 through `0xE7`, so it includes the longword at `FFFF8518–FFFF851B`.
- A separate setup path explicitly loads VBR from `FFFF8500+4 = FFFF8504` at `0x1578–0x157E`, corroborating that this RAM region is used as a vector/exception dispatch table.
- Therefore `FFFF8518` is the start of a four-byte vector-table slot and `FFFF851A` is its lower halfword. Their proximity to the other requested RAM cells is not evidence of ADC acquisition or sensor staging.
- A targeted exact-address search found no code use of `FFFF8518` or `FFFF851A` outside the RAM declaration; the positive vector-table initialization is stronger evidence than the absence alone.

## 2. ADC helper census and channel group already resolved

### Generic conversion helper

`sub_253C0` at `0x253C0` accepts an 8-bit channel index and has separate control paths for:
- `0x00–0x0B`: ADC0 control/result bank (`ADCSR0` / `ADDR0–ADDR11`).
- `0x0C–0x17`: ADC1 control/result bank (`ADCSR1` / `ADDR12–ADDR23`).
- `0x18–0x1F`: ADC2 control/result bank (`ADCSR2` / `ADDR24–ADDR31`).

The helper programs the selected channel, starts conversion, polls the completion/status bit, reads the selected result register as a UWORD and returns the conversion result in R0. The result is a raw ADC word; scaling is caller-specific.

### Direct callsite inventory

The pinned listing contains only two direct callsites of `sub_253C0`:
- `0x28B24`: R4 = `0x1B` (AN27, ADC2). Raw UWORD is stored at `FFFF1798+0x1C`; caller shifts it right two and evaluates ROM curve `0xF406), then stages/filter-processes the result through `FFFF84BB+6 = FFFF84C1`. WO65056 already traces the filter/failsafe/slew path and 7-byte mirrors into `FFFF84B4–FFFF84BA).
- `0x28B5E`: R4 = `0x1F` (AN31, ADC2). Raw UWORD is stored at `FFFF1798+0x1A`; caller shifts right two, evaluates the same `0xF406) curve, and stages at `FFFF84BB+1 = FFFF84BC), followed by the already documented filtering path in WO65056.

These are the existing NTC channel paths explicitly excluded from repetition by this WO. No additional direct callsite to `sub_253C0` was found.
