# WO65050 — sensor-block producer check in sub_70880 predecessor group A

**Status:** ACTIVE  
**Parent:** WO65045  
**Lead:** FC90/111EA reader at `sub_969C2` is called from `sub_70880` after a fixed sequence of sibling routines.  
**Target:** `VERSA f501.bin`, MD5 `46991697c502052752a2cabcb84c9e27`  
**Inputs:** preserved annotated LST and XREF index, read-only

## Objective

Check whether the three routines immediately preceding `sub_969C2` in the `sub_70880` sequence populate or transform the `FFFF84B4` sensor/state structure, especially byte +6 (`FFFF84BA`). This is a concrete caller-chain lead, not a global writer scan.

## Scope

- `sub_957BA` called at `0x70862`
- `sub_9595C` called at `0x70868`
- `sub_95C1C` called at `0x7086E`

Inspect each routine's local stores, copy helpers, pointer arguments, and any references to `FFFF84B4` / `FFFF84BA`. If no relation appears within the routine/caller boundary, stop and report it.

## Required output

- Any direct/indirect writes or transfer source to `FFFF84BA` or containing structure.
- Whether these routines write adjacent +4/+6 fields or call a shared acquisition/normalization helper.
- Exact producer/source PCs and any interrupt/peripheral boundary.
- If no producer is found, close with a bounded negative and recommend the next sibling group only if justified.
