## Producer chain for the query multiplier (UWORD[FFFF8494] +0)

The value consumed by E904/E914, AF72/ADF2, and WO64894 queries is **UWORD[FFFF8494] at offset +0**. This field is **copied from offset +2 (FFFF8496)** by `sub_20DCE` on each INT_TRAPA62 tick:

```
INT_TRAPA62 (periodic, bit0-gated)
  → sub_250A6 (0x250A6)
    → sub_20DCE (0x20DCE) via jsr @r2
       0x20DD6: ldc r0, gbr  (r0 = FFFF8494 base)
       0x20E30: mov.w @(0x2,r14), r0   ; read UWORD[FFFF8496] → r0
       0x20E34: mov.w r0, @r14         ; write UWORD[FFFF8494] ← r0
```

Thus **the runtime query multiplier at FFFF8494+0 is a shadow copy of FFFF8496**, refreshed each scheduler tick.
