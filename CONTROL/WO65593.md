## Method and selection rule

For each payload and period `p = 1..64`, bytes were partitioned into `p` columns by `i mod p`. For each column:

- **IoC** = `Σ_x n_x(n_x−1) / (n(n−1))`, averaged over columns; uniform reference `1/256 = 0.00390625`.
- **Entropy** = Shannon entropy in bits/byte over 256 byte values, averaged over columns; uniform reference `8`.
- **Max-frequency share** = `max(n_x)/n`, averaged over columns; uniform reference `1/256`.

Per-payload top five were ranked by IoC excess over `1/256`, with entropy deficit and max-frequency excess as reported tiebreak columns. The five periods carried into key trials were selected by aggregate mean IoC excess across both payloads, tie-broken by aggregate entropy deficit then max-frequency excess: **49, 47, 16, 36, 53**. These column metrics are byte-value-permutation invariants, so they necessarily coincide with WO65581's XOR screen; they were recomputed independently as required by this WO.
