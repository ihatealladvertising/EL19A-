## Method (bounded)

1. Parse concordant listing CODE/DATA/label lines; verify raw bytes at every cited PC against the ROM; drop/list mismatches. Report full concordance.
2. Recompute function membership from code-start labels using WO65116's extent rule (label → final concordant `rts`/`rte` before the next code-start label), for attribution only — do not republish extents.
3. Extract direct calls:
   - `bsr <label>` → callee from the operand label, direct.
   - `jsr @rN ; <annotation>` → callee from the annotation when it names a code label; otherwise attempt a nearby pool load into `rN` and accept only a full 32-bit ROM pointer to a code label.
   - `jmp`/`bra` are not calls; exclude them, but record `jmp`-based tail dispatch separately in the dispatch table work.
4. Build per-function callers/callees summary from the emitted edges.
5. Dispatch tables: read 9 big-endian U32 values at `0x21A64` and 8 at `0x216EC` from ROM bytes; verify each target is within ROM and is a concordant code-start label; record the loading `mov.l` PC (`0x20986`, `0x20A12`) and the loop count (`r13=9`, `r14=8`).
6. ISR map: parse `.data.l` vector entries in the `0x20000–0x21A64` region whose values are code labels; for each ISR, scan its body for a call edge to `sub_2088C`; list the two known callers and the nine-entry dispatch order.
7. Regressions, reported verbatim pass/fail:
   - **R1** `dword_21A64` has exactly 9 entries, all in ROM and at concordant code starts.
   - **R2** `dword_216EC` has exactly 8 entries, all in ROM and at concordant code starts.
   - **R3** `sub_2088C` is called by `INT_ATU02_ICI0A` and `INT_ATU12_IMI1AE` (both call edges present).
   - **R4** the nine-entry order is `34464, 4D02C, 3C45E, 59CAE, 47276, 5F81E, 500EC, 951E0, C29A2` as read from ROM bytes.
   - **R5** negative control: no call edge attributes `PKIOR_W` (`FFFFF770`) as a callee; no dispatch target is a RAM address.
   - Comparisons (reported, not gated): total direct call edges, `jsr_reg_unresolved` count, distinct callers/callees.
