## 4. Implementation

- **Generator:** `EVIDENCE/WO65120_call_graph_generator.py`, stdlib-only Python 3, version `WO65120-CALLGRAPH-1.1.0` (embedded in all five TSV headers). Run command: `python EVIDENCE/WO65120_call_graph_generator.py --listing <extracted V3_NEXT6_16 .lst>`.
- **No `tools/` entry was created.** WO65115 retains the repository's first-tool scope.
- Function membership is recomputed only to attribute call edges (label → final concordant `rts`/`rte` before the next code-start); extents and GBR are **not** republished.
- Call extraction: `bsr <code-label>` → `bsr_direct`; `jsr @rN ; <code-label>` → `jsr_reg_ann`; `jsr @rN` with a nearby full 32-bit pool pointer to a concordant code PC → `jsr_reg_ann`. Everything else → unresolved (`jsr_target_not_provable`, `bsr_target_not_code_label`, `annotation_not_code_label`). `jmp`/`bra` are excluded as non-calls.
- Dispatch targets are read from **ROM bytes** (big-endian U32) and accepted as code starts when they are concordant CODE PCs (a label may be absent — the nine task-table targets are concordant code PCs without individual labels).
- ISR vector map scans `.data.l` entries in `0x20000–0x21A64` whose value equals a code label's PC, and flags those with a static call edge to `sub_2088C`.
- All five TSVs have identical 14-line header blocks with ROM/listing hashes, version, run date, concordance, `target_file_sha256: N/A`, and the static-only method-limits sentence.

## 6. Limits / unverified (explicit)

- **L1** Static direct calls only. Computed targets, runtime pointer tables, `jmp`-based tail dispatch and self-modifying/indirect chains are not modelled.
- **L2** 233 register-indirect/unhandled call sites are unresolved; their callees are **not** asserted. Absence of an edge is not evidence of absence of a call.
- **L3** The ISR map covers only `.data.l` vectors in `0x20000–0x21A64` whose value equals a code label; vectors outside that window or using non-label encodings are not enumerated here.
- **L4** Dispatch-table targets are accepted as concordant code PCs; individual labels may be absent (all nine `dword_21A64` targets are unlabelled code PCs). No semantic/physical/unit naming.
- **L5** Branch-only and unreviewed; rows are structural call leads until coordinator audit.
