## Objective

Produce a bounded, source-faithful donor metadata extract for ignition/knock VALUE characteristics so target-side workers can search by exact symbol and description without relying on declaration order.

## Scope

1. Read the exact source file 64811000p2_m.a2l if it is available in the authorized project workspace. If unavailable, report the missing path and stop; do not fetch a replacement or modify the A2L.
2. Extract VALUE characteristics matching ignition advance/retard/knock/dwell/cylinder compensation/coolant retard/limiter concepts, including exact symbol, description, donor address, storage type/width/signedness, conversion method, units, limits and record layout where declared.
3. Resolve referenced COMPU_METHOD definitions and any axis-independent conversion formulas; retain original A2L identifiers and distinguish missing/inherited metadata.
4. Include bank/pair naming variants such as suffix-2 forms only when actually present; do not assume paired symbols are adjacent in target ROM.
5. Report exact counts, extraction filters and a compact table of matches. Do not infer EL19A addresses or scales.

## Required deliverable

A bounded report containing:
- Exact A2L characteristic metadata and source identity where used; clearly mark donor-only fields.
- Exact EL19A ROM addresses, extents, storage types, dimensions, axes/query evidence and instruction PCs where established.
- Reader/caller contract, transforms, branch conditions and first meaningful consumers where in scope.
- Separate structural, axis/scaling and functional confidence.
- Candidate-to-symbol matches, competing matches and disconfirming evidence.
- RomRaider disposition and exact unresolved boundary.
- Reused evidence, filters and explicit no-repeat list.

## Stop conditions

Stop if the source is unavailable or the candidate family is empty. No scripts, extracted files, indexes, A2L edits, XML/workbook/catalogue edits.
