### 3.1 Call site and helper structure

`sub_22AFC` has exactly one call site in the pinned LST (`0x5C28E`; symbol at L25904, pointer `off_5C4C4 = 00 02 2A FC` at L174867). At `0x5C288` `r4 = [off_5C4C0] = 0x0D8D6` (`00 00 D8 D6`). The two index registers at the call are:

| Input | Register at `0x5C28E` | Derivation (exact PCs) |
|---|---|---|
| A | `r5` = clamped y-derived index | `word_5C350 = 0x859C` → `mov.w @(h'10,r2),r0` = `U16[FFFF85AC]` (`0x5C270`); `extu.w`; `shll2`/`shll2`/`shll` = ×32 (`0x5C272–0x5C278`); `add r6` where `r6 = 0xFFFFF000` = −0x1000 (`0x5C264/0x5C266`); clamped `0..0xFFFF` against `r5=0xFFFF` and sign (`0x5C27C–0x5C286`). |

Inside `sub_22AFC` these become fixed-point fractions, not pointers:

- `0x22B02 extu.w r6,r3` and `0x22B06 extu.w r5,r4`; two calls to `sub_2354C` (`0x22B08`, `0x22B12`) perform 16× `shlr r4 / rotcr r5` to split the indices.
- `0x22B0C/0x22B0E` set `r0 = frac_A`, `r1 = 0`; `0x22B16/0x22B18` set `r2 = frac_B`, `r3 = 0`; `0x22B1C r8 = 0xF` (16−1 sentinel); `0x22B2A/0x22B2C shll r0,r2` apply the 2-byte word stride.
- `0x22B32` jumps to `loc_232D0`, which addresses the payload directly: `0x232D6 mulu r5,r0` (row × stride), `0x232D8 add r2,r4` (table + row), `0x232DE shll r5`, `0x232E0 add r0,r4`, `0x232E2 add r4,r5`, then `0x232EC mov.w @r4,r1` and `0x232EE mov.w @(2,r4),r0`, followed by `sub_231C8` bilinear interpolation.

No axis-array load (`mov.w @(axisN,...)`, pointer literal or table-relative fetch) exists anywhere in `sub_22AFC` or the two-block path through `loc_232D0`. `r0`/`r1` are recomputed fractions, not caller-supplied pointers.
