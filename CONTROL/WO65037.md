## Downstream arithmetic trace — 2026-11-17
- The paired outputs are staged at FFFF1708 (base FFFF1054+0x6B4, map ADF2) and FFFF1707 (base FFFF1054+0x6B3, map AF72) by sub_AE8CE at 0xAE910–0xAE930. Both use query UBYTE [FFFF859C+8], Y axis F4AE, and respective X axes F4CA/F50A.
- The common downstream path at loc_AE9EA reads UBYTE breakpoints x0=[0x8F09], x1=[0x8F0A] and threshold T=[FFFF84B4+6] (FFFF84BA):
  - If x1>=x0, it performs endpoint selection only: T>x1 selects FFFF1707; otherwise selects FFFF1708.
  - If x1<x0, T>x0 selects FFFF1707; T<=x1 selects FFFF1708; otherwise it linearly interpolates:
    **v = FFFF1708 + (FFFF1707−FFFF1708)×(T−x1)/(x0−x1)**.
  - Numerator multiplication is in MACL at 0xAEA2A; the JSR delay-slot instruction at 0xAEA38 transfers MACL to R1 for sub_21AC0, with denominator x0−x1 in R0. sub_21AC0 performs signed division. Result is clamped to UBYTE 0..255 at 0xAEA40–0xAEA4A.
  - If FFFF34AB.bit6 is SET, a signed byte offset [FFFF1054+0x386] is conditionally applied: the corrected value is accepted only when <=255, and negative results are floored at zero. If bit6 is clear, correction is bypassed. Final UBYTE is stored at FFFF1CA5 (0xAEA90–0xAEA92).
- Gate/sentinel path preceding interpolation: FFFF1D83+4.bit2 SET enters the interpolation/endpoint path directly. If that bit is clear, FFFF1D99+0x4B.bit4 CLEAR routes to the explicit 0x80 value; if bit4 is SET, FFFF34AB.bit6 SET enters interpolation while bit6 CLEAR routes to 0x80. Therefore interpolation is enabled by (FFFF1D83+4.bit2) OR (FFFF1D99+0x4B.bit4 AND FFFF34AB.bit6); otherwise the explicit 0x80 sentinel is written at 0xAE9D2/0xAEA90.
- A separate initialization writer sub_AE5C4 is called from 0x290E0 and writes 0x7E to both FFFF1708 and FFFF1707 at 0xAE602/0xAE608. This precedes the runtime sub_AE8CE lookup writer and proves the pair has an initialization/default writer as well as the paired lookup writer.
- The parent sub_AE680 calls sub_AE8CE at 0xAE680, then sub_AE942 at 0xAE68E, followed by sub_AEC4A at 0xAE6B4 (delay slot sets R4=0), sub_AEC7C, sub_AEE10, sub_AF014, sub_AF17A, sub_AF374 and sub_AF410. sub_AE942 is another possible FFFF1CA5 writer/override; therefore the final consumer state must not be attributed to sub_AE8CE alone without its branch conditions.
- Direct downstream consumers:
  - sub_AEC4A reads FFFF1CA5, subtracts byte [FFFF1D12+0x64+R4] (R4=0 at its parent call), adds 0x80, clamps to 0..255, and stores the UBYTE at FFFF1000+0x12 (FFFF1012).
  - sub_AF014 reads FFFF1CA5 and compares it with [ROM 0x8915+1]+0x80; depending on the comparison it stages a byte at FFFF1054+0x65E and updates status fields at FFFF1D99+0x50 and +0x93.
  - sub_AF374 explicitly compares FFFF1CA5 with 0x80, gated by FFFF860B.bit3 and additional status/range tests, before updating FFFF1D99+0x8C. This confirms 0x80 is consumed as a special state.
  - Separate routine 0x76D32 reads FFFF1707, subtracts [FFFF1D12+0x64], and clamps the signed result to [-128,127] for a local word result. It is an independent consumer of the 6B3 field.
- **Result:** the two map outputs are directly consumed as paired endpoint/interpolation values and feed a staged UBYTE state plus further signed-offset/threshold logic. The physical meaning of axes, maps, FFFF1CA5, and downstream status fields remains unassigned. ## Alternate FFFF1CA5 writer / override resolved — 2026-11-17
- sub_AE942 is called by parent sub_AE680 at 0xAE68E immediately after sub_AE8CE returns. It shares the FFFF1CA5 write/epilogue block at 0xAEA90–0xAEA94 and can therefore replace the value produced by the ADF2/AF72 interpolation path before later consumers execute.
- Entry selection:
  - FFFF8CC8.bit4 SET, or FFFF8CD6.bit1 CLEAR, routes to the common status/interpolation/sentinel gate at 0xAE9B4.
  - Otherwise, if FFFF8CD6.bit0 SET, it selects a byte source using ROM byte 0x87B3.bit1: SET selects FFFF85AC; CLEAR selects FFFFB2BC (= FFFFA378+0xF44). That byte is written directly to FFFF1CA5 at 0xAE9A8–0xAEA92.
  - Otherwise it tests FFFF84D4+0x3A.bit3. If clear, it returns without replacing the prior FFFF1CA5 value. If set, it reads UWORD FFFF8478+2, shifts right two (SHAR twice), clamps to 0..255, and writes the resulting byte to FFFF1CA5 at 0xAE998–0xAEA92.
  - The alternate branch to 0xAE9B4 reuses the previously documented gates: FFFF1D83+4.bit2 SET enters interpolation; otherwise the explicit 0x80 sentinel is used unless both FFFF1D99+0x4B.bit4 and FFFF34AB.bit6 are SET, in which case interpolation is entered.
- **Ordering consequence:** the final FFFF1CA5 value seen by sub_AEC4A/sub_AF014/sub_AF374 is the result after sub_AE942, not necessarily the value written by sub_AE8CE. The paired maps are one valid source path for the shared output field, not its exclusive producer.
