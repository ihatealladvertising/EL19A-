## Scope

1. Build a compact comparison of table extents, payload types, axis objects, query producers, helper contracts, mode gates, destination cells, scaling/threshold arithmetic, first consumers and confidence.
2. Distinguish three questions: (a) same physical ROM region/family; (b) shared software helper/consumer mechanism; (c) shared physical calibration function. Evidence for one does not prove the others.
3. Assess whether E904 and E914 share query generation, mode-dependent RAM structures, or threshold logic; assess whether E934 shares any of those or follows a separate producer/consumer path.
4. Reconcile any apparent contradictions between XML v3, the discovered-table catalogue, and the three trace reports. Record exact source/version and avoid editing source data.
5. Recommend one of: retain existing provisional XML identity with axis correction specification; leave as provisional; split/rename provisional table; or defer semantic naming. Each recommendation must state evidence and confidence.
6. Specify the minimum evidence required before any XML v4 edit or calibration promotion. Do not perform integration edits.
