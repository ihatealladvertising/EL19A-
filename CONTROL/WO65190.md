## Result

### 1. Payload and the two-value caveat — CONFIRMED

ROM bytes (`VERSA f501.bin`, pinned by WO65115):

- Rows 0–4 (`0x0B622–0x0B6B1`): every UWORD BE is `0x0040` (64).
- Rows 5–7 (`0x0B6B2–0x0B6A1` tail): every UWORD BE is `0x0000` (0).

The surface is a genuine two-level step object: value 64 for rows 0–4, value 0 for rows 5–7. The catalogue sample `[64, 64, 64, 64]..[0, 0]` is the raw shipped data, not an indexing artifact. No third value exists in the shipped image.

### 2. Sole reader: `sub_6988C` (0x6988C–0x699FE), GBR = `FFFF2F00`

Single call site of `sub_22CF8` for this map at `0x6992C` (confirms WO65060 / catalogue; also WO65120 call graph). Three entry gates, all tested on ROM/RAM status bytes:

| Gate | PC | Polarity to proceed | Shipped value | Effect in shipped calibration |
|---|---|---|---|---|
| `byte_8CD3.bit7` | 0x69898–0x6989C | must be CLEAR | `0x8CD3 = 0x80` (bit set) | **path disabled** |
| `byte_87C8.bit7` | 0x698A4–0x698A8 | must be SET | `0x87C8 = 0x00` | **path disabled** |
| `byte_8B52.bit7` | 0x698B0–0x698B4 | must be SET | `0x8B52 = 0x00` | **path disabled** |

With the shipped calibration the entire lookup is unreachable; every result below is the conditional behaviour if all three gates change.

### 3. Both query axes — RESOLVED

At `0x6991C–0x6992C`: `r4 = 0x0B622` (map), `r5 = 0x0F7D2` (axis A), `r6 = 0x0F7E2` (axis B), `jsr sub_22CF8` with delay slot `extu.w r0, r7`.

- **Row axis `0x0F7D2`** (8 UWORD BE: 0, 91, 182, 273, 364, 365, 636, 727) is queried by **`UWORD[FFFF992C]`** (`r7`, loaded at `0x69924` via `FFFF9916+0x16`). Note the near-duplicate breakpoints 364/365.
- **Column axis `0x0F7E2`** (8 UWORD BE: 0, 200, 300, 400, 500, 1000, 1050, 1500) is queried by **`UWORD[FFFF855E]`** (loaded at `0x6991E` via `FFFF8534+0x2A`, passed through a stack slot).

Inside `sub_22CF8` the first `sub_2340C` axis search (`0x22D04`) uses axis A with `UWORD[FFFF992C]`; the second (`0x22D12`) uses axis B with `UWORD[FFFF855E]`; tail `jmp loc_232D0` interpolates the 8-wide row (`r5=8`).

Query producers are **unresolved** at the bounded boundary: no direct UWORD writer to `FFFF855E` and none to `FFFF992C` appears in `EVIDENCE/WO65118_ram_byte_bit_xref.tsv` (the function itself only reads `FFFF992C` at `0x698D4/0x69900/0x69924` and stages copies to `FFFF2F60/FFFF2F62`).

### 4. Result path and first meaningful consumer — RESOLVED

- The lookup result (helper return, `r6`) is stored as a UWORD to **`FFFF3134`** at `0x6993A` (`GBR FFFF2F00 + 0x234`). Bounded check found **no reader of `FFFF3134`** in the RAM xref or in the function itself — the store is a dead store within static analysis, matching the catalogue's zero-consumer taint row.
- The **live first consumer is the in-register comparison chain** immediately after, a flag machine on byte `FFFF1E42` bit 7:
  1. `0x6993C–0x69956`: if `byte[FFFF1E42].bit7` is clear and the staged delta `UWORD[FFFF313E]` (computed earlier in the same pass from `UWORD[FFFF992C] − cached[FFFF2F62]`, clamped ≥ 0, at `0x698D8–0x698EA`) is **less than** the lookup result, set `FFFF1E42.bit7` (`0x69956`).
  2. `0x69958–0x69974`: gate `FFFF860D.bit3` set → if `UWORD[FFFF855E] < 690` (ROM word `0x922C = 0x02B2`), clear `FFFF1E42.bit7`.
  3. `0x69976–0x69986`: gate `byte[FFFF373E] == 0` → clear `FFFF1E42.bit7`.
  4. `loc_69988` (`0x69988–0x6998E`): unconditionally re-arms `FFFF373E` from ROM `byte_845B = 0x64` (100).

So the surface's output participates in a set/clear hysteresis on `FFFF1E42.bit7` against a staged delta and a fixed threshold of 690 on its own column query. Readers of `FFFF1E42.bit7` downstream are outside this WO's stop boundary and were not traced.

### 5. Pre-lookup decimation counter (context for the same function)

Byte counter at `FFFF32E2` (`GBR+0x3E2`): if < 3 it is incremented (`0x69912–0x69916`); on reaching 3 the one-shot block (`0x698C8–0x6990E`) runs (sets `FFFF35CB+2.bit4`, computes the `FFFF313E` delta from `UWORD[FFFF992C] − cached[FFFF2F62]` clamped ≥ 0) and resets the counter to 0 — a divide-by-3 decimation scheduling the delta refresh.

### 6. Caller / cadence

Trampoline `loc_69AC8` (`bsr sub_6988C` then falls into the sibling `sub_699FE`) is the pointer entry at ROM `0x217A8` — **index 18 (0-based) of the 62-entry callback table at `0x21760`**, dispatched by `sub_209A6` in `INT_ATU31_IMI3A` context (listing comment; consistent with WO65104's event-gated scheduler finding, no fixed period). The sibling `sub_699FE` shares the same three status-byte gates (inverse-polarity forms at `0x69A0A–0x69A1E`) and is likewise disabled in the shipped calibration; it is a separate computation (two `sub_21AC0` division-helper stages, byte maximum stored to `FFFF3234`) and is **not** a consumer of this map.
