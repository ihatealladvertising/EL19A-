## Objective

Independently test the reported reverse-direction relationship that sorting donor scalar symbols by ascending ROM address produces an almost alphabetical symbol-name stream. The reported claim is approximately 97% alphabetically ordered adjacent pairs in the 0x8000–0x97FF region for both V6 and Juke, with roughly 80 contiguous runs and a longest run of 603 symbols.

This is explicitly different from WO65285, which tested original A2L declaration order as a predictor of ascending ROM address and returned NO-GO. Do not alter, weaken or reinterpret that NO-GO result. This task tests only the inverse ordering direction and whether the apparent relationship is statistically meaningful and stable enough to serve as a local donor-alignment prior.

## Exact question and method

1. Reproduce the claimed 0x8000–0x97FF analysis independently for V6 and Juke. Define the primary population as unique-address scalar `CHARACTERISTIC` records whose A2L record type is `VALUE`; report `AXIS_PTS`, `CURVE`, `MAP`, non-VALUE characteristics, aliases and duplicate-address groups separately.
2. Sort the primary population by numeric ROM address, with a deterministic tie-break by exact symbol name and source declaration line. Preserve the original symbol spelling.
3. Primary adjacency statistic: count adjacent pairs for which the left symbol name is lexicographically less than or equal to the right symbol name using case-sensitive ordinal comparison; divide by all adjacent pairs. Report case-folded and natural-sort sensitivity separately, never substituting them for the primary statistic.
4. Define an ascending run as a maximal sequence of adjacent symbols whose names remain lexicographically nondecreasing. Report run count, run-length distribution, median, 90th percentile, maximum and the exact symbols/address range in the longest run. Explicitly state whether the reported “approximately 80 runs / longest 603” is reproduced under this definition.
5. Primary region is exactly 0x8000–0x97FF. Also report full-address-range results and fixed 1-KiB subregion summaries to reveal whether a global statistic hides local variation.
6. Evaluate a deterministic null baseline using at least 10,000 permutations per donor, fixed documented seed, preserving the observed population size and name multiset. Report the null distribution for adjacent-order fraction and longest run. Also run a within-1-KiB block shuffle to control for broad address-region composition. Report empirical p-values and effect sizes; do not rely only on a nominal 50% shuffled baseline.
7. Test sensitivity to duplicate/aliased addresses, exact-name case, removal of a common leading prefix only as a secondary diagnostic, and the inclusion/exclusion of symbols with non-ASCII or malformed names. Keep the primary result unchanged by these sensitivity variants.
8. Compare the observed stream with a fully alphabetical sort and report a rank/order association measure (for example Kendall's tau or Spearman rank correlation) if it can be computed without quadratic memory/time. State precisely what this measures and its limitations.
9. Do not use these donor-order results to assign any EL19A target address, calibration name, axis, unit, conversion, physical meaning or family relationship. The output may support only a documented, provisional local search/alignment prior.
