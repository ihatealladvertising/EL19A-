# WO65009 — Selector FFFF1D99+0x7A Bit 3 Writer and Gate

**Status:** COMPLETE — direct set/clear writer and parent sequence confirmed.
**Scope:** Resolve the writer used by WO65008 for selector bit 3 and its immediate input conditions.

## Evidence
- `sub_6F89A` calls `sub_6F4C0` at 0x6F89C, before its other processing helpers.
- `sub_6F4C0` sets GBR=FFFF1D99 and reads byte FFFF99F4+0x0D at 0x6F4C8.
- If that byte's bit 7 is CLEAR, the function sets bit 3 of GBR+0x7A (FFFF1D99+0x7A) using `or.b #8` at 0x6F4D2, then returns.
- If bit 7 is SET, it reads FFFF860B at 0x6F4D6. If FFFF860B.bit3 is SET, it returns without modifying selector bit 3. If FFFF860B.bit3 is CLEAR, it clears selector bit 3 using `and.b #0xF7` at 0x6F4DE.
- Thus the exact update rule is: `(FFFF99F4+0x0D).bit7 == 0` forces selector bit3=1; otherwise selector bit3 is cleared only when `FFFF860B.bit3==0`, and retained when that flag is 1.
- Parent `sub_6F89A` is called from `loc_6ECF0` at 0x6ECF6, immediately after `sub_6EAAC` and before jump to `loc_66DF6`.

## Relation to WO65008
- WO65008 established selector SET => curves 10206/10226; CLEAR => 10CC2/10CE2.
- WO65009 now establishes the selector's immediate state logic, but not the meanings or producers of either input flag.

## Unresolved
- Producer/meaning of FFFF99F4+0x0D.bit7.
- Producer/meaning of FFFF860B.bit3.
- Whether the selector update reflects a mode, inhibition, validity, or another control condition.
