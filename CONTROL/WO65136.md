## Coordinator erratum — E678/E688 gate polarity (2026-11-22)

The earlier selection wording above is superseded by the verified branch truth table in `CONTROL/WO65183.md` §3 (also reconciled in WO65015): while the calculation runs (`FFFF860B.bit3=0`), E688/`0x848B` is selected only when `FFFF85F8.bit4=0` **and** `FFFF8600.bit6=0`. If either bit is set, E678/`0x848A` is selected. When `FFFF860B.bit3=1`, both lookup calculations are bypassed. The flags' physical names and any Drive/Neutral interpretation remain unproven. This correction changes the selector polarity record only; it does not change table geometry, query mechanics, or calibration semantics.
