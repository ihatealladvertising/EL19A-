## Objective

Resolve the genuine 0-row terminal word cell exposed by WO65500's paired-byte reset. With `r6=FFFF2150` loaded at `0x800C4` from `off_801C0`, `0x800C6` loads `r0=h'5AC` and `0x800CA` writes `r2=#FFFF` to `FFFF2150+0x5AC=FFFF20FC` after the `FFFFA6FD`/`h'386`/`h'388` zero writes. The same `h'5AC` literal also appears in an `SR`/`loc_80808` path under an `r12` base that must be re-proved or excluded, and in a `0x9F0xx` cluster under `FFFF1054` that resolves to `FFFF1600`.

Test whether this terminal cell reaches a consequential compare, state export, previously dispositioned state cell or one of the six discriminator cells.

## Scope

1. Using WO65117/WO65118 plus targeted pinned-listing checks, enumerate every direct reader/writer of the logical `FFFF20FC` cell with exact PCs, raw bytes, base provenance and immediate next compare/state write. Both `FFFF20FC` and `000020FC` have **0 exact rows**, and `h'20FC`/`h'FFFF20FC` have 0 LST hits; declare that explicitly.
2. Account for all 16 exact `h'5AC` rows: 9 CODE (`0x800C6`, `0x80802`, `0x80808`, `0x9F038`, `0x9F116`, `0x9F3A4`, `0x9F3F8`, `0x9F40E`, `0x9F5DA`) and 7 DATA (`.data.w h'5AC` at `0x800E0`, `0x808AA`, `0x9F0A6`, `0x9F260`, `0x9F408`, `0x9F49C`, `0x9F660`). The `0x800CA` write is the accepted endpoint access; re-prove or exclude all other CODE rows by base.
3. Re-prove `r6=FFFF2150` at `0x800C4` → `0x800CA` with 0 intervening writes and recompute the word EA once: `FFFF2150 + 0x5AC = FFFF20FC`. Determine the `r12` base for `0x80802`/`0x80808`; do not assume it from the `FFFF2150` value in the earlier routine. Reject the `0x9F01E`/`0x9F0EA` `FFFF1054` bases that resolve to `FFFF1600`, and re-prove the other `0x9F0xx` bases before exclusion.
4. Note but do not retrace `FFFFA6FD`/`FFFFA378` (WO65500), `h'386`/`h'388`, `h'588`, `FFFFA074`, `FFFF1054`, `FFFF1600`, the SR interrupt-mask path, `0x8B42` table contents or helper bodies.
5. Check direct absolute literals, `@(h'5AC,gbr)` and other scaled-GBR forms. `FFFF20FC` is 0 mod 4, so an aligned longword could start there; confirm by absence of a `mov.l @(r0,rN)` within six instructions after any `h'5AC` literal and by exact `h'20FC` checks.
6. Run one bounded discriminator against `FFFF2BF6`, `FFFF3085`, `FFFF3031`, `FFFF11B8`, `FFFF11BC` and `FFFF130B`; a negative is acceptable. No physical family name, unit or conversion may be promoted from these state cells.
