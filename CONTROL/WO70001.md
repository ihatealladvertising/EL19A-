## Objective

Implement Operating Protocol v4 across the repository so 2–3 concurrent sessions (mixed local Git IDEs and stateless AI Studio containers) allocate work orders without ID collisions, lock target scopes in per-WO files, and rely on a single serialized GitHub Action on `main` to rebuild `CONTROL/WO_LIVE_INDEX.md` and the dashboard block inside `CONTROL/active_work_orders.md`.

3. **`tools/wo_registry.py`**: Stdlib-only CLI supporting `validate`, `rebuild`, `next-id`, and `init` with legacy-tolerant parsing (`WO64828`–`WO65163`), canonical hex/range scope normalization, conflict detection, `BLOCKED -> READY` dependency resolution, and 24-hour soft-lease staleness checks.

6. **`CONTROL/WO_LIVE_INDEX.md`**: Initial deterministic ownership dashboard generated directly by `tools/wo_registry.py rebuild`.
