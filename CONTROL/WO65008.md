# WO65008 — Conditional UWORD Curve-Pair Selection at 0x6F6F0

**Status:** COMPLETE — selector and paired output contract confirmed.
**Scope:** Resolve the local branch between 10206/10226 and 10CC2/10CE2, common axis/query, and immediate result staging. No semantic expansion.

## Evidence
- At 0x6F6EA–0x6F6EE, code reads FFFF1D99+0x7A and tests bit 3.
- If bit 3 is SET, branch at 0x6F6F0 selects loc_6F76C:
  - R4=0x10206; R13=0x109B4; UWORD [FFFF9860+0x18] is zero-extended to R6; sub_22F80 called at 0x6F778 with R5=109B4 in delay slot 0x6F77A.
  - R4 changes to 0x10226 at 0x6F77C; first result is saved to local var_24 at 0x6F77E.
  - Fall-through at 0x6F780 performs the second sub_22F80 call with R4=10226, same axis 109B4 and same query field.
- If bit 3 is CLEAR, execution enters the 10CC2/10CE2 path documented in WO65006: first lookup at 0x6F6FE, second at 0x6F784, same axis/query.
- Both branches converge on the same local staging/arithmetic sequence. The two selected lookup results are written to FFFF2150+0x9FE at 0x6F792 and FFFF2150+0xA00 at 0x6F798.
- The 10206/10226 pair's use of shared axis 109B4 is consistent with WO64987; WO65006 independently establishes the 10CC2/10CE2 pair on that axis.
