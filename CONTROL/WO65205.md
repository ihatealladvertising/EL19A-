## Decision question

Can the existing WO65106 ATU/timer output-channel inventory be traced backward to an EL19A ignition-advance value, selector and trim path, with an instruction-supported boundary at the final output staging?

## Required reuse

- WO65106 output/actuator endpoint inventory and its exact ATU channel/register anchors.
- WO65104 timebase/scheduler findings and WO65116–WO65122 function, GBR, EA, RAM-xref and callgraph indexes.
- Existing ignition/knock fragment and reader reconciliation WO65109.
- Do not repeat the global MMIO census, timer inventory or broad RAM scan.

## Investigation

1. Select only the ATU output channel(s) explicitly identified by WO65106 as plausible ignition timing outputs. If WO65106 does not establish a specific channel, report the missing anchor and stop rather than guessing.
2. Trace the output register's immediate producer and staging buffer backward through direct stores, computed pointers and known copy/transport helpers.
3. Identify the last software value before hardware encoding. Trace its producer chain to candidate base advance, load/temperature/knock trims, limiters and selector gates only where directly connected.
4. Resolve units/scale only from target-side arithmetic and constants; distinguish timer ticks, angle-domain values and encoded compare values.
5. Identify task/ISR/cadence only where the existing scheduler evidence directly supports it.
6. Stop at unresolved peripheral/DMA/interrupt or external ignition-driver boundaries.

## Required deliverables

- Exact ATU output channel/register and WO65106 evidence reference.
- Backward instruction trace table: PC, opcode/effect, source, destination, width, condition and effective address.
- RAM staging/producer graph and first meaningful consumer(s).
- Candidate ignition advance and trim paths with separate structural, software-role and physical-domain confidence.
- Explicit negative findings and a ranked next discriminator.

## Stop conditions / budget

- No new MMIO census and no ROM-wide literal scan.
- Maximum 3 backward hops across already-indexed functions before requiring a concrete next edge.
- Stop if no unique ignition-specific output anchor exists or if the path terminates at an unresolved hardware/transport boundary.
- No physical vehicle testing.

## Acceptance criteria

A result must connect a WO65106-identified output endpoint to a target-side software value by instruction-derived stores/loads and caller context. Similarity to donor labels or expected ignition behavior is insufficient.

## Artifact boundary

Read-only use of existing EL19A ROM/LST and merged indexes. Modify only this assigned WO report on this branch. No ROM/LST/XML/A2L/workbook/catalogue/index/script/tool/Library edits are authorized.
