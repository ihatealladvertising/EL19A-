## Objective

Build a ranked, evidence-backed donor crosswalk from the V6 master A2L to the 179 EL19A reader-verified varying calibration candidates. Use A2L characteristic declarations, axes, conversion methods, function groups and associated measurements to find meaningful matches that raw dimensions or Nissan-like names alone would miss.

## Bounded scope

1. Parse only the A2L declarations needed to compare against the current 179 catalogue rows: `CHARACTERISTIC`, `AXIS_DESCR`, referenced `AXIS_PTS`, `COMPU_METHOD`, `FUNCTION` / `FUNCTION_LIST`, and linked `MEASUREMENT` declarations. Do not attempt a complete A2L re-documentation.
2. For each EL19A catalogue object, screen donor candidates by:
   - record type, storage width, signedness, endian and dimensions;
   - explicit/fixed axis count, axis storage type, raw points and engineering conversion;
   - output conversion method, units and numerical range;
   - named function / calculation group and its description;
   - related runtime measurements, RAM addresses and status flags.
3. Produce a compact matrix covering all 179 EL19A rows. A target row with no credible donor match must still appear, classified as no match / insufficient evidence. A single A2L characteristic may be a competing candidate for more than one target; preserve ambiguity rather than forcing one-to-one matches.
4. Add a focused comparison for adjacent high-priority EL19A objects outside the 179-row catalogue where the repository already documents them: `0xE678/0xE688`, `0xF3D6/0xF3DE`, and `0x0FEE0`. Identify the target source document used for each.
5. Rank the results and identify the five most discriminating follow-up tests. Do not perform those deep target traces in this WO.

## Required output in this WO record

- One row for every EL19A catalogue candidate, with target address/geometry/helper/axis fields and candidate A2L symbol(s).
- For each A2L candidate: donor ROM address, record type/width/dimensions, axes and donor axis addresses, exact COMPU_METHOD formula/units, FUNCTION_LIST and useful related MEASUREMENT names/ECU addresses.
- Separate columns/labels for structural match, axis/scale match, calculation-family match and confidence. Include explicit disconfirming evidence.
- Ranked shortlist and false-positive examples; list unresolved candidates as unresolved, not failed or unused.

## Acceptance / stop conditions

- No candidate is called a verified EL19A physical calibration solely because the V6 symbol name sounds appropriate.
- A strong crosswalk needs at least two independent discriminators beyond table dimensions (for example axis conversion plus related function/measurement path, or exact payload/scale correspondence plus function context).
- Keep structural, software-role and physical-domain confidence separate.
- Stop at a missing donor measurement/function link or unresolved EL19A software boundary; record it rather than guessing.
