**mTADVC1/C2 (Jar sound compensation):** "Jar sound" is likely a translation of knock/pinging detection. Referenced by KF7-320A.23 "Ignition timing control for splashing noise correction". Competing interpretation (general noise compensation) is less specific; knock/retard role is supported by function context.

**mTKADVA/R (K2Y/K1 tables):** Symbol names use K-suffix abbreviations without explicit knock keywords in descriptions. Referenced by KF7-320A.15 "Calculation of ADV phase control value at acceleration". Classified as knock-adjacent based on K-suffix convention and ADV phase context; ambiguous — no explicit knock keyword in description.

**mPIADVAT (DUETTE Pi per cent table):** Referenced by KF7-385.2 "DUETTE control for normal AT". DUETTE is torque control; this may modulate ignition advance as part of torque management. Competing interpretation (pure fuel/air torque) is possible; ignition role is not explicit.

**No conflicting symbol matches** were found within the MAP/CURVE set for any category; each functional area has a distinct donor symbol set.
