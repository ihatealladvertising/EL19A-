# WO65324 — Scalar and support-curve classification for the provisional RR definition

**Status:** ASSIGNED — WORKER 2 — READY  
**Priority:** P1  
**Owner:** Worker 2  
**Dependencies:** Reuse the 179-row catalogue, existing scalar sweep (including WO65090), verified scalars and donor A2L inventories.

## Objective
Build the best-supported inventory of EL19A scalar calibrations and high-value 1D support curves needed for a useful high-level RomRaider definition.

## Scope
- Reconcile already discovered EL19A scalars, limiters, thresholds, multipliers, correction rates and mode selectors.
- Identify 1D curves that serve as axes, breakpoints, support schedules or calibration inputs to major maps.
- Use MR16DDT/Juke, MR18DE-related and V6 A2L metadata only to generate/rank naming hypotheses and identify likely shared versus forced-induction-specific families.
- Separate actual EL19A ROM objects from RAM constants, code constants, duplicate placements and donor-only objects.
- Do not repeat the completed 0x7800–0x9B00 sweep or launch broad scans.

## Evidence rules
For each candidate record address, width/signedness, dimensions, raw range, reader or direct consumer evidence, scaling evidence, donor analogue (if any), confidence tier and unresolved issue. Never transfer A2L addresses, COMPU_METHODs, units or names as target facts.

## Deliverable
A deduplicated scalar/curve manifest ranked for RR inclusion, using **Established**, **High-confidence provisional** and **Exploratory** tiers. Flag missing high-impact scalar families and distinguish turbo-only donor features from plausible MR18DE counterparts.

## Stop conditions
Stop when the known scalar and 1D candidate inventory has been reconciled without repeating completed searches. No XML or workbook edits.
