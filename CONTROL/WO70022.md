## 7. Recommendations

### 7.1 Minimum Python Version
**Recommend: Python 3.10+** (allow 3.11 as CI baseline, 3.10 for Windows compatibility).

**Rationale:**
- All scripts use only stdlib features available since 3.7 (`dataclasses`, `pathlib`, `typing` generics)
- `zoneinfo` (3.9) not used; `tomllib` (3.11) not used
- Windows 10/11 ships with 3.10+ via Microsoft Store; 3.12.10 is current local
- CI pins 3.11 — aligning CI to 3.11 and documenting 3.10+ as minimum avoids version skew
- **Do not require Python 2.7** (`C:\Python27\python.exe` is a legacy workflow; no script supports it)

### 7.2 Dependency Policy
**Maintain stdlib-only for core.** Optional third-party adapters only behind feature flags:
- `lxml` for faster XML (optional, `xml.etree` is sufficient)
- `pyyaml` if YAML config needed later
- `pandas` only for review-time CSV/TSV, never in pipeline

**No `requirements.txt` needed today.** Create one only when a justified optional dependency is added.

### 7.3 Test Strategy
| Layer | Approach | Fixtures |
|---|---|---|
| Unit | `unittest` (existing) | Synthetic in-memory ROM/listing |
| Regression | Golden JSON/TSV outputs | Committed `tests/fixtures/` with known ROM hashes |
| Integration | Optional, gated | Real ROMs via environment variable (not in CI) |
| CI Matrix | Add 3.10, 3.11, 3.12 on ubuntu-latest + windows-latest | Same synthetic fixtures |

**Proposed `tests/` layout:**
```
tests/
  fixtures/
    synthetic_rom.bin         # 64KB minimal SH-2 ROM with known helpers
    synthetic.lst             # Matching listing
  test_unit_scanner.py
  test_unit_indexer.py
  test_unit_registry.py
  test_regression_golden.py   # Compares JSON/TSV output to committed goldens
  conftest.py                 # pytest fixtures (if pytest adopted)
```

### 7.4 CLI Conventions
Adopt a shared `lib/romtool/cli.py` with:
- `add_common_args(parser)` — `--rom`, `--listing`, `--out`, `--json-out`, `--verbosity`
- `validate_inputs(args)` — hash checks, path existence
- `setup_logging(verbosity)` — structured `logging` with levels
- `run_manifest(args, outputs)` — deterministic JSON manifest with hashes, timings, command line

Each standalone script imports the shared CLI helpers; no monolithic launcher required.
