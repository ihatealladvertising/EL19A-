## Objective

Determine whether the timer-capture-derived query used by the QDSPT curve reader at `0xE678/0xE688` can be expressed in a defensible EL19A physical or normalized unit, and whether the existing timer/timebase and pin-mux evidence supplies a valid axis conversion. The query itself and its reader mechanics are already established; this WO tests only the missing numeric-domain link.

## Established facts — do not repeat

- WO65095: `sub_403D8` forms `q = min(UWORD[FFFF85AE] >> 1, 0xFF)`; the `sub_22E10` helper uses an implicit 16-count grid 0,16,…,240 and rejects q >= 0xF0.
- WO65095: `FFFF85AE` is supplied by timer-capture-derived state chain `FFFF85E4 → FFFF8596 → FFFF85D6 → FFFF85AE`.
- WO65181: related F3D6/F3DE query derives from `FFFF8596`, itself produced from capture-interval state; the exact capture tick source and timer period were not resolved there. Reuse its arithmetic and interrupt context; do not assume the two calibration queries have identical final scaling.
- WO65104 / WO65115: reuse completed timebase, timer and pin-mux evidence only where it directly constrains this capture path.
- V57's displayed Rev Hang axis 0–6000 RPM in 400-RPM steps is a fingerprint/source hypothesis, not an EL19A axis definition.

## Mandatory falsifiable hypothesis

- **Hypothesis:** existing timer/timebase and pin-mux evidence permits a target-side conversion from the capture-derived query to a stable period/frequency/speed-like unit, or establishes a precise missing hardware boundary that prevents conversion.
- **Prediction:** the capture source, clock basis, prescaler and interrupt/capture channel can be identified from existing pinned evidence without new broad scans.
- **Falsifier:** capture sample provenance or clock configuration crosses an unresolved MCU/peripheral/board boundary, so no defensible physical conversion is available from current artifacts.
- **Identity layer advanced:** query numeric domain and possible axis unit; no semantic table rename by resemblance.

## Acceptance

A precise bounded negative is a valid completion. The report keeps the V57 screenshot axis separate from the target's proven timer representation and does not label the query RPM without a target-side clock and signal conversion.

**Disposition:** The timer-capture-derived QDSPT query is a **capped reciprocal index** (`min(UWORD[FFFF8596] >> 7, 0xFF)`) on a 16-point UBYTE grid (0,16,…,240). The upstream capture interval `FFFF85E4` originates from a RAM word `FFFF14E0` whose producer and clock/prescaler/channel relationship are **unresolved**. The SH7058 ATU-II channel-0 `φ/32` divider is known at the device level, but `FFFF14E0` is not linked to ICR0A/TCNT0. The 48,000,000 numerator is an arithmetic constant only. **No defensible physical conversion (period, frequency, RPM, or normalized unit) is available from current artifacts.** The exact missing fact is the producer of `FFFF14E0` and its hardware timebase.
