## Method

For each payload index `i`, the delta stream was `d[i] = (tuned[i] − stock[i]) mod 256` over the full 1 MiB. For periods `p = 1..64`, bytes were partitioned into `p` columns by `i mod p`. Per column:

- **IoC** = `Σ_x n_x(n_x−1) / (n(n−1))`; uniform reference `1/256 = 0.00390625`.
- **Entropy** = Shannon entropy in bits/byte; uniform reference `8`.
- **Max-frequency share** = `max(n_x)/n`; uniform reference `1/256`.

The five periods carried forward were ranked by IoC excess, tie-broken by entropy deficit then max-frequency excess: **64, 32, 52, 48, 4**. For each, the per-column MFB additive delta key was derived from the whole delta stream. Tuned first 4 KiB were decoded as `(tuned − key) mod 256`; stock first 4 KiB were decoded in the reverse direction only as `(stock + key) mod 256`. Printable means ASCII `0x20–0x7E`; runs are maximal and reported only at length >=8.
