## Objective
Trace a small, high-information set of sensor/actuator diagnostic monitor callsites backward from DTC trigger conditions to inputs, threshold constants/tables, RAM producers and any calibration readers. Prioritize P0325, P0456, P1110, P2119 and P2100, plus reported flag_byte=0x43 slots only where exact crosswalk identities and callsites are confirmed.

## Falsifiable hypothesis
- **Hypothesis:** at least one selected monitor compares a target-side sensor/control value against a ROM-resident threshold or lookup result before setting its DTC slot; the 0x43 zero-static-writer cases may be populated through shared/indexed/bitfield helpers rather than being genuinely writerless.
- **Evidence:** exact DTC crosswalk rows, writer index, WO65174/65218 callsite/dispatcher evidence and target LST PCs.
- **Prediction:** selected DTC paths expose concrete input variables, comparison/qualification logic and the write/helper that sets the corresponding slot.
- **Cheap discriminator:** resolve one representative callsite per selected DTC from crosswalk slot → helper caller → condition operands → first DTC-state write; inspect the 0x43 writer mechanism only for selected active slots.
- **Result:** unresolved until traced.
- **Information gain:** separates sensor input identity from diagnostic dispatch identity and determines whether anonymous thresholds have monitor-specific roles.
- **Identity layer:** input identity and function identity; calibration identity only if an actual reader and compatible consumer path are reached.
