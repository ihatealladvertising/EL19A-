## Decision question

For a bounded set of high-priority EL19A RAM candidates, can donor A2L/logger symbols be mapped through independently aligned functions and matching read/write roles without transferring unsupported physical names or units?

## Investigation

1. Select at most 15 candidates from WO65207's ranked list, preferring RAM with independent Mode 01, DTC/monitor or known sensor/output anchors.
2. For each candidate, establish EL19A access width, signedness, writer/reader roles, function context and first meaningful consumers from target evidence.
3. Use only function pairs accepted under WO65204's alignment criteria. Compare donor A2L/logger measurements and their function/callsite roles.
4. Classify each proposed correspondence as: exact structural/software-role match; partial role match; contradicted; or unresolved.
5. Keep donor symbol, target address, target software role, physical interpretation and unit as separate fields. Promote no physical label or conversion without target-side evidence.
6. Cross-check existing Mode 01 PID anchors (ECT, RPM, VSS, timing advance, IAT, throttle position, module voltage, commanded/relative throttle) and WO65174 DTC monitor paths. Do not recreate the PID map.

## Required deliverables

- Candidate-by-candidate correspondence matrix with both ROM function anchors and RAM access evidence.
- Explicit alignment provenance and evidence for each donor symbol.
- Contradictions, false positives and confidence levels.
- A small set of proposed target-side names only where evidence supports them; otherwise retain generic addresses.
- Follow-up list limited to missing target-side discriminators.

## Stop conditions / budget

## Acceptance criteria

Every accepted correspondence must have both an aligned function path and matching target-side access/consumer behavior. Donor name or unit alone never establishes EL19A identity.
