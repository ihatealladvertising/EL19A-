## Decision question

Use the CF48D donor ROM and SH3B LST to trace the three XML-declared starts `0x8DD1`, `0x8ED1`, and `0x8FD1` through actual reader callsites. Specifically test whether `0x8DD1`/`0x8ED1` are aliases/duplicate tables or overlapping XML views, and whether `0x8FD1` is a separate selected calibration. ## Decision question dispositions

| Question | Disposition | Basis |
|----------|-------------|-------|
| Are 0x8DD1 and 0x8ED1 aliases/duplicate tables? | **Contradicted** | Different ROM storage addresses (0x8DD1 vs 0x8ED1); separate `.data.l` constants (off_318CC vs off_318C0); selected by different conditions (0x8DD1 used in loc_31686/31714/31828 paths; 0x8ED1 used in selector bit6 and B624>B625 paths). Same axes (B624/B634) and same declared dims (16×16) do not make them aliases. |
| Is 0x8FD1 a separate selected calibration? | **Established** | 0x8FD1 is the default map base (loaded unconditionally at 0x315F2 into r14); selected when selector_byte2 bit6 is clear AND not overridden by B624>B625 path; also directly read by secondary consumer at 0x2D9A0. Separate ROM region from 0x8DD1/0x8ED1. |
| Are all three maps 16×16 with shared axes? | **Established** | XML declares all three as 16×16 with X=0xB624, Y=0xB634; sub_701C uses h'F mask for both axes (4-bit index = 16 elements); GBR=B624 set at 0x315E6; axis read at B624/B625 (0x31608-0x3160A). |
| What is the element width and stride? | **Established** | Element width = 1 byte (UBYTE); `mov.b` reads; h'F mask = 15 (4-bit index); row stride = 16 bytes; extent = 256 bytes per map. |
| What is the selector chronology? | **Established** | 1) Default = 8FD1. 2) selector_byte2 (FFFF23AC) bit 6 → 8ED1. 3) selector_byte1 (FFFF23AE) bit 0 → r6 flag. 4) Axis compare B624 vs B625 determines branch path. 5) B624 > B625 → 8ED1, then check r6 bit0 and B624 bit1. 6) B625 >= B624 → loc_31834 path with 8ED1. 7) 8DD1 used in loc_31686/31714/31828 sub-paths. |
| Effective extent per map? | **Established** | 256 bytes (16×16×1 UBYTE), starting at each map's storage address. |
