## Objective

Resolve the highest-value remaining EL19A ignition/knock calibration candidates against target readers and consumers, using the new A2L VALUE descriptions and address-sorted metadata only as candidate generators.

## Scope

1. Start from the existing ignition fragment, 179-row catalogue, scalar candidates and closed reports. Do not repeat WO65287/WO65290 mechanics; continue only unresolved semantic boundaries.
2. Use the supplied 64811000p2_m.a2l VALUE symbol/description inventory to identify plausible ignition/knock families (advance limits, knock retard/recovery, cylinder-specific compensation, cold/intermediate-coolant retard, dwell-related scalars). Preserve exact donor symbol, description, donor address and storage/conversion metadata.
3. For no more than 8 target candidates, test target-side reader/caller context, raw width/signedness, exact consumer arithmetic, selectors and first meaningful spark/knock/dwell output. A donor name match alone is insufficient.
4. Explicitly test whether mADVADH/mADVADL/mADVAMX/mADVFAL/mADVRMX and mA5TP1/mA5TVO/mA5TWD have plausible EL19A counterparts; allow a negative result.
5. Return candidate-by-candidate RR disposition and separate target function confidence from donor metadata confidence.

## Required deliverable

A bounded report containing:
- Exact A2L characteristic metadata and source identity where used; clearly mark donor-only fields.
- Exact EL19A ROM addresses, extents, storage types, dimensions, axes/query evidence and instruction PCs where established.
- Reader/caller contract, transforms, branch conditions and first meaningful consumers where in scope.
- Separate structural, axis/scaling and functional confidence.
- Candidate-to-symbol matches, competing matches and disconfirming evidence.
- RomRaider disposition and exact unresolved boundary.
- Reused evidence, filters and explicit no-repeat list.

## Stop conditions

Stop after the eight highest-information candidates or when the next semantic endpoint is unresolved. No broad ROM scan, no duplicate trace of closed WOs, no XML/workbook/catalogue edits.
