## Objective

Resolve the target-side semantic inputs and first meaningful output use for the paired EL19A 8×8 UWORD BE maps at `0x0B756` and `0x0B7D6`. Specifically:

1. Trace both calls into `sub_22CF8` (known callsites `0x39FD2` and `0x39FE2`) to recover the actual query values in R7 and on the caller stack, including exact source RAM/ROM addresses, widths, signedness, arithmetic transforms, clamps, and branch selection.
2. Trace the query producers backwards only as far as required to establish whether the two axes can defensibly be interpreted as engine-speed-like and time/throttle-like domains. Do not inherit V6 RPM/ms units solely from numeric compatibility.
3. Trace the returned map values and the staged `FFFF86D4+0x0E` result forward to the first meaningful consumer, including any scaling, accumulation, flag/gate, mode selection, or downstream storage.
4. Compare the two map branches at the level of caller/query/output behavior. Preserve the fact that `0x0B756` varies while `0x0B7D6` is a constant `0x8000) surface; do not infer the latter is disabled or a trustful bank without code evidence.
