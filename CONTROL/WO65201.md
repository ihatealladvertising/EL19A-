## Finding

**Curve 0x0E9EC has no first downstream consumer.** Both outputs of `sub_40F18`'s curve-reading path are dead stores:

1. **Axis pointer byte** (ROM 0x08ACD) → `FFF2740`: never read externally
2. **Curve 0x0E9EC output** → `FFF2741`: never read externally

The curve is read via `sub_22DF8` (8×1 UBYTE) behind a 5-gate chain:
1. ROM 0x8A88.bit7 == 0
2-4. Three sub_224EC gate calls return nonzero
5. sub_224EC gate #5 returns nonzero AND GBR+0x56.bit0 == 1

Query = low byte of `FFF85B2`-adjacent word `FFF84D4` (0xD4 = 212 → curve index 6 → output 0x91 from curve data `80 80 80 80 81 89 91 9A`).

Both staging cells are `UNDEFINED .res.b 1` with zero external references. The axis pointer 0x08ACD is preserved (byte read from ROM and stored to RAM) but its stored value is never consumed.
