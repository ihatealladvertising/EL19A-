## Result

**All 261 scope-matrix rows have an explicit alignment and Release 1 XML disposition.** The 254 INCLUDE rows correspond exactly to the 254 top-level calibration objects in Release 1; all seven EXCLUDE rows are alternate/overlay rows that share addresses with included objects and are not themselves included. There are 12 exact address intersections with the scalar alignment file: seven Tier A, zero Tier B and five Tier C. No matrix row is missing from the alignment audit's address join due to a parser failure; 249 rows simply have no alignment TSV entry.

The most important correction candidate is **0x0924E**. The current Release 1 XML still displays `[P] QDSPT APO Compensation Change Rate [S] mDDPAPO (924E)` as a uint16 BE scalar with `Percent_UWORD_100_256` conversion. WO65324's target-side disposition is that 0x924E is a binary enable factor and is **not established as mDDPAPO**. This audit flags the name/conversion conflict but does not edit the XML or scope matrix.

### 0x0924E — stale mDDPAPO XML assignment

- Alignment TSV: no exact row at 0x0924E.
- Scope matrix: INCLUDE — PROVISIONAL, mDDPAPO label and `Percent_UWORD_100_256`.
- Actual Release 1 XML: present as a 1D uint16 big-endian scalar with the same label and scaling.
- WO65324 target-side boundary: binary enable factor; not established as mDDPAPO.
- Disposition: **confirmed release-scope conflict; correction required in a separate authorized XML/matrix change**. This WO did not modify either protected file.

### 0x08550 — generic hysteresis threshold

The Tier A donor crosswalk includes the donor-side mDSHCUT association, and the current matrix/XML retain a coolant-minimum label and `Temp_Coolant_Min`. WO65324 establishes only a generic UBYTE hysteresis threshold on an internal dashpot-target path; coolant identity remains unresolved. Do not promote mDSHCUT or coolant conversion as established EL19A semantics.

### 0x0848A / 0x0848B — deferred to WO66032

Both rows are Tier C. Their donor labels and D/N split are not proven. WO66032 owns the Findings migration and target-side interpretation correction; this WO records the crosswalk tier and actual XML presence without pre-empting that work.
