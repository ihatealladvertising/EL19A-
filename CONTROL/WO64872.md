## Confirmed

- E688 path: `0x404C2–0x404D8`. `sub_22E10` returns UBYTE lookup result in R2; UBYTE `R11+0x622` is copied to R5; ROM byte `0x848B` is loaded via `off_40614`; `mulu R2,R5` produces a 32-bit product; low 32-bit MACL is stored as UWORD at `R11+0x39C` (`0x404DA`). The selected raw scalar byte at `0x848B` is also loaded into R2 at `0x404DE`.
- E678 path: `0x40512–0x4052C`. Same pattern with table `0xE678` and ROM byte `0x848A`; lookup result × UBYTE `R11+0x622` is stored as UWORD at `R11+0x39C` (`0x4052A`). Raw scalar byte `0x848A` is loaded at `0x4052C`.
- Both paths converge at `0x4052E`, storing the selected scalar byte to `FFFF2150+0x296 = FFFF23E6` (`0x40530`).
- Therefore 0x848A and 0x848B are confirmed UBYTE scalar operands, selected one-at-a-time with the corresponding E678/E688 branch. They are not table axes and are not proven percentage values.
- Branch selection: E688/0x848B requires `FFFF85F8.bit4 = 1` AND `FFFF8600.bit6 = 1`; otherwise the E678/0x848A path executes (assuming the earlier FFFF860B.bit3 path has not bypassed the lookup).
- Both products use a second runtime UBYTE factor `R11+0x622`; R11 base provenance and physical units are unresolved.

## Interpretation boundary

The scalars plausibly act as per-branch multipliers in the QDSPT calculation, but the code does not establish the human-facing names `mDDSHPTD/N`, units, percentage scaling, or Drive/Neutral identity. Keep names provisional and retain the raw UBYTE interpretation only.

## Coordinator erratum — E678/E688 gate polarity (2026-11-22)
