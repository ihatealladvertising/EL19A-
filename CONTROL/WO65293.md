## Objective

Screen only still-unassigned 3D maps in the 179-row target catalogue for credible ignition/fuel functions, prioritizing target reader/query contracts, relevant A2L function-group matches and caller arithmetic. Produce a short ranked shortlist for definition completion.

## Mandatory falsifiable hypothesis record

- **Identity layer advanced:** function identity and output identity.
- **Hypothesis:** One or more currently generic 3D catalogue rows may be ignition correction, fuel quantity/compensation, AFR or mixture-control tables not identified by morphology-only discovery.
- **Evidence:** exact EL19A ROM addresses, instruction PCs, existing report/index anchors and source classes; distinguish target evidence from A2L/donor metadata.
- **Prediction:** if supported, the specified target-side reader/caller/consumer or independent ordering relationship will be observed.
- **Cheap discriminator:** perform only the bounded scope below using existing indexes, ROM/LST evidence and reports.
- **Result:** record supported, weakened, rejected or unresolved; do not claim unrun tests.
- **Information gain:** distinguish the named competing calibration identities or determine exactly which RR fields can be safely populated.

## Scope

1. Start from current 179-row catalogue and exclude candidates explicitly rejected, disputed, constant/sentinel-heavy or semantically closed in WO64903/WO64904 and related reports.
2. Join remaining rows to existing V6/CF48D/Juke A2L metadata crosswalk; use function groups, dimensions, storage, axis types and conversion as candidate generators only.
3. Prioritize 16x16/8x8/4x4 candidates whose target query variables or first consumers are already known; reuse completed reader/query work without repeating it.
4. For each shortlisted table, test immediate consumer arithmetic and caller context for spark advance, dwell, injector pulse/base fuel, lambda/AFR, trim or fuel-cut discriminators.
5. Reject candidates supported only by numeric range, table size, donor name or address proximity. Deliver no more than 12 ranked leads.

## Required deliverable

A bounded report containing:
- Exact target addresses, extents, storage types, dimensions and axis/query evidence where established.
- Relevant target instruction PCs, caller/reader contract, transforms, branch conditions and first meaningful consumers where in scope.
- Separate structural, axis/scaling and functional confidence.
- Candidate-to-symbol matches and disconfirming evidence where applicable.
- RR disposition and exact unresolved boundary.
- Reused evidence and explicit no-repeat list.

## Stop conditions

Stop at first unresolved output semantic boundary per candidate. No broad consumer graph, new ROM scan, generic 179-row re-audit, XML/catalogue/workbook modifications.
