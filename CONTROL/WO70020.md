## 4. Interchange formats, schema drift and provenance

- **Versioned JSON (best):** scanner writes `sh7058-cross-rom-scan-v1` per ROM and `sh7058-cross-rom-batch-v1` per batch (`L679`, `L792`) with source/decoded hashes, scanner source hash, command line and inferred layout. TSV companions encode nested evidence as JSON strings (`L786-L830`). JSON is canonical; TSV is derived.
- **Manifest gap:** scanner JSON does not include all output hashes, captured stdout/stderr or exit status; this is why WO70006 remains BLOCKED at its raw-output gate (integration plan §2.4/L49/L162). No new export was created in this WO.
- **Ad hoc JSON/TSV:** workbench `cmd_scan` emits an unversioned `{file, fingerprint, helpers, tables}` JSON and a 14-column table TSV; `cmd_audit` emits a 293-table enriched TSV. No schema ID or output hash.
- **Console-only:** matcher `main` prints consensus/single-source summaries with no machine-readable output; this is the direct reason WO70017 could not reproduce per-pair structural rows.
- **Fixed-schema INDEX TSVs:** indexer, static-index, diagnostic and variant scripts emit domain TSVs into `INDEX/` with printed hash summaries but no per-file schema version or manifest.
- **Example of good practice:** `CONTROL/WO70017_DONOR_METADATA.tsv` carries `source_hash` on every row plus `parse_status`/`unresolved_fields` and preserves conflicts; it is still a derived TSV review view, not a lossless canonical record. Canonical JSON/JSONL is WO70021's authority.

## 6. Migration boundaries and incremental sequence

Shared core stays processor- and ECU-neutral; this sequence preserves standalone commands and does not block EL19A investigation.

1. **Boundary freeze (no source edit in this WO):** treat `build_scan_export()`/`write_machine_exports()` as the single per-call exporter; treat `load_any_rom()` as the loader-source candidate; treat the 26-field WO70017 TSV as a donor-metadata fixture.
2. **Fixtures before refactor:** add synthetic loader, duplicate-address, conflicting-geometry, null/unresolved and deterministic-serialization tests (implementation WOs only). Keep ordinary tests independent of protected ROM/LST/A2L files.
3. **Formats and identity:** extract BIN/ZIP/SREC/HEX/DAT/A2L/XML adapters and generic hash/identity primitives; preserve original-container vs decoded-image hash distinction.
4. **Processor and profile:** move SH-2 opcode/helper behavior into the SH705x backend; move Nissan helper bands, EL19A hashes, paths, checksum offsets and memory windows into explicit profiles. Never weaken existing identity validation.
5. **First vertical slice:** have workbench `scan`/`audit` consume the existing exporter through a stable interface; add the complete run manifest required by WO70006 externally. Do not write a second per-call scanner.
6. **Cross-reference and optional providers:** replace address-keyed A2L dictionaries with the WO70021 relational model; add hash-validated, explicitly typed static-index/diagnostic/variant providers with an `unavailable` state when inputs are missing or stale.
7. **Thin command layer:** reduce the workbench to command orchestration and convert the matcher to a typed JSONL lead provider. Donor names/units/conversions and payload matches remain labelled hypotheses.

## 7. Gaps, risks and no-repeat notes

- No dedicated workbench/matcher/index-generation/diagnostic/variant tests; migration without fixtures risks silent behavior drift.
- Address-keyed dictionaries overwrite duplicate declarations and collapse conflicting geometry — explicitly contrary to the charter's preserve-duplicates rule.
- Scanner caller boundaries remain nearest-prologue heuristics and register arguments come from a bounded 56-byte window; these limits must survive export and UI presentation.
- WO70006 cannot be unblocked by the existing scanner JSON alone; a full attributable run package is still required.
- `tools/nissan_sh705x_workbench.md:L20` states 1,023 lines while current source has 1,022; historical counts and console figures are not current verification.
- Do not re-inventory these tools to rediscover the same anchors; join against `CONTROL/SH705X_TOOL_INVENTORY.tsv` by `path` + `component_or_function`. Do not run the ROM tools to reproduce historical console totals in this WO. Do not rerun WO70017 A2L parsing, WO70006 scans or static-index generation.
- WO70021 owns the canonical data model/JSON schema and WO70022 owns runtime/CI readiness; this report deliberately does not define either.
