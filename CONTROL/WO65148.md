**Gate behavior:**
- `s == 0` → output = `UWORD[FFFF156C]`
- `s == 0xFFFF` → output = `UWORD[FFFF156A]`
- `1..0xFFFE` → interpolated blend of `FFFF156A` and `FFFF156C`
- Gate fail → output = `UWORD[FFFF156C]`
- Caller fail path (0x6AA78) writes `0xFFFF` to `FFFF1D64`; `sub_6A8C0` internal gate failure writes `0` to `FFFF1D64`
