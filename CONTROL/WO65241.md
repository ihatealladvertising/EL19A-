## SH-2 instruction semantics (authoritative)

- `cmp/hs Rm, Rn`: T = 1 iff (uint32)Rn >= (uint32)Rm. Encoding `0x3nnn mmmm 0010`, bits 11-8 = Rn, bits 7-4 = Rm. For `32 02`: Rn=R2, Rm=R0 → T = (uint32)R2 >= (uint32)R0.
- `sub Rm, Rn`: Rn = Rn - Rm (signed 32-bit, wraps mod 2^32).
- `mul.l Rm, Rn`: MACH:MACL = (int32)Rn * (int32)Rm (signed 32×32 → 64-bit). Low 32 bits in MACL.
- `sts macl, Rn`: Rn = MACL. `lds Rn, macl`: MACL = Rn.
- `swap.w Rm, Rn`: Rn = (Rm << 16) | (Rm >> 16) (16-bit halves swapped).
- `extu.w Rm, Rn`: Rn = Rm & 0xFFFF (zero-extend low 16 bits).
- `rts`: branch to PR; the following instruction (delay slot) always executes before the branch target.
- `bt disp`: if T, PC = PC + 4 + (disp * 2); delay slot always executes.
- All loads/stores are big-endian; stack grows downward.

## Two comparison-branch vectors (hand-evaluated)

Entry state for sub_231C8 (from caller loc_23254): R0 = c0 (first sampled cell, masked 0x7F), R2 = c1 (second sampled cell, masked 0x7F), R3 = f (interpolation fraction). MACL preserved across call.

**Vector A — T clear (R0 > R2 unsigned, descending):** falls through to 0x231CC
- R0_entry = c0, R2_entry = c1, c0 > c1
- diff = c0 - c1 (signed)
- prod = low32((int32)f * (int32)diff)
- term = high16(prod) = (prod >> 16) & 0xFFFF = floor(f * diff / 65536) (no 32-bit overflow for byte×frac)
- Return: **R0 = c0 - term** = c0 - floor(f * (c0 - c1) / 65536)

**Vector B — T set (R2 >= R0 unsigned, ascending/equal):** branches to loc_231E4
- R0_entry = c0, R2_entry = c1, c1 >= c0
- diff = c1 - c0 (signed)
- prod = low32((int32)f * (int32)diff)
- term = high16(prod) = floor(f * diff / 65536)
- Return: **R0 = c0 + term** = c0 + floor(f * (c1 - c0) / 65536)

Unified equation: **R0 = c0 + sign * floor(f * |c1 - c0| / 65536)** where sign = +1 if c1 >= c0, -1 if c0 > c1.
