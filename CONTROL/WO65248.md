### 4. Proven software arithmetic vs physical meaning

- **Proven software:** FFFF84A4 is a UBYTE RAM cell read directly by PID43 CAN and 0xA0F2 query; both double the byte. PID43 serializes doubled value as 2-byte A,B; 0xA0F2 saturates doubled value to 0xFF before table query.
- **Not proven here:** physical "absolute load" units, calibration intent, or whether 84A4 is percent/load/torque proxy beyond diagnostic naming. PID43 formula association is consistent with scaling; physical identity unresolved.
