## Objective

Validate every one of the 35 objects in `CALIBRATIONS/EL19A_WO65325_provisional_tiered_v1.xml` against the ROM payload it points at, and give each row a keep / demote / drop verdict. WO65325 verified tag balance and extents only; this WO checks what the bytes actually say.

## Mandatory falsifiable hypothesis

- **Identity layer advanced:** structural confirmation of the emitted inventory (not physical identity).
- **Hypothesis:** every included row points at a genuinely varying ROM payload with a coherent axis, so no included row is constant-like, sentinel-dominated, mis-addressed, or a mislabelled duplicate.
- **Evidence:** the emitted XML; `EVIDENCE/VERSA f501.bin`; WO65323 §3.2/§3.3 mirror and axis facts.
- **Prediction:** rows flagged constant-like by earlier lanes (`0xB622`, `0xC3D6`, `0xC0D6`) would show ≤2 distinct values; the eight twin pairs would show byte identity; every axis would be non-decreasing except the recorded `0x0F7D2` anomaly.
- **Cheap discriminator:** read exactly the declared extents (35 payloads + 16 axis tables ≈ 4.5 kB) and compute counts/identity/monotonicity.
- **Information gain:** turns a structurally valid file into a trustworthy one, and catches any row that should be demoted before a user loads it in an editor.
- **Result:** to be recorded on closeout.

## Scope

1. For each of the 35 payloads: declared length, distinct value count, min/max, constant-like flag, and (uint16 offset-binary rows) whether values cluster around `0x8000`.
2. For each nested ROM axis: read its declared length, verify ascending/non-decreasing ordering, and flag sentinel terminals (e.g. `0xFFFF` in `0x0FEC0`).
3. Verify the eight byte-identical twin pairs claimed in the table names.
4. Verify that the axis address used by each row matches the WO65323 axis assignment for that row.
5. Emit one verdict per row: **keep**, **demote** (tier/annotation change) or **drop** (with reason).
6. Stop after the emitted inventory; do not add rows or widen to the catalogue's other 144 entries.
