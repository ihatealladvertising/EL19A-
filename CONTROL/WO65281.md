## Objective

Resolve the producer provenance and execution chronology of the two state flags selecting the EL19A QDSPT curves at `0xE678` and `0xE688`: `FFFF85F8.bit4` and `FFFF8600.bit6`. The curve addresses, data, reader, query and branch truth table are already established. This WO advances only the semantic identity of the selector inputs.

## Established facts — do not reopen

- `0xE678` and `0xE688` are distinct 16×1 UBYTE ROM objects with identical raw payloads; both are read by `sub_403D8` through `sub_22E10`.
- Query: `min(UWORD[FFFF85AE] >> 1, 0xFF)`; helper uses implicit query grid 0,16,…,240 and rejects query >= 0xF0. The query is timer-capture-derived; physical RPM units are not established.
- Exact selector truth table from WO65183:
  - `FFFF860B.bit3=1`: bypass both curve lookups.
  - If bit3=0: E688 is selected only when **both** `FFFF85F8.bit4=1` and `FFFF8600.bit6=1`.
  - If either inner bit is clear, E678 is selected.
- WO65183 found no direct literal byte-store writers for either inner flag in its bounded search. Treat this as a search boundary, not proof of no writer.
- The paired scalar addresses `0x848A/0x848B) are user-verified `mDDSHPTD/N` calibration definitions; do not infer their Drive/Neutral identity from the flag names or branch order.

## Mandatory falsifiable hypothesis

- **Hypothesis:** the two selector bits are fields in a bounded state structure or are updated by a localized routine/interrupt path, and their joint state determines the E678/E688 lookup branch.
- **Prediction:** effective-address/bit-write indexes and local routine/caller analysis reveal one or more producer paths or a precise indirect/initialization boundary.
- **Falsifier:** no producer/chronology can be established without a broad RAM/interrupt census or dynamic execution.
- **Identity layer advanced:** selector-state provenance; not physical Drive/Neutral naming.

## Scope

1. Start with the existing RAM byte/bit and effective-address indexes. Resolve every indexed access that can write the bytes containing `FFFF85F8.bit4` and `FFFF8600.bit6`, including overlapping word/long stores and GBR-relative/structure aliases.
2. Classify each candidate write as definite/possible/non-write after checking actual effective address, width, masks and instruction semantics. Do not rely on symbol/index annotations without checking the pinned listing.
3. Trace only the nearest producer routines and their immediate callers/guards. Determine whether the flags are updated together, independently, copied from another state block, initialized, or supplied across an interrupt/transport boundary.
4. Establish ordering/validity relative to the `sub_403D8` lookup. If chronology is not statically provable, state the exact scheduling/interrupt boundary.
5. Test whether any producer evidence supports named transmission modes. A Drive/Neutral label requires independent target-side state evidence; donor A2L grouping is insufficient.
